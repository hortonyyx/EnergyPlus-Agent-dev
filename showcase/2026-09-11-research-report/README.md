模型在当前页自动显示，直接拖动旋转、滚轮缩放；BIM 的小工具栏提供整体、分层、复位；两种视图均完整显示楼板与顶面。无需弹窗或跳转。封面仅模型，第 3 页与第 6 页的原始贴图也隐藏原说明面板。键盘翻页从模型传回汇报；离开该页卸载查看器，重新进入恢复默认视图。

整个目录保留在一起即可用桌面浏览器离线打开，不依赖 CDN、外部字体或模型 API。`embeds/` 为基于原查看器生成的精简展示副本，重建方式见 [说明](embeds/README.md)。跨机器搬运保留 `slides.css`、`slides.js`、`assets/`、`embeds/` 的相对位置；`demos/` 保留完整模型资产入口。打印使用静帧并输出七页，交互只在 HTML 中提供。

# Voimatalo：真实贴图单体到轻量 BIM

[打开交互展示](index.html) · [外壳与楼层](envelope.html) · [原始贴图](input_viewer.html) · [下载 GLB](input.glb)

主助手按用户要求直接判读真实网格和完整 UV 贴图，再用项目已有几何工具构建模型。目标是较细的可查看轻量 BIM；这是开发助手辅助探索，不是生产 Agent 的独立冷启动成绩，也未量化证明达到“相对高精度”。

## 输入与产物

输入为 Helsinki 城市摄影测量数据裁出的 Voimatalo 单体，属于 Google Earth 类实景体量，素材并非来自 Google Earth。`input.glb` 是 **glTF 2.0 二进制文件（GLB），969,568 字节，约 0.92 MiB**，包含 12,520 个三角面、8,242 个顶点和内嵌 JPEG 贴图，没有房间、楼层、门窗等 BIM 语义。来源、裁剪和授权信息沿用[原输入说明](../../../../case_tests/textured_mass/single_buildings/voimatalo/README.md)与 `input_selection.json`。

| 版本 | 模型范围 | 空间体 | 窗组 | 门 |
|---|---|---:|---:|---:|
| 外壳与楼层 | 主楼八层、附属体、屋顶及凸出的交通盒；各层内部合并 | 13 | 322 | 10 |
| 空间推理方案 | 办公室、走廊、服务空间、原竖向核心及新增交通盒 | 165 | 322 | 173 |

“窗组”可能包含多片玻璃，不能等同于逐扇窗真值；165 是推理方案的空间体数量，不能表述为还原了 165 个实际房间。当前输出保存在 `revision_02/exterior/`、`revision_02/inferred/` 的 `source_model.json`，包含独立空间、边界、开口、宿主关系和来源说明；没有生成 IFC 或仿真结果。原 `exterior/`、`inferred/` 保留第一版，不覆盖历史。

本次复核另查看了裁剪前去标签瓦片的一小段上下文，以判断贴邻与裁剪遗漏，属于新增证据，不冒称只凭原单体图像就恢复了所有缺失细节。周边建筑只作观察依据，没有加入目标 BIM。

## 怎么演示

当前页面与 sm25 使用相同的原生查看器布局：左侧是楼层过滤、透明度、剖切、展开和量测控制，右侧是模型/对象信息，中央直接查看模型。左面板可打开原始贴图、切换另一版模型、下载当前源 JSON。单层查看会将连续交通盒的显示范围裁到该层，并保留该层已有楼板；不改变源几何。HTML 的脚本与几何内嵌，可直接离线打开，也可用 iframe 嵌入后续 slides。

## 哪些仍是估计

- L 形轮廓、楼层高度、退台及窗口依据网格和贴图量测后规整，未做逐点贴合；重复标准层窗组按可见排布建模。
- 内部隔墙、门及竖向核心位置是明确的办公布局假设。核心中没有逐层封堵的假楼板，未建楼梯踏步和电梯。附属体内部楼板未知，保持合并空间。
- 两端的局部上下文显示紧邻其他楼房，结合残留山墙片段按贴邻墙/露出山墙推断补全，尚未核实隐藏开口。不是看到缺图就直接认定透空，也不是所有缺面都统一封成无窗墙。
- 正面缺口补为阶梯形凸出交通盒：主面主要为不透光墙，侧旁退入窄窗带补六个窗组。外凸位置有裁剪前网格和纹理支持，交通用途、窗洞精确尺寸和每层连接门仍是推断。原 316 个窗组的几何全部保留。
- 屋顶曲面简化为水平顶面和组合体块；地面坡度、遮挡面和细窗框尚未精细恢复。采用墙的代表面，未建材料分层或完整实体墙。
- 查看坐标为局部 u / v / z，v 箭头不是正北。源 JSON 记录从原 GLB 米制坐标到当前坐标的变换。

## 验证与复现

当前源几何、接触关系和开口宿主检查 **pass**；这表示补全方案几何自洽，不等于实际建筑保真通过。七个高度切片对主楼加交通盒的轮廓覆盖一致、没有空间重叠；新交通盒有八处楼层连接门，没有中间封堵楼板。实际离线查看范围见[本次实验与 QA](../../../../AI_agent/logs/experiments/2026-09-10_showcase_voimatalo_revision/README.md)；首版证据仍保存在[原探索记录](../../../../AI_agent/logs/experiments/2026-09-10_showcase_textured_mass/README.md)。

在仓库根使用项目 Python 环境复现到新目录，不覆盖现有资产：

```bash
python AI_agent/logs/experiments/2026-09-10_showcase_voimatalo_revision/build_revision.py --out /tmp/voimatalo-exterior-new
python AI_agent/logs/experiments/2026-09-10_showcase_voimatalo_revision/build_revision.py --interiors --out /tmp/voimatalo-inferred-new
```

脚本显式构造带逐层轮廓的 v2 类型对象并调用既有几何内核；`proposal.json` 是记录，不应直接当作通用 CLI 已支持的新输入接口。主展示页由本次实验目录的 `build_standard_viewers.py` 包装，本轮未修改产品几何、管线、GT 或历史成果。

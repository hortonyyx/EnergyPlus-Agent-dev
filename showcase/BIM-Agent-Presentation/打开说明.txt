面向设计前期的仿真轻量 BIM Agent — 离线汇报版

1. 把整个 BIM-Agent-Presentation 文件夹复制到另一台电脑。
2. 用 Chrome 或 Edge 打开文件夹中的 index.html，即可演示。
   不需要联网、安装项目、启动服务器或登录账号。
3. 如果使用 ZIP，先完整解压，再打开 index.html。

操作：
← / → 翻页；1–7 跳页；F 全屏；O 打开目录。
模型可直接拖动旋转、滚轮缩放，成果页可切换整体 / 分层。
两个 BIM 的楼板和顶面均已恢复。

research-report.pdf 是七页静态备用版，可直接打开，模型不能旋转。
请保持 assets、embeds、slides.css、slides.js 与 index.html 的相对位置。
来源与模型说明见“素材与模型说明.txt”。

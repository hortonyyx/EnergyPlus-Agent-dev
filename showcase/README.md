# 展示资产目录

`index.html` 是离线入口，收纳课题汇报和可查看的展示资产。产品实现与实验记录仍在各自目录。

- `2026-09-11-research-report/`：七页中英双语 HTML 汇报；入口为 `index.html`，模型资产入口为 `assets.html`。详细操作见该目录 README。
- `previous-showcase/`：历史展示原型，入口为 `previous-showcase/prototype/index.html`；保留以便回看，不表示当前产品能力或研究结论。

新资产的实际验证范围以各资产自己的 README、实验记录和 QA 报告为准。展示页不会把人工辅助、探索性假设或未完成产物写成自动生成成功。

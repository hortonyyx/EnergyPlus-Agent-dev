## 二、⭐ 一处**看起来像**说谎、实际不是（必须写清，否则下一轮会误判）

`self_check.all_visible_strokes_captured = true`，同时 `uncaptured` 有 9 条 —— 形状上与
2026-08-19 GPT r1 那次「自检说谎」一模一样。**但内容不是同一回事**：

- 那次 r1 的 `uncaptured` 点名的是**两道它没画的走廊墙**（真漏）。
- 本次 9 条 = **8 条门洞被 heal 进宿主墙**（pen library 的规定动作，不另立笔画）+ **1 条家具显式排除**
  （~16 个家具符号逐类点名）。⇒ 是**拒收台账**，不是漏画自白。

⇒ **判据修正（记进方法论）**：`all_visible_strokes_captured` 与 `uncaptured` 并存**不构成**自相矛盾；
要看 `uncaptured` 里装的是「按规矩不画的东西」还是「该画没画的东西」。
⛔ 只数条数会把好产物误杀。

## 三、⭐ 与 08-19 诊断不一致、且**对我方结论有利**的一点（也必须写）

锚点是**整数**（425 / 1815 / 346 / 1087），不是 R1 那次的亚像素（273.56 / 1172.48）。
08-19 的病灶叙述把「整数锚」当成 Haiku 失败的指纹之一。**本抽证明那条相关不是因果**：
整数锚 425/1815 与 07-07 满分那次的 425.4/1815.9 **指的是同一组图元**，四舍五入带来的误差
≈0.9 px / 1390 px ≈ 0.06%，不影响结果。

⇒ **真正的分界不是「锚点是不是亚像素」，是「锚点指没指对图元」**；而指对图元靠的是放大回读
（本抽 20 次 crop_zoom），不是数位小数。⛔ 不要把「亚像素」写成验收判据。

## 二、REWORK 的唯一依据（过程缺陷，与分数无关）

**只标定了一根轴。** 工具单次调用就支持两轴同时给全，读图说明书也要求跨轴一致性核对；
只给一轴 ⇒ **跨轴门没有比对对象**，那道门在本抽上等于不存在。

这正是已登记的 F-63：08-19 Haiku 就是把两轴拆成两次单轴各自自洽、然后自己取平均，
门抓不住。**本抽是同一条缝的另一种形态（干脆只标一轴）。**

⇒ 返工要求 = **纯过程**：用一次调用同时给出 x 与 y 两条锚，让跨轴一致性判据有对象。
⛔ 返工文本不含任何坐标、不含 gt 值、不含「哪里画错了」。

## 三、⚠️ 明确**不**作为 REWORK 依据的两项（避免下一轮误用）

1. **`provenance` 全 `seen`、引用 0/17** —— ⛔ 不构成缺陷。2026-08-19 已实证该标注**不具分辨力**
   （那次满分的产物同样是 17 条全 `seen`、引用 0/17）。此判据已收回，不得复用。

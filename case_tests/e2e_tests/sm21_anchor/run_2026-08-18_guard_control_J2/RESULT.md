## 三、F-62（新，未修）：guard 把 heredoc 正文当成命令参数

**根因**：`_check_bash` 对**整条多行命令** `shlex.split`，于是
① heredoc（`python << EOF … EOF`）的**正文每个词都成了命令参数** ⇒
  取决于正文里恰好有什么词，随机触发「脚本必须位于 out/」「path escapes staging」等；
② **反斜杠续行**的换行成为一个裸参数 ⇒ 探针参数校验器报「意外的裸参数」。

**独立复现**（真 staging + 真 guard）：

| 形态 | 结果 |
|---|---|
| `python -c "print(1)"` | ALLOW |
| `python << 'EOF' / print(1) / EOF` | **DENY** |
| `--tool … \`+换行+` --image …` | **DENY** |
| 同一条写成单行 | ALLOW |

**⇒ 这是 F-49 → F-60 → N-1/N-2 → F-61 → F-62，同一族第五次。**

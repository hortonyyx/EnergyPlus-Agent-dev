## 实际任务与方法

该研究面向韩国城市既有建筑的简化基准 BEM 自动生成。输入已有建筑数据，照片用于补充窗墙比；它没有验证仅凭单张照片恢复建筑几何或室内空间。

## 作者报告的实验结果

| 实验 | 结果 | 必须同时保留的条件 |
|---|---|---|
| 模型选择（第 9–12 页） | 14 个 LLM；前 5 类任务各做 5 次，调试另按 3 类错误各做 5 次 | 角色选型主要使用一栋 10 层、19 顶点的 Bldg4；不是多种建筑形态的完整能力基准 |
| 多模型组合（Table 4） | Haiku 4.5 用于 U-value 与 WWR；grok-4-fast-reasoning 用于 M&C、Z&S、window、debugging | 这是论文当时、该任务和评价条件下的选择，不是当前模型推荐或通用能力排名 |
| 270 栋建模（第 10–13 页） | 多模型与全 GPT-5 两组均完成全部 270 栋 | 包含调试修复；“全部完成”不等于首次无错或精细 BIM 还原正确 |
| 时间与费用（第 10–12 页） | 多模型平均 94.2 s、$0.02/栋；全 GPT-5 平均 708.6 s、$0.31/栋；作者报告分别降低 86.7%、93.5% | 同一简化多智能体流程内的模型配置比较，不是单 agent 与多 agent 比较；不能直接与本项目整案成本横比 |

## 与质量判断有关的限制

1. **WWR 成功率不能当成读图准确率。** Table C1（第 23 页）对 WWR agent 只列“正确获取街景图片”；第 9、14 页明确没有 WWR ground truth 验证。窗口角色检验的是生成值与估计值一致，不能验证最初估计正确。
2. 图像缺失或判断模糊时，规则采用 WWR = 0.30（第 18 页）。它是默认假设。论文第 14 页报告，一栋代表建筑的 WWR 从 10% 改到 40%，年能耗变化约 13.7%。
3. 房屋统一拉伸、每层一个热区、代表墙上的简化窗、Ideal Loads 等设定与城市基准模型目标相符，但没有证明房间布局、门窗关系、退台或复杂外形已恢复。
4. 数据准备依赖专家和韩国地区资料，作者明确指出尚不能外推全球适用性（第 14 页）。第 24 页声明研究数据没有分享许可。

## 对 Sim BIM Agent 的启发（项目判断，尚未实施）

- 支持刚讨论的 work model 原则：先按具体任务及质量条件测出可用模型，再比较耗时、费用并考虑组合；通用能力档位不能代替项目内实测。论文选型本身不要求我们采用其中的具体模型。
- 五类知识结构可帮助审查现有 domain 文档，但不能据此把所有角色固化为固定阶段，或照搬其每种 IDF 对象一个 agent 的划分。可以确定性处理的几何、单位和对象序列化仍应交给工具/kernel。
- 其照片能力是“局部视觉属性提取”，可作为可复用方法；不等于已经完成纯照片到源 BIM 的完整路线。
- 本项目要独立检查照片可见部分的一致性、推断部分的建筑合理性、源 BIM 的几何/语义/连接以及下游可用性。能耗结果接近不能单独证明空间和构件正确。

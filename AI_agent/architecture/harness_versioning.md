一次有价值的实验或交付保留：

- 代码提交，若有未提交业务差异则附补丁或对应存档。

- 运行到了哪里、哪些检查/评分执行、结果和已知缺口。
- 与旧结果比较时，说明输入、模型或口径是否改变。

直接使用 Git commit/tag 和 run/工作记录，不另造一套 v0/v1 准入清单。能力改变时更新 [能力图](../capability/README.md)，当前任务只更新 [plan.md](../plan.md)。目标档运行模型从首批实验参与。

# 输入适配与混合样例

状态：设计建议，尚未实现。两路输入与最终混合入口是已确认的目标；具体公共 schema 要在样例上验证。

第一组样例分别使用已有图纸 case、用户提供的带表皮体量，并以一个局部补充输入验证它们能细化同一个结果。体量输入不通过伪造 reading 平立面数据接入。

图纸适配保留房间、尺寸、门窗及可验证来源；体量适配先保留外形、楼层和表皮，再生成标明假设的内部结构。CAD 在生产侧提供几何/尺寸证据，已有 CAD→GT 工具只作为可复用技术，不能把评分答案混进生产链。

共同边界先覆盖单位/坐标、房间或推断空间、边界与开口、来源/假设/冲突及查看输出。从现有模型演进，缺一个能力再补一个，不先完整复制新几何引擎。

完成样例时检查两路是否交给同一个模型和出口、缺失信息是否可见、补充输入能否更新相应对象。输入不足时产出有用的较粗模型；完全无有效约束时可以概念化，但不能称作真实重建。

并行建议：公共接口先在 main 落一个最小例子，各输入在短期分支改各自模块，公共变更随做随集成。详细结构与取舍见 [融合设计](../architecture/multimodal_bim.md)。本轮不创建开发树或执行此提案。

**核心原则(一句话)**:**视图 ≠ 面**。`Facade=Literal[N/S/E/W]` 保留、语义收窄为**视图/朝向族**(正交投影方向);
「面」= 新的 `facade_segments` 确定性表(D10#2)。**立面识图保持 image-local 2D、永不判断深度**——
前后关系(深度)全部来自平面 footprint 多边形,由确定性核把两者拼起来。这是分工铁律在 C2 的自然延伸,
也直接回答用户「怎么收全部立面数据」:**收不到的不硬收,确定性算出哪里收不到,然后诚实登记**。

## E1 · 立面可见性模型(确定性,B5 的核心新件)

**输入**:per-floor footprint 多边形(B2/D3)。**输出**:`facade_coverage.json`(1_correction 确定性核产物,单一 writer)。

1. **分段派生**:footprint 每条边按外法向归入 N/S/E/W 朝向族;同族内按沿轴坐标排序,
   段 id 确定性命名 `{D}{k}`(N/S 按 x 升序、E/W 按 y 升序,如 `S1,S2,S3`)。每段记录:
   `edge_ref`(polygon 边索引)、`along_interval:[a,b]`(世界沿轴区间)、`depth`(叉轴世界坐标)。
2. **可见性计算(1D skyline)**:对每个视向(如 South = 沿 -Y 看),同族各段按 along 区间做区间覆盖竞争——
   同一 along 位置上**叉轴最靠视点的段可见**,其余被遮挡。输出每段
   `visible_intervals: [[a1,b1],…]`(可为空=全遮挡、可为多段=部分遮挡,Z/T 形出现)。
   正交下这是纯一维区间运算,确定性、可单测穷举;**算法按「任意视向」写(输入=方向向量),C2 只实例化 4 个轴向,C4 斜交时零重写**。
3. **几何直觉验证(设计依据)**:L 形=多段但全可见(缺口两面各朝外);凹/U 形=**缺口两侧翼墙互相遮挡→四视图全不可见**
   (用户「四个立面不够」的精确形态),缺口底墙从开口方向**可见**(深度更远但 along 区间无人遮挡);
   口/中庭形=四个内立面全不可见。→「收不全」不是模糊风险,是**可精确计算的清单**。
4. **窗归翼确定性化(对 D10#2 的修订)**:立面图上每扇可见窗,经标定得世界 along 坐标 →
   落在哪个段的 visible_interval 内即归哪段——**正交投影下可见位置↔段是单值映射,不需要 VLM/A3 判深度**。
   `Window.facade_segment_id` 由确定性核填,A3 仅收**例外**:窗 along 坐标落段边界 ±容差内、或落在无可见段的区间
   (识图错/虚线画了被遮挡构件)→ conflict 条目,不静默。容差进 correction.yaml + A0 登记(禁裸字面量,D9#4 同款纪律)。
5. **per-segment `derive_facade_frame`(D4/B5 原计划)**:每段一个 `base_world`,E/W 号位约定继承 6.30 翻正后的定案;
   验收含 sm21 单平面回归(单段=现行为字节不变)。
6. **楼层维度**:可见性按层计算(C2 各层 footprint 相同→各层段表相同;结构上按层算,C3 退台到来时零改动)。

## E2 · 缺失立面数据政策(全新)

1. **账本**:`facade_coverage.json` 每段给 `coverage ∈ {observed | partially_observed | unobserved}`——
   由可见性(E1)× 实际收到的视图集推出。四张标准立面 = 缺省视图集;**视图集显式化**为 run 输入清单
   (case_data 里有哪几张立面、各属哪个视向),为将来「补交庭院立面/局部立面」留缝(C2 只做 4 标准视图,缝留好)。
2. **unobserved 段的窗政策(诚实缺省)**:**不发明窗**——unobserved 段缺省无窗 + gate① WARN(非 block:无窗建筑合法)+
   REPORT 显式桶:「N 段立面不可见,窗数据未知,如需精确请补充立面图」。与 reading-honest 同一哲学:
   证据不在,宁可标记不可猜。**不走 prior 阶梯发明几何**(prior 只用于物理属性,几何幻觉是 J0/J1 抓的重罪)。
3. **判卷同步(并进 B4)**:gt 有窗而落在 unobserved 段 → 判 `NOT_APPLICABLE(unobserved)` 单列计数,
   **不算 miss**(reading 不能隔墙视物)也**不算 hit**;判卷 sidecar 记录 coverage 摘要。
   judge 侧可复用 E1 helper 对 gt 多边形算可见性(纯函数在 src/agent/geometry,gt 铁律不破:gate①/执行器仍不 import gt)。
4. **贯穿性(用户点名「以后非正交更复杂」)**:E1 算法方向泛化(见 E1.2)+ coverage 状态机与视图清单机制
   对任意视向成立;非正交时只换「段派生」一步(边法向不再限 4 族),政策层零改。

## E3 · envelope 多边形完整仲裁(完成 D3 遗留)

1. **权威分工**:平面多边形(尺寸链定各顶点)= 形状权威;立面 = **外包 bbox 佐证**(每视向 overall span 仍应等于
   多边形该向投影全宽——凹/L 形下依然成立,翼间缺口不改变投影 span)+ 分段宽度佐证(翼分界有标注时)。
2. **吸收规则泛化**:`envelope.py` 现行「lo/hi/跨度 ≤ ENVELOPE_RECONCILE_TOL 则吸」按**逐边**执行:
   贴边 cell 边吸到多边形对应边(B0 已有 attachment 判定,BoundaryGrading 已有贴边提取可参照);
   分歧超容差 → conflict 升 A3(现行为)。缺口深度(notch depth)无立面证据时以平面尺寸链为准——
   立面对深度本来就无证据(正交投影不显示叉轴),这条与 E1「深度全来自平面」自洽。
3. **验收**:矩形 case 严格退化为现行为(字节回归,D10#3 同款);合成 L/凹形 envelope 吸收 + conflict 负例。

## §T · 用户测试案例规格(明后天出图用)

**共同要求**:与 sm24 同套出图纪律——天正 CAD 图形导出 DXF(供 `gt_from_dxf`,DXF 放 gt 根外)、
平面尺寸链**包含每个缺口的两轴偏移**(多边形每个顶点可由链算出)、四张标准立面、各层 footprint 相同(退台留 C3)、2 层即可。

1. **sm25-L(第一梯级:多段无遮挡)**:L 形,如 15×8 右上切 6×3。北/东各成 2 段(不同深度、along 区间不相交),
   南/西单段。全部段可见 → 只考 E1 分段+归属+E3 envelope,不碰缺失数据。**缺口两面都放窗**(考深段窗归属)。
2. **sm26-U(第二梯级:前后关系+遮挡)**:凹形开口朝南,如 15×8 中部切 7×5。南视图 = 两翼前脸(2 段,同深)+
   缺口底墙(1 段,深 5m,经开口可见)→ 同视图三段前后关系;**缺口两侧翼墙(朝东/朝西的内壁)四视图全遮挡 = unobserved**。
   **在缺口底墙放窗**(考「同视图不同深度的窗」)+**在一面侧翼内壁也放窗**(考 E2:系统必须不发明它、
   判卷 NA(unobserved)、REPORT 提示补图——这扇窗就是政策的验收器)。
3. **sm27-口(第三梯级,可缓)**:中庭四内立面全 unobserved;若做,可另出 1–2 张庭院立面当「补交视图」考输入扩展缝。
   不阻塞 C2 收官,B6 用 sm25/26 即可。

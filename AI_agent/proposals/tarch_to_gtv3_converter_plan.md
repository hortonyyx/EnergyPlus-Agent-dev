## 0. 裁决摘要

**主干 = opus 稿的「腔体 + 逐边外扩」路线**（补洞 → polygonize → 面积二分出腔体 → 逐边向外测厚外扩到
「外墙落外皮 / 内墙落轴线」的混合基准框）。**明确不做双线成对匹配**。

**三条决定性理由** `[M]`：

1. **它绕开了另一方自认最脆的一环。** sol 稿把「双线配对 + 唯一性证明」列为自身最脆环节
   （原文：「洞口和接头切碎后的双线墙配对及唯一性证明」），并诚实指出这里存在
   **信息论上的不可识别**（纯双线矩形无语义时无法区分"厚墙"与"窄房间"）。
   opus 路线**根本不需要配对**——它从腔体（房间净空）出发向外测厚，墙的两侧线是否"配成一对"不影响结果。
2. **接头问题被结构性消解。** sol 稿需要一张 5 类接头（L/丁字/十字/自由端/厚度变化）的分类求解表；
   opus 路线中，正交多边形的边严格 H/V 交替、新顶点 = 相邻两条外扩后支撑线的交点，
   **L 角/丁字/十字/凹角不需要任何特例代码**。少一整类特例 = 少一整类 bug。
3. **它是唯一一份有端到端实测的，且实测数字已被主控独立复现**（2026-07-21→22 闭环）：
   洞口 **21/21** · 补洞后 `dangles/cuts/invalid` **全 0**（faces 51）· Σ面积 **200.0 m²** ·
   腔体 **8 个**（墙体域 20.84 m²）· **L 走廊天然单面**（27 顶点 L 形、30.82 m²，未在拐角引入任何线）·
   外扩后 8 区对称差 **0.000000 m²** · 两两重叠 **0.0 m²**。
   > **溯源闭环**：出稿方初次未落盘脚本 → 对抗审 C6 判"无法判定"（复现不出拓扑数字）→ 主控要求原样落盘
   > `logs/experiments/2026-07-21_sm24_gt_extraction/probes/`（17 脚本）→ **主控独立跑 `final.py`/`final2.py`
   > 逐项复现，全部吻合**（唯一微小出入：稿称走廊 30.82 是"最大面"，实为第 2 大〔最大腔 35.8〕，
   > 不影响"走廊单面"结论）。⇒ **C6 从"无法判定"结清为"已复现"**，理由 3 效力恢复。
   > 教训固化：**探针数字必须随稿落盘脚本**，否则第二方无法复现即不能作裁决依据（本轮流程缺陷已补）。

**但 sol 稿贡献了 7 条主干缺失的关键条款，全部并入**（§2）。sol 稿在**证据纪律**与**边界情形**上更严，
opus 稿在**算法可行性**上有实证——这正是双独立的价值，不是二选一。

## 2. 从 sol 稿并入的条款（**逐条具约束力**）

### 2.1 `[S]` 厚度证据的**六类合法来源**，取代基线的 `[t_min, t_max]` 区间兜底

基线用 case intent 里的合法墙厚区间（默认 `[0.06, 0.50]` m）筛墙垛端头。**这不够**——区间是先验，
落在区间内的错误配对不会被发现。**改为**：厚度只能来自源图**离散证据**，且每段保存自己的 proof：

1. 窗块 bbox 短边（实测 sm24 全部 = 240，与外墙一致）
2. 墙端 cap / opening jamb（连接两侧面的短线）
3. `PUB_DIM` 中**显式绑定**的墙厚尺寸
4. `PUB_HATCH` 两侧边界（**仅**作外墙局部证据——实测 sm24 的 hatch 只覆盖外墙）
5. 已认证厚度在另一段上的**精确复现**
6. source-hash 绑定的**人审 override**

**禁止**出现 `DEFAULT_WALL_THICKNESS` / `MAX_WALL_PAIR_DISTANCE` / `MIN_ROOM_WIDTH` / "取最小间距"。
合法墙厚区间**降级为 sanity 断言**（超区间必 fail），**不得**作为厚度的来源。

### 2.2 `[S]`+`[M]` 面积二分阈值的纪律：**歧义不得由阈值消化**

基线 `A_room`（默认 2 m²）把面分成腔体/墙体。sol 稿正确指出这里藏着与双线配对**同一个**信息论问题
（"这个小面是厚墙还是小房间"）。裁定 `[M]`：

- `A_room` **只用于分桶提案**，不是判据；
- **分桶结果必须与人声明的房间数一致**（闸门 G6），不一致 **一律 fail**；
- **严禁自动调整 `A_room` 直到数量吻合**——那正是把错答案调出来的经典路径；
- 失败诊断必须列出**落在阈值附近**（`[0.5·A_room, 2·A_room]`）的所有面及其面积与坐标，供人判读。

⇒ 基线原文"误分会立刻被 G6/G7 抓住，不是静默风险点"的判断**成立且予以保留**，但必须由上述禁令兜死。

**⚠️ 对抗审 C4 强化条款（2026-07-21）**：G6 的**计数比对是必要非充分**条件 —— 可构造**补偿性误差**
（一个小房间被误判为墙 + 一个墙腔被误判为房间）使**数量恰好吻合但分配错误**，纯计数抓不到。
⇒ **充分闸门 = 近阈值面清单 + G8 反演重建 + G10 人核 三道，全部是承重件、施工不得省任何一道**。
若施工时这三道偷工，本条的绕过路径就会成真。

### 2.3 `[S]` outer skin 用**无界 flood-fill** 求，不用 Footprint 外环

基线以 `unary_union(全部面)` 的外环为 footprint。对**多部件**（两栋分离体量）与**带洞**（回字）会给出错误结果。
改为：从 arrangement 外侧做**无界 flood-fill**，与无界外部相邻的墙面链构成该层 exterior outer-skin ring。

- 被外墙包围、**与无界空间不连通**的空白 component：有 zone anchor ⇒ 房间候选；有 `VoidIntentAnchor` ⇒ footprint 内环；
  **两者都无或都有 ⇒ 阻断**。
- **多个不相交 exterior ring ⇒ multipolygon ⇒ 阻断**，保留 IR 诊断，**不取最大环**。

### 2.4 `[S]` 「信息论不可识别 ⇒ 阻断，不发明先验」写进设计纪律

sol 稿原则原文并入：*纯双线矩形在没有厚度、标签、cap 等语义时确实可能无法区分"厚墙"与"窄房间"，
这是信息论上的不可识别，正确行为就是阻断而不是发明先验。*
⇒ 全稿任何"猜/取最近/取最像/打分选第一名"的做法**一律禁止**；歧义必须 fail 并列出**最小冲突集**。

### 2.5 `[S]` 接头 5 类分类表 ⇒ 转为**负例测试矩阵**（强制覆盖）

主干路线结构性消解了接头特例代码，**但不等于这些形态不会出错**。sol 稿的 L 角 / 丁字 / 十字 /
自由端 / 厚度变化 五类，**每类必须有合成夹具的正例 + 负例**，验证外扩重建给出的顶点与手算一致。
特别是 **厚度变化跨边**（基线 S7 步骤 3 的"按段拆边、产生真实墙垛错台"）必须有独立夹具。

### 2.6 `[S]` 自由端墙的**证明式**处理（补基线空白）

基线遇残留悬空即 `tarch_wall_free_end` fail 停下让人决定 —— 方向正确但过粗。并入 sol 的细分：
两侧空间绕 cap **连通**且属**同一 intent** ⇒ 可经证明标为 `non_zoning`（保留在审计 IR、不发到区划线）；
否则要求人确认或修图。**绝不自动延伸**（自动延伸会横切走廊 = Q5 明令禁止）。

### 2.7 `[S]` 逐实体 `source_map` 落盘（应对基线自登记的 D7）

基线 D7 诚实登记了：派生实体导致 gt 内溯源指针**指向派生件而非原始墙线**。
⇒ 必须落 `source_map.json`：每条输出边 → 其 ancestry（原始 WALL 句柄 / 洞口块句柄 / 派生规则 ID）。
人核与后续判卷追责都依赖它。**这是 D7 的缓解措施，不是可选项。**

## 4. 两稿一致、予以确认的结论（**已双重独立验证，可信度最高**）

1. **接缝**：不改 v3 提取器本体，转换器产 规范化几何 + manifest，交现有链路。
2. **种子点不得自证**：坐标归机器、**数量与房名归人**；若种子由转换器自己的面反推，
   v3 的"每面恰含一个种子"退化为**自证同义反复**，被错切的走廊会自动配两个种子一路全绿。
   ⇒ 两方独立指向同一结论，**列为全链最脆环节**，闸门 G6 是主防线。
3. **回字形（带洞）是硬例外**：当前 `c2_simple_orthogonal_no_holes` profile、提取器、validator **三处**都拒内环；
   sm27 前必须**单独立项**做带洞 profile 扩展（不是加个枚举值）。
   **⚠️ 该立项清单必须含以下两条（对抗审清单外发现）**：
   - **S7 远端分类支持内环**：现判据只查**外环**（射出点落在 Footprint 外环 ⇒ 外墙）。回字形有内院时，
     **朝内院的墙射出点落在内环上、会被误判为内墙**（扩 d/2 而非扩到内院外皮）⇒ **sm27 会静默出错答案**。
     本批因带洞已被前置阻断而潜伏，**解除阻断时必须同步改写**。
   - `vg_for_direction` 支持凹角单环、**不支持洞**（见 §6.3），属同一立项。
4. **不用 LLM、不猜、fail-closed**：这是答案生成器，静默错答案比崩溃危险得多。
5. **逐墙厚度、逐层 footprint、多环 IR 从 v1 起保留**，绝不把"无洞/单层/各层同 footprint/墙厚统一"写进算法。

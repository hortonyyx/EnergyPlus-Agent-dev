# 识图泛化策略

**核心判断**：完整矢量化重建（FloorplanVLM 等）对当前任务目标（产 IntakeOutput）是过度工程。中间路径——"LLM 元分析自主发现规范 + 轻量 CV 预处理提供视觉统计量"——更匹配 ROI。

**Why**：IntakeOutput 不需要像素级精度（zone 尺寸 5% 误差不影响仿真结论），只需要回答"几个 zone、每个多大、窗在哪"。完整矢量化试图回答"图上每一根线是什么"，投入产出不成比例。

**How to apply**：
- 短期优先做 prompt 改造实验（拆为元分析段 + 抽取段，让 LLM 先发现规范再抽取），成本 ~2 天
- 中期 B7 预处理定位从"增强当前规范"改为"提供视觉统计量（线宽/颜色/文字坐标）供 LLM 自行语义绑定"
- 仅当 A+B 都撞墙 + 有 500+ 标注数据时，才考虑微调小 VLM

**三层次分解**：L1 符号层（门/窗/墙的图形表示）/ L2 标注层（尺寸/文字/图例位置）/ L3 语义层（空间功能/关系表达）—— L1 最适合 CV 辅助，L2/L3 是 LLM 强项。

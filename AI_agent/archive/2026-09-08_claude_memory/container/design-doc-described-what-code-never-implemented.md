## 2026-08-23 同一天，同一形状犯两次，两次都要换人才看得见

| 轮 | 我写的 | 实际 |
|---|---|---|
| 一审 | 「三种破坏变异全部报红 ⇒ **尺子没改松**」 | 我挑的三种**恰好都是尺子看得见的**。审阅方第一条就找到漏的那种：**一条线两头读到了、中间没读到** —— 挖掉 153/198 段的中间 20%，分数**逐位不动** |
| 二审 | 一份完整的 v2 设计稿：三层 schema / 不跨接 / 无 `class` / `admissible_alternatives` / 面线级 `ink_coverage` | **代码一样都没实现**。§八引用的每个数都是 **v1 形态产物**跑的 ⇒ 证明不了 v2 |

二审顺带打掉我**最得意**的一条：「假面线 `ink_coverage`=0.74、真的全是 1.000，分得干干净净」——
那个 0.74 **完全是 v1 跨接造出来的**；按我自己主张的不跨接拆回去，五段**全是 1.000**、与真墙面分不开。
⇒ **我在同一份稿里既主张删掉跨接、又拿只有跨接才存在的数当证据，自己没看见。**

## 有效的做法（当日实证）

1. ⭐ **先实现、后写文档**。用户当日拍板后我直接写代码，产物出来再写文档，二审的头条随之消失。
2. ⭐ **送审前按自己列的存疑项去核**：我在稿里写了「§八#4 我没跑过真实转换」，然后真去核，
   **当场推翻了自己「B 步序列化即可」的承重假设**（实测 `span_a` 只是单个 DXF LINE 的端点，
   448 条线归组后只有 151 条面线、最碎 15 段）⇒ 工程量从「小」上修为「中」。这条自查有效。
3. ⭐ **审阅方要被明确要求「再找一种能骗过它的真实错误形态」**——两轮都是靠这句话拿到最值钱的 finding。
4. **参数一律扫描证明不承重**（当日四次全有效）；**免疫项必须单独验证变异真的生效**
   （我第一版「1 像素作弊」变异把伪造空档跨度写成 `[0,0]`，任何参数下都"必红"——测试本身坏了）。

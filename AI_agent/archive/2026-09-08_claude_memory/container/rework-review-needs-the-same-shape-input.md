**2026-08-27 实测（F-97 契约判别器返工审，GLM 家族）**：请求单给了三条判据，
①「在返工前的 commit 上复现出那条缺陷」②「在返工后的 commit 上确认不再复现」
③ ⭐「**修法只堵住了被举的那一种输入，换同形输入照样走通**」。

**读数**：①② **三条阻断全绿**（旧夹具全复现、新夹具全不复现、三次 neuter 零附带、全量 3070 绿，
上一轮复核方提的三条阻断**无一判错**）。**③ 一条判据抓出 3 条新阻断**：

- **只修了半句**：上一轮返工要求原文是「未登记 **/ 畸形** 声明 ⇒ unknown」，
  施工只修了「未登记」那半 ⇒ 声明**已登记**值但缺必需键的文件仍被静默消费（3 个已登记值全部塌缩）。
- **修法挪了个位置**：账先行的修法在被点名的那个入口成立，但**组合入口**（上游 40 行）
  自己先解析了同类文件 ⇒ 同一夹具死在**逐字相同**的异常、同样无账。
  它自己 docstring 写的 "Runs before ANY consumer" 在那一层是假的。
- **前提本身不成立**：「账本永不抛」被三个**普通文件系统/编码现实**证伪
  （非字符串声明值 ⇒ `TypeError: unhashable`；非法 UTF-8 ⇒ `UnicodeDecodeError`；
  **一个名叫 `*.json` 的目录** ⇒ `IsADirectoryError`）。前两个来自另一席位的线索，第三个是复核方自加的。

**Why**：①② 回答的是「**这个例子**修好了吗」，③ 回答的才是「**这类缺陷**修好了吗」。
施工方为了通过验收，天然会朝着「让被举的夹具变绿」收敛 —— 这不是坏信念，是判据的形状决定的。
同族 [[offline-fixtures-test-gate-discriminating-power]]（好的全绿+坏的至少红一条）与
[[neuter-proves-wiring-not-discriminating-power]]（变红只证接线）。

⭐⭐⭐ **2026-09-06 把 ③ 锐化成一句可机械执行的提问：「交件自带的证据，覆盖了哪一半？」**
当天两条线的复核**各自都是在【交件自己没走过的那一半】上抓到东西的**：
- **E-a′**：交件证明立面 `lo<hi` 拦截能变红，但它只 mutate 了 `facts[0]` —— 按 fixture 的边顺序
  `['O:x0','O:x1','O:z_low','O:z_high']`，那是 **x 轴**；**z 轴分支从未被验过**。复核方自造
  `z_low := z_high` 的反例，才把另一半验掉（两轴都能独立变红）。
- **J**：交件只演示过分辨率 `0.6`/`0.35` 两个值；复核方取**独立第三值 `0.123`**，并把消费函数
  改成永走默认分支 ⇒ 3 条锁变红 ⇒ 证明验的是**消费本体**而非「两个常量不相等」这个影子。
- **E-a′ §2.3**：⭐ 复核方**拒绝用被测代码自带的 `verify_tick_archive()` 去自证**
  （用它验证自己 = 自证），改用裸 `hashlib.sha256` 在磁盘字节上重算 `batch_id`。

**⇒ 复核的头号提问不是「它验了吗」，是「它验的是哪一半、另一半谁验」。**
判别动作：把交件每条「已变红」证据的**变异点**拎出来，对照该判据**声称覆盖的维度集合**
（几个轴 / 几个分支 / 几个参数取值），**逐维问有没有被各自量到**——
这正是 [[gate-teeth-direction-follows-fixture-inventory]] 的「别问有没有对照物，
要问它声称覆盖的每种量各自有没有被量到」用在**交件证据**上。

**How to apply**：
0. ⭐⭐⭐ **复核单固定写一条**：「**交件自带的变红证据，每条的变异点落在哪个维度？
   该判据声称覆盖的其余维度，各自造一个反例验过没有？**」+「⛔ 不许用被测代码自带的
   校验函数去证明被测代码正确（那是自证），换独立实现或标准库重算。」
1. **凡「修了某条阻断」的返工审，判据固定写三条，⛔ 缺一不可**：
   ① 旧 commit 复现得出（**复现不出 ⇒ 上一轮判错了，如实写**）· ② 新 commit 复现不出 ·
   ③ ⭐ **换同形输入仍走不通**。
2. **③ 的「同形」要给方向而不是给清单**（清单会被当穷举）：
   「上一轮打的是 X 面，本轮请**换方向**」+ 若干提示 + 一句「⛔ 只是提示、不是穷举」。
3. ⭐ **把上一轮返工要求的原文逐字贴进新请求单** —— BLK-A 正是「原文有『畸形』二字、施工漏了半句」，
   若我只写压缩版，复核方无从发现漏的是哪半句。
4. ⭐⭐ **另一席位没交成件的中间产物要当「线索」交下去，⛔ 不当证据**：
   08-27 GPT 做完 113k token 的复核后被自家 provider 安全过滤拦在交件前，
   探针文件被抢救下来交给 GLM，明确写「⛔ 线索非证据，请独立复跑，且⛔ 不许因此跳过你自己的找缝」。
   **结果：5 条线索里 2 条升成阻断，复核方还自加了第三个同族形态。** 那 113k token 没有白烧。

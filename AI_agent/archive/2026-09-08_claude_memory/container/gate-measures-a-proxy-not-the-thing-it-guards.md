⭐⭐⭐ **2026-09-04/05 一天之内，四条独立的线全部因为【同一个形状】被打回**，
这是本项目迄今最集中的一次同族证据：

| 线 | 判据量的（代理量） | 要守的那件事 | 怎么被击穿的 |
|---|---|---|---|
| **B2 返工 2** | `isinstance(x, ValidatedFloorLadder)` | **它真的过了字节门吗** | 类型注解 `tuple[_DerivedFloorLevel, ...]` **运行时不强制** ⇒ 塞个 `SimpleNamespace` 就装配成功 |
| **T4-a 返工 1** | 输入**像不像**活键（19 项近错族参数化） | **它能不能被成功解析** | 挂一个**与活键毫无字面相似**的兼容映射 `"owner_b4"→活键` ⇒ 三层锁全绿、债被真退休 |
| **刻度认领设计稿** | 边落在 `cum_mm` **节点**上 | **值能不能由尺寸链给出** | 累加 / 分段相减 / 轴线±半厚**都是合法一档**，被这条判据表达不了 |
| **B2 返工 1**（同日早些） | 类是不是私有 | 同上 | 复核方**根本不用碰那个私有类**，公开 helper 会替它铸造 |

⭐⭐⭐ **有效解的形状（三次实测都指向同一族）**：
- **让那条路在类型层不存在**（B2：闭包持有的 mint 封印 + 载体不携带 z、消费时重新派生）
- **出口全检，⛔ 不是入口收窄**（T4-a：锁「**所有成功解析输入的集合 == live key 集合**」这个性质本身）
- ⛔ **已知无效**：往近错族里再加变形 · 再加一道类型钉 · 把那个具体反例串写进黑名单
  （= 把判据钉在缺陷的**一个实例**上）

⭐ **自查话术（本条的可执行形式）**：写完一条判据问自己
> **「我量的这个东西，和我要守的那件事，是同一个东西吗？还是它的影子？」**
如果答案是「它通常等价」，那就是代理量 —— 去找那个**能被换掉**的方向。

⭐ **配套派工纪律**（同日立、当天四次兑现）：返工单里**逐条写死已知无效解**，
并要求施工方交件必含三小节：①原路复现 ②**自己另设【两条】同形但不同的路径** ③声称与强制逐句对账。
⛔ 只做①②只证明「这个例子修好了」。

## ⭐⭐⭐ 2026-09-05：这条口径第一次被【正面证明】，而不是从失败反推

此前所有证据都是「某条判据被击穿 ⇒ 反推出它量的是代理量」。**B2 返工 3 的跨家族复核给出了正向证据**：
复核方**自己发明了五类攻击**（⛔ 未照抄施工方交件里的 7 条），结果是

| 攻击 | 入口封印（闭包令牌 + `__init_subclass__`）挡住了吗 | 出口全检（每次读取重新过门 + 从冻结字节解析）|
|---|---|---|
| `copy.deepcopy` + 直改 `__dict__` | ⛔ **没挡住**（deepcopy 走 `cls.__new__`，`__dict__` 直改也绕过 frozen）| ✅ 抓到漂移 |
| 直调私有 minter `m._mint_sealed_ladder` | ⛔ **没挡住**（普通模块属性，`getattr` 就能拿，**且铸造成功**）| ✅ 抓到 |
| `__class__` 重赋值 | ⛔ **没挡住**（`isinstance` 过，且**不触发** `__init__`/`__init_subclass__`/`__setattr__` 任何一个）| ✅ 抓到 |
| pickle 往返 | ✅（意外副作用：闭包内动态建类 ⇒ 根本不能 pickle）| —— |
| 原地改真实 artifact 的 `.bundle` | ⛔ 没挡住（pydantic 那里不是 frozen）| ✅ 抓到 |

⇒ **五条里三条把入口封印整个绕过去了，全部由出口接住。**
**这就是「入口收窄不属于有效解那一族」的直接证据**，⛔ 不再是推论。
⭐ 附带一条：施工方 docstring 写的「不能从模块外部被构造」**字面不严谨**（私有 minter 可外部调用并铸造成功）
—— **入口的声称几乎总是比它的实现宽**，而出口不需要这种声称。

⭐ **复核方法本身也被证明**：「⛔ 不许照抄施工方的探针，自己发明第三条」这条纪律，
在这一轮直接兑现成**三条施工方没想到的绕过路径**。

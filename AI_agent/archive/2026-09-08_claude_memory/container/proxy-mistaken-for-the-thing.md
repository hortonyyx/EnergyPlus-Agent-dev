**⛔ 判据：动手前问「我量的这个，是它本身，还是它的影子？两者什么时候会分家？」**

2026-08-18 一天，同一形状 **10 次**（全部由用户或既有锁抓出，非自查）：

| # | 我量的 | 它其实是谁的影子 | 分家点 |
|---|---|---|---|
| 1 | 要不要**新建**物理边界 | 边界对**真实威胁**够不够 | 现有边界（每 run 新目录 + 答案不在里面）本来就够 |
| 2 | **有没有** pilot 门 | pilot 门**守到什么程度** | 一轮就放行 ≠ 打到对为止 |
| 3 | 图片**尺寸** | **帧一不一致** | 恢复原尺寸 = 重开帧错位 |
| 4 | 坐标**像不像** | 有没有**真去量** | 猜对了也能过 |
| 5 | **侧车份数** | 有没有**重标定** | 它在自己 Python 里重算了 |
| 6 | 复刻 **07-07 那一次** | 恢复**重复出好成绩的形式** | 见 [[reproduce-the-form-not-the-run]] |
| 7 | 去掉 `--settings` | 去掉 **guard** | 那文件同时管**写权限** ⇒ 读图器一个文件没写成 |
| 8 | 「单独改它没效果」 | 「**它不是原因**」 | 组合型病因下，单变量测试**全部阴性**——11 个阴性正是它的指纹 |
| 9 | `891356d`（**记录**该 run 的提交） | 该 run **跑在哪棵树上**（`723b0f9`） | 差 +330 行 prescan |
| 10 | 「**不在仓库里**」 | 「**没法恢复**」 | npm 上 485 个历史版本全在；且本机 CLI 反而比 07-07 还旧 |

**代价**：每错一次烧掉一抽（30–60 分钟），**而那一抽的结果又被下一个错代理去读** ⇒ 复利。
四天 22 抽的大头在这里。

**⭐ 唯一有效的拦截**：三次被 [[verify-the-path-works-before-blaming-the-model]] 拦下
（差点写出「它不肯重做标定」「一次都没调工具」）——**以产物为准、不以 transcript/计数为准**。

**⭐ 结构性解法**（比记性可靠）：把判据交给**完整快照**而不是我挑的子集 ——
`git worktree` 而非手搓复现；读**当时的实验 README** 而非从产物反推。

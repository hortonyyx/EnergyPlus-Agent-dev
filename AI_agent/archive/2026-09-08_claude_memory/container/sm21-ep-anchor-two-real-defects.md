2026-06-10, diagnosing handoff §8.6 priority #1 (clean sm21 anchor on 0–5 pipeline). The handoff/CLAUDE banner blamed the EP failure on "本容器 energyplus 二进制 segfault（环境，非模型）". **That conclusion is wrong** — verified the EP 25.1.0 container binary runs a minimal hand-written IDF fine; the sm21 IDF (`test_data/SmallOffice_TwoStep/smalloffice_21/output_step8_e2e/temp_*.idf`) segfaults for two **real model defects** on our side:

**Defect 1 — segfault root cause = incomplete Schedule:Compact.** Schedules that cover only Weekdays/Saturday/Sunday/Holidays but omit `For: AllOtherDays` (i.e. no design-day / custom-day coverage) make EP 25.1.0 *segfault* during GetInput instead of emitting the normal "missing day types" severe. Isolated by bisection: `Office_People_Number/Lights/Heating_Setpoint/Cooling_Setpoint/HVAC_Availability` all crash; the complete ones (`Office_Activity`=AllDays, `Office_Weekend`/`Office_Workday`=have AllOtherDays) don't. Adding `For: AllOtherDays` to each removed the crash. → **fix belongs in 4_MEP authoring rule** ([skills/intake_pipeline/4_mep/authoring.md]): every Schedule:Compact must fully cover all day types (emit `For: AllOtherDays` or use `AllDays`).

**Status of Defect 1 (2026-06-10): hardened + gated in code.** (a) Skill rule [skills/intake_pipeline/4_mep/authoring.md] hardened with ✗/✓ example explicitly calling out that `Weekdays`+`Weekends Holidays` is NOT complete. (b) **New deterministic pre-EP gate** [src/validator/schedules.py] `validate_schedule_completeness(idf)` wired into [src/mcp/tools/workflow.py] `_check_schedules` alongside the interzone gate (both `export_idf` + `run_simulation` paths) — converts the segfault into precise "Schedule:Compact X incomplete: day type(s) [...] uncovered" issues before EP. 9 tests [tests/test_schedule_completeness.py], 61 total green. Verified it catches all 6 incomplete schedules in the stale step8 IDF. (Note: a prior same-day session had already added the prose rule + flagged the downstream schedule subagent — see [AI_agent/logs/downstream_agent_changes.md] 2026-06-10; my pass added the code gate.)

**规则**：每条验收锁必须
① **经过真实入口**（CLI 命令函数 / 真实调用者），⛔ 不许直接给内部函数喂构造好的参数；
② **断言落在具体 check-id 行 + 落盘产物的头部字段**上，⛔ 不许落在「返回值存在 / 总数变了 / 不是 None」；
③ 配 **neuter 自查**：摘掉它唯一对应的实现 hook ⇒ **恰好红它、零连带** ⇒ 恢复工作树。
**「锁绿」≠「锁真绑」——只有摘得动才算数。**

## ⭐ 2026-08-07 新增一类：**恒等锁 ≠ 正确性锁**

F-13 r1 的「内核产出喂过校验器后逐面逐顶点不变」是一条**恒等锁**。
orchestrator 换方向 neuter（**调用点全留、只让规范化挑错角**）时它**依然绿** ——
因为内核与校验器用的是**同一个**函数，一起挑错角时「两边一致」照样成立。

> **恒等锁证明的是「两套规范已统一」，⛔ 不证明「这套规范是对的」。**
> 守正确性的必须是**「断言等于手算值」**那类锁（例：断言首顶点确实等于手算的左上角坐标）。
> **两类锁职责不同，⛔ 不许当成一条用；设计锁时要问：这条锁在两边一起错的时候还红不红？**

## ⭐⭐ 2026-08-10 新增一类：**结构上恒真的断言**（比恒等锁更隐蔽，且我在轻门里漏判了）

F-20 施工席的验收项写「两个 golden 正基线的 `blocked`/`blocking_summary`/**`digest`** 逐字节相同」，
用的是 `git archive` 取修前快照对比 —— **姿势完全正确**。
**但那两个基线的 `geometry_digest` 修前修后都是 `None`** ⇒ **`None == None` 恒真**
⇒ **「历史几何批准不失效」这条性质根本没被验到**（`blocked` 那两维仍有效）。

**⛔ 我（orchestrator）在轻门 v1 里把它写成「一次有效的人工验证」，是漏判**；
是派 GPT 侧补锁时执行席按合法退出口停下上报「没有可冻结的值」才炸出来。
**与 08-09「我只观察到症状、没诊断出原因」同族。**

⇒ **新判别问法（对每一条相等断言都要问一遍）**：
**「这两边有没有可能【都是空的】？如果都是 None / 空集 / 空列表，这条断言是不是恒真？」**
同族弱谓词已收集到四种：`is not None` · 「总数变了」· **恒等锁**（两边一起错照样绿）·
**空比空**（本条）。
⇒ **横扫一批锁时，把「找出结构上恒真的断言」列为独立一问**，别只找「摘掉实现还绿的锁」。

⭐ **配套正例**：修法 = 找一个**真的产出该值**的锚点把它**钉成源码字面量**
（F-20 实测：全仓 `case_tests/e2e_tests/**/run_*` 里**只有一个** run 能产出非空 digest）
+ **必须用 neuter 证明这把新锁会红**（已实测转红）。

## ⛔ 2026-08-10 运维：`nohup … &` 套在 harness 后台里 = 进程丢失，且退出码来自包装器

同一轮实犯三次：全量跑到 51% / 97% 被掐断，**`.rc` 文件根本没写出来**（= 进程被杀，不是 pytest 失败），
而外层「退出码 0」是 **nohup 包装的**、不是 pytest 的 —— 与 08-09 那条
「`pytest | tee | head` 的退出码其实是 `head` 的」**同一个病**：**观测到的退出码不属于被观测的命令。**
⇒ **纪律**：① 后台跑用 harness 自己的后台机制，⛔ 不要再叠 `nohup`/`&`；
② **判据永远是「汇总行 + 属于该命令的 `.rc` 文件」两者俱在**，⛔ 缺一不可；
③ 跑全量期间**不要并跑 neuter 等重活**（本轮把自己挤断过一次）。

⛔ **同轮我自己又差点记错一条**：本条初稿写「`.rc` 缺失本身就是【进程被杀】的确证」——**错**。
`.rc` 缺失只说明**「没跑完」**，可能是**被杀**，也可能是**还在跑**（进度日志有缓冲、看着像停住）。
实测：一次「停在 51%、日志 1438 字节」的跑，`pgrep` 一查**7 个 worker 全活着**、内存还剩 11 GB。
⇒ **判活必须查进程（`pgrep`）+ 内存，⛔ 不许拿日志字节数或进度百分比当哨兵**
——又一次「用错哨兵判据」，与 [[interface-sweep-gate-vs-range-check]] 的「非 None ≠ 成功」同族。

配套：**验一个「已被代码规范化」的东西，必须用那段代码自己的定义**——
orchestrator 用俯视直觉判「左上角」，把 18 个楼板误判为不合规
（**楼板朝外法向朝下，"从外面看"是从下往上看**）。自己临时想的几何判据零分辨力。

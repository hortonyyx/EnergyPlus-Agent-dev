**用户 2026-09-02 原话**：「**正交、画法的泛化哪些不着急呀，因为还没解锁哪些，考虑到未来的可升级性不代表现在就需要落实，只要别做成没办法升级的就行。**」

**起因（我实犯）**：用户先纠我「别把方案特化到现有几个 case（墙厚会变，模数以后进 harness）」；我落口径时**用力过猛**，写了「非正交输入必须响亮拒绝」——而今天**根本没有非正交输入**（gt 转换器把歪线都吸平了）⇒ 那是一条**空防御**，正是 [[research-first-p0-is-speed-not-completeness]] 要砍的东西。

**⭐ 判别法则（替代「以后要支持吗」这个问法）**：
> **「以后要松动这个假设时，是改一处，还是要翻遍全仓？」**
> 答「改一处」就够了 —— **⛔ 不必现在把那一处改对，也不必现在写它的分支。**

**分档（投影桥那次的实例）**：

| | 现在做不做 |
|---|---|
| 尺寸不写死常数（尺子从数据里取，如「对方墙自报的半厚」）| ✅ 现在就做 —— 零成本，不做就是特化 |
| 夹具不许只用现有 case 的墙厚（要 90/150/300/370 混排）| ✅ 现在就做 —— 便宜，是「别特化」的直接兑现 |
| 非正交 / 别的画法方言**能力** | ⛔ 不做（没解锁）|
| 非正交的**拒绝路径 / 泛化分支** | ⛔ 不做 |
| 让假设**局部化、有名字、可替换** | ✅ 现在就做 —— 这才是「别做成升不上去的」的全部含义 |

**Why**：[[building-complexity-extensibility-principle]]（不变量 #6）说的是**别烤死**，⛔ 不是**现在就泛化**；我把两者读成了一件事。空防御既烧工期，又制造「看起来考虑周全」的假象。

**How to apply**：落任何几何/尺寸相关决策时分三样 —— **规则**（尺子从数据取，可进算法）· **前提**（某画法下才成立，显式命名+局部化）· **读数**（这个 case 的数，⛔ 永不进算法也不进验收）。只有「尺寸不写死」+「假设局部化」这两档是现在的义务。落 `guides/reading_correction_split_guide.md §十三`。

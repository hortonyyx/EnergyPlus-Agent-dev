**2026-08-06 实犯 + 兑现**：昨天把 F-12 登记成「下游把墙建错了、违反几何铁律」。用户问「**之前不是端到端跑通过很多次吗？之前没有这几个问题吗**」⇒ 拿 **07-02 那次真跑到 EP 的 run**（既有 `5_intakeoutput/intake_output.json` 又有 `EP/*.idf`）做**内核 vs 最终 IDF 逐面对账**，零 LLM 成本、只读、五分钟：

```
100 面：逐顶点一致 11 · 不一致 89
  89/89 = 循环旋转（同一多边形、绕向不变、法向不变、EP 等价）
   0    = 绕向反 ·  0 = 坐标真的不同
```

⇒ **那次几何其实是对的**，偏差是纯「起笔点不同」`(A,B,C,D)→(D,A,B,C)`。**定性当场从「建错了」降级为「没有逐字转录」。**

## 两种潜伏机制，⛔ 别混为一谈

- **A. 一直有偏差，但没有尺子在量**（F-12）：drift 门代码 07-14 才写、08-06 才接进链路，且**只在产物带冻结快照时才比**（无快照整段跳过）—— 全仓只有今天这个 run 带快照。⇒ **不是新坏的，是第一次有人量它。**
- **B. 一直是坏的，但没东西跑到那一段**（F-10 断一个月）。⇒ 见 [[probe-past-the-blocker-to-find-hidden-walls]]。

## 可复用的判别动作

1. **新门第一次报红，先问「这门什么时候接上的、以前的产物有没有喂过它」** —— 别默认红=新坏。
2. **历史跑通产物 = 免费的回溯尺子**。只要同时留下「内核产物 + 最终 IDF」，就能零成本量出历史真相。⇒ 与 [[probe-past-the-blocker-to-find-hidden-walls]] 同源：老产物是资产。
3. **「顺序不同」必须再分一层**：循环旋转（法向不变，EP 等价，无害）vs 绕向反（法向翻转 ⇒ 内外面反转 ⇒ 窗挂错房间，有害，见 [[symmetric-evidence-cannot-prove-direction]]）。⛔ 只说「顺序不一样」等于没说。
4. **门保持逐位严格是对的**，⛔ 别加「循环旋转视为等价」的豁免 —— 那会同时放过绕向反。修法应落在**让上游忠实照抄**，不是放宽门。

## 给 orchestrator 的

**用户对「这跟历史不符」的直觉，值得每次都当场用数据兑现** —— 这次五分钟的回溯改写了一条已落库的定性。⛔ 不要用「以前没这个门」这类解释打发过去，去把那次的产物真的量一遍。

**2026-08-30 一天栽两次，两次都是把【别人量的数】当成【已经验过的事实】写进了承重位置。**

1. **把叙述当成拓扑条件**：复核方裁决书写「`exterior ring ≠ 1` = 多栋楼图纸；**sm24 就是两栋楼**」，
   我照抄进派工单当**验收项的承重前提**。施工方停下上报，实测 sm24 是**单个 `Polygon`、1 个 exterior ring**。
   我自己复查后确认它对 —— 「两栋楼」是**叙述**，`exterior ring ≠ 1` 是**拓扑**；
   两个 block 相连时 `unary_union` 出来仍是**一个** polygon。**⇒ 派工方题错 #49。**

2. **拿不完整的复现去收窄别人的结论**：复核方报三个静默形态，我跑它留的 probe，
   发现其中一个「被抓住了」，于是写下「裁决书这行说错了」+「缺锁的只在 facts 那一侧」。
   **是我读错**：那个 probe 里根本**没有** E2c 变体（它是平移 50 m，probe 只有 5 m / 同位）。
   补跑后 E2c 逐位复现静默 ⇒ **三个形态全属实、两侧都缺锁**，处方是**双向**全集对账。

⭐ **为什么值得单独记**：这两次我都**不是量错**，是**根本没量**——
第一次直接转引，第二次量了个**近亲变体**就当量过了。

**⇒ 硬规矩**：
- **凡要写进承重位置**（派工单的承重前提 / 验收项 / 送用户拍板的材料）**的事实，自己跑一遍**，
  ⛔ 不管它出自多可靠的裁决书。**转引可以，转引而不复核不行。**
- **复现别人的结论时，先核对「我跑的变体 == 它报的变体」**；
  近亲变体给出的不同结果，**不是反驳，是我跑错了题**。
- ⭐ 反过来同样成立：复现失败**不等于**对方错——2026-08-30 另一例中，复核方的探针选得不好（伪造把墙压坏 ⇒ NA），
  我**换了个探针**才发现真实代价比它报的**更重**。⇒ [[neuter-proves-wiring-not-discriminating-power]]

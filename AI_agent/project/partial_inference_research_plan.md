# 部分推理建模研究计划

2026-09-10。用户确认本研究可与还原建模主线并行。本页安排研究问题、样本、验证与共享能力。阶段 1 已准备真实 Voimatalo 单体和 `sm24` 只给四立面的受控缺信息输入；主工作树已用后者生成首份部分推理 BIM：1 个合并空间、11 窗、3 外门，几何检查通过，内部推断真实性未验证，[工具辅助恢复](../logs/experiments/2026-09-10_partial_inference_sm24_run02/README.md)实际接通逐面回查，但仍未修正一扇窗的0.48米偏移。Voimatalo完整UV页与简化BIM均已离线浏览器查看并旋转验证，真实体量到BIM尚未运行。复杂度只确定为对实际建筑空间的简化/合并程度，不固定档数、滑块、各档对应关系或合并算法，详细产品设计在实验后展开。

统一分类见 [产品目标](goal.md#按信息充分程度划分建模任务)，数据获取证据见 [带贴图体量调研](../design/textured_mass_route.md)，主线见 [还原建模计划](drawing_reconstruction_plan.md)，实际进度见 [当前任务](roadmap.md)。

## 研究对象与边界

部分推理建模已有一部分可用的建筑事实，仍需推断重要缺失部分。近期从单栋带贴图三维体量入手，允许补充局部图纸、尺寸、建筑用途和用户说明；只有不完整图纸的任务也可属于这一类。贴图体量是首个研究入口，不定义整个类别。

只处理目标单体，优先普通办公、住宿和商业，不重建周边环境；复杂公共建筑后续特化或明确简化。产物是各后端共用的轻量 BIM，用户无需先选择模拟插件。分块按实际隔墙形成的空间理解，低复杂度可直接推断合并后的表达；最细也不能将真实开敞空间按朝向或功能凭空切块。信息充分程度、输出简化程度和后端计算粒度分别考虑。

完全推理建模纳入共同概念和接口考虑，本研究不同时启动仅凭参考图片或概念文字生成整栋的独立实验。完整停点编辑、热工物性、EP 或其他模拟跑通均非本轮研究前置。生成中缺信息可交互补足。

## 要回答的问题

1. **外部已知信息能转成多少可用建筑约束？** 验证尺度、外形、楼层、门窗及局部变化；区分网格几何、贴图观察和推断，避免把可渲染外壳当成可直接使用的空间模型。
2. **缺内部资料时，能否生成合理、自洽的空间组织？** 按用途、进深、入口、楼层和外立面线索推断可能的实际分隔，允许明确假设；开放办公、独立隔间及跨层变化分别检验。
3. **补什么信息最有效？** 比较增加一张局部平面、一个已知尺寸、标准层/用途说明后的变化，检查相关假设是否更新、已知信息是否保留。问答发生在生成中，不依赖停点编辑。
4. **怎样在不同简化程度下仍交付同一通用 BIM？** 检验能否直接生成较粗表达并说明合并范围，以及少做合并时是否更充分保留实际空间。复杂度的具体控制方式和默认值留待这些结果支持。

## 案例安排

先取得一个可运行的真实单体，再逐步补代表差异，不以凑齐一整套数据集为首例前置。两类证据互补：

| 案例来源 | 当前状态与下一步 | 能回答什么 |
|---|---|---|
| 真实带贴图单体 | 已从 SUM / Helsinki 的 `Tile_+1984_+2690` 按公开轮廓裁出 Voimatalo；办公/沿街商业用途有 Helsinki 市博物馆依据，保存米制 GLB、完整 UV 离线页、面中心采色范围预览、来源/变换和未闭合缺口。它是受保护历史办公楼，首例不代表随机普通办公形态 | 实景几何噪声、贴图线索与缺失内部条件下能否产出可用 BIM |
| 已有案例的受控缺信息版本 | 已制作 `sm24_exterior_only`：只给四向立面和深圳/办公/一层/约 200 m²，不给唯一平面、房间数、GT 或旧答案；首轮生成与一次工具辅助恢复已完成，内部未知且整层合并，仍有一扇窗错位 | 同栋建筑增加或减少信息对生成的影响；与独立完整参照比较 |

真实瓦片只作素材池。确认单栋范围、建筑类型、尺度依据、贴图可读性和原件来源；缺失信息按问题或假设记录。不要仅凭外形独立就指定此前 `Tile_+1985_+2693` 的主体为普通办公。若现有池没有合适目标，再查已核实的 Helsinki 单体来源或 Melbourne 数据，不为一栋楼下载整库。获取事实与许可边界沿用调研文档，新增获取时再核实。

受控缺信息版本的完整资料留在评价侧，生成只拿到显式提供的子集；后续补图是另一项明确实验条件。已有错误候选不能当作真值，熟悉过的 sm 案例也不能当作未见泛化样本。若从人工模型制作外壳或贴图，明确记为合成对照，不能冒称实景扫描。

首例之后优先补的差异是：有可靠依据的开放办公布局、有实际隔间的住宿/办公，以及首层与标准层不同的普通建筑。先核实资料能证明什么，不从外部网格宣布内部已经确认；无内部参照的真实样本只评价推断合理性，不报告真实房间恢复率。两个已下载的人工模型继续作为导入工具对照。

## 推进顺序与阶段产物

下面是研究工作安排，不是产品必须执行的固定流水线或 Agent 数量。准备与受控对照可以交错推进，首份可查看 BIM 不等待复杂度界面或完整多模态平台。

| 阶段 | 工作重点 | 可查看或可核对的产物 / 完成依据 |
|---|---|---|
| 1. 准备单体与参照 | 选一个真实目标，裁出纯输入；另准备一个已有案例的缺信息对照 | 单栋输入、贴图查看、来源/变换/尺度与缺口记录；对照的生成输入和评价资料清楚分开 |
| 2. 外部约束与首份 BIM | 提供带空间对应的整体/局部视图，利用外壳和可见线索，直接推断一种适当简化程度的内部方案 | 独立 run 中实际保存源 BIM、楼层/三维查看、几何检查、已知信息与假设；先取得结果再按失败定位工具缺口 |
| 3. 生成中补信息 | 对同栋楼加入局部图纸或用户回答，记录补充前后方案与受影响对象 | 能看到哪些假设被证据替代、哪些空间需要重建；实质冲突可见，未相关的可靠信息没有无故改变 |
| 4. 比较信息与简化程度 | 固定简化意图比较输入条件；固定输入再试不同简化意图，补开放空间和实际隔间对照 | 独立实验与并排查看；说明信息增益、源合并是否合理、是否出现假隔墙，而非仅统计块数 |
| 5. 扩展样例并收敛设计 | 用另一类建筑或采集质量复核前述发现，整理共性能力与失败 | 给出可复用范围、不能支持的情况、下一轮工具/模型改动；此后才展开复杂度控件、合并规则及接口细节设计 |

阶段 2 的最短技术依赖是单体读取、空间位置可回查的观察、源方案生成、检查与显示。可以先由开发助手准备目标和确定性视图，明确记为辅助准备；随后让产品 Agent 自主选择观察、推断、提问及修订。开发助手直接写内部方案的结果只算内核诊断，不算产品生成成功。

如首例遇到内环、非正交或跨层空间，按真实需求补共同几何能力或明确有依据的简化；不能通过多造隔墙、堵内院或加假楼板迎合现有接口。保留已有可查看成果及具体缺口，不用无关全量重跑代替定位。

## 对照与评价

| 对照方向 | 控制条件与观察内容 |
|---|---|
| 几何 vs 几何 + 贴图 | 同一目标、尺度、简化意图、模型配置和预算，观察贴图对楼层/门窗及内部约束的增益 |
| 现有输入 vs 加局部图纸/说明 | 同一目标和简化意图，比较新增信息涉及的对象、假设、冲突与人工投入 |
| 固定输入、不同简化意图 | 比较实际分隔的保留和合并；不强制两档或三档必须产生不同块数 |
| 独立生成 vs 生成中问答 | 分别报告输入条件、补充内容、结果和总投入；辅助结果不充作无交互成绩 |

这些是待选择的实验，不要求首批完成全部组合。先围绕首例最大不确定性做最短对照，再按结果扩大。外部观察、内部推断、源简化、几何可用性分别评价：

- **已知信息是否守住：** 外形、楼层、主要开口及给定图纸关系是否一致；实质偏差定位到对象和证据。
- **空间是否合理：** 分隔是否有观测或明确推断依据、是否错误切开大开敞空间、跨层变化是否合理；相邻与门/开口连通分开核对。
- **几何是否可用：** 闭合、体积、覆盖、重叠、开口宿主和显示一致；环绕核心筒的一个空间不能因计算分片变成多个物理房间。
- **简化是否符合意图：** 合并范围和省略细节可解释；不能以用户选低复杂度掩盖错误，也不能要求低档逐间复刻参照。现有逐房比较器需要明确适用条件，未适配前不直接套用判定。
- **信息补充与投入：** 保存关键问题、回答、假设变化、未解决项、模型实际用量、耗时和人工参与；不以主观精度百分比或块数增加证明改善。

对有独立参照的样本比较实际格局；对无参照的内部只报告约束一致性与合理性。新增细节是否改善具体模拟属于后续后端评价，不反过来定义源复杂度，也不作为本计划首份 BIM 的验收门槛。

## 与还原建模主线怎样并行

| 工作范围 | 各自推进与共享边界 |
|---|---|
| 还原建模主线 | 继续 sm21/sm24/sm25 原图保真、开口/分区及恢复实验；Claude 恢复入口按当前交接执行 |
| 部分推理建模研究 | 独立准备单体与缺信息案例、观察工具、内部假设和补充信息实验；不等主线所有案例成功 |
| 共同能力 | 共用总 Agent 的工具调用方式、源 BIM、几何内核、来源/假设、查看与评价基础；按实际缺口小步集成 |
| 完全推理建模 | 保留同一底座和输入扩展方向，具体研究计划后续单独展开 |

可复用的实际入口是 [总 Agent 实验](../../scripts/tool_scripts/run_bim_agent.py)、[直接方案导出](../../src/agent/execution/source_proposal.py)、[共同源内核](../../src/agent/geometry/source_bim.py) 与 [查看器](../../scripts/tool_scripts/render_geometry_viewer.py)。现有 Agent 主要面向二维原图，尚无通用贴图网格观察和部分图纸融合入口；直接方案导出也有单外环、正交等限制。复用这些代码不等于新任务已跑通，具体能力见 [模型](../design/model.md) 和 [系统设计](../design/architecture.md)。

同一 main 集成公共接口；需要同时施工时，输入工具和案例各自明确文件范围，源 schema/内核改动成小提交及时共享，不复制三套管线，不建长期分叉。各实验独立 run，保留原始输入和旧结果，按共同改动影响复用或补相关检查。

产品运行从首批实验纳入目标档能力，Sonnet 级为上限；开发与调用授权见 [模型与费用](../workflow/models.md)。额度不可用时先做选材、几何准备和离线工具工作；不探测或自动切到未获本批许可的 DeepSeek，不因等待模型而把计划写成已完成实验。

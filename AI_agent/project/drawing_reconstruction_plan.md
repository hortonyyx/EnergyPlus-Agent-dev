# 图纸重建：相对精准建模推进计划

2026-09-09 修订。状态：已按用户“定性大于定量”的纠偏回看历史成功案例与 gate/judge/GT 接线，实施实验尚未开始。本版取代同日初稿中人工逐对象核对和误差统计优先的安排。
本批按用户要求优先推进两条路线中的图纸重建；体量推断暂不排入本批施工。产品范围仍以 [目标](goal.md) 为准。

## 本批结果

让完整平面、立面和输入声明，经可复现的读图、容差校正和确定性建模，得到正确、可查看、可修改的轻量 BIM，并由 judge + GT 自动说明效果。使用 sm21、sm24、sm25 三个案例：sm21 复用已成功的基本链路，sm24 覆盖非矩形及表示差异，sm25 推进多层复杂图纸。已有历史 EP 成功链可直接作为资产，不从零重建出口。

“相对精准”首先指建筑的尺度、房间、隔断、门窗与空间关系正确，几何自洽可用。允许图纸/CAD 的细小噪声经容差规整成为干净模型；GT 也可由原始 CAD 自动派生规整参考。标注、量测和推断分别记录，量化仅辅助诊断，具体原则以 [验证与评价](../design/evaluation.md) 为准。

现有项目库都是可选资产：优先复用已有效的代码、工具、样本和实验结论；旧 schema、流程与检查如不适配目标，查清消费者后调整。不以维护全部历史流程为本批交付条件，也不提前重写整套系统。

## 实施顺序与交付条件

### 1. 三案例自动评价基线与容差实验

复用三案例历史模型、judge/GT 结果、查看器和报告，在新 run 中重放必要部分。优先自动判断外形、楼层、房间、门窗与空间关系，并输出可定位的异常；只有匹配歧义或证据冲突才人工抽查，不逐房手工重建一套答案。

以三案例做最短对照：不改变建筑意图的小扰动应保持定性结论；漏房间、错宿主、错楼层或明显比例错误应被检出。由误报定位需要修改的输入规整、GT 派生或 gate/judge 消费者。sm25 的 27/29 和 sm24 历史 11/8 都按源房间关系与派生分区解释，不只凭数量定错或补造对象。

**交付**：三案例已有产物的可视入口、自动定性报告及少量具体规则调整；详细误差附在异常证据中。可用、有轻微问题、不可用与评测不完整明确区分，求解器阻塞不自动否定建筑模型全部用途。

**完成依据**：小扰动不会无端变成严重失败，真实结构错误不会被放宽容差掩盖；改动走通实际消费者与报告。无需先修完所有历史检查，也不以 GT 全部顶点精修结束为完成条件。

### 2. 接通原始图纸到 reading 的最小入口

选三案例中一张代表平面和一张立面做目标档模型实验，再按成功资产最易贯通的案例跑完整链路，并推进 sm25 六视图。最小入口复用现有隔离执行和量测工具，接到 `flow` 前端或增加薄驱动层；各 run 保留原有 0–5 阶段语义、自动检查和 judge 记录。

模型负责视图/图层角色、尺寸语义、房间和开口识别、候选选择以及冲突解释；代码负责裁图坐标变换、量测、约束求解、切配与装配。对已有工具覆盖不到的图式，允许模型换工具或报告局部未解决项，不强制所有图纸都走同一套颜色/墙线规则。

**交付**：从本次原始输入启动的命令、实际模型配置和调用记录、全部视图观测、标定/来源和问题说明；有效输出可继续校正并生成查看模型。

**完成依据**：不手填答案坐标、不借用旧 reading 或 case 感知配置生成此次观测；单图成功后至少完成一次 sm25 整案尝试。失败也保留部分输出，但六视图和模型未贯通时本阶段不宣称完成。人工帮助另开辅助结果记录。

### 3. 按实质错误修几何，补最小源模型

依次处理尺度/方向/楼层，房间及外形，隔断和门窗，空间相邻与实际连通。用自动报告定位识读、校正、装配与显示错误，每次只改影响建筑正确性或用途的环节。小偏差可在证据和拓扑支持下规整；无实质影响的残差不继续追到逐点重合。

以 `CorrectedGeometry`、`BuildingGeometry` 和现有来源字段为基础，用必要字段或薄转换层保留稳定源房间/隔断/开口 ID、宿主、两侧空间、参考面及假设。生成的 Z 编号和切配面不能替代源对象身份。门和未填充开口先具备位置、宿主和连通语义，无需先做全实体墙。

约 65 mm 短边仅作为当前阻塞样本：优先检验是否能在用途容差内规整、得到正确且自洽的模型。需要改变 [InterZone 校验](../../src/validator/interzone.py) 时做最小消费者/EP 验证；真实错层关系保留或有记录地做用途简化。不把这一次偏移的 CAD 微观成因彻底考证或原坐标精确复现设为前置。

**交付**：sm25 冷启动生成的几何、源对象关联、质量说明和剩余不确定项；重大错误有对应的局部行为验证。

**完成依据**：自动检查/judge 判断源房间与主要隔断开口保留、楼层/外形/拓扑正确、尺度处于用途容差内；已知缺失不静默掩盖，轻微偏差可带提示交付。证据不足时明确范围，不冒充全部正确。

### 4. 三案例回归与一次真实编辑

固定工具和入口，按影响对 sm21/sm24/sm25 做回归与冷启动尝试，自动报告实质错误、轻微偏差和人工投入。三者都是既有案例，不能据此宣称新图式泛化；不重复同版本、同范围的有效结果。

同时选一个窗口移动作为首个修改动作：用户选对象并给出位移 → 更新源开口 → 确定性重建相关几何/宿主 → 检查并保存 → 重新打开仍能看到修改。复用现有查看器，按实际部署选择本地服务或可导入导出的补丁。第一次可用明确参数动作，随后自然语言解析复用同一个动作接口。

**交付**：三案例覆盖范围及定性对比记录；一个可持久化、可撤销的开口编辑闭环。

**完成依据**：案例结果可查看且由自动报告说明已验证范围；编辑改变权威源对象，重新生成后仍有效，失败不破坏此前模型。墙推拉和完整自然语言编辑排在这一闭环之后。

### 5. 复用成功下游链并接通本批几何

对已检查的 sm25 几何，接协作者物性及现有下游接口，先按房间一对一区域派生，完成 IntakeOutput → IDF → EP。复用阶段 3 的短边实验结论，检查覆盖、开口、构造和边界，不为仿真通行丢弃源信息。

**交付**：可追溯的仿真输入、运行结果、失败/警告说明和几何派生差异。如比较生成/参考几何，挂同套物性并明确比较的是供冷/供热需求等量。

**完成依据**：选定配置的实际 EP 运行成功，几何与输入来源可回查；运行成功与重建准确性分别报告。协作者接口缺口只修实际对接所需部分。

## 用实验决定什么

| 不确定问题 | 最小实验 | 结果影响 |
|---|---|---|
| 自动评价是否抓实质错误而容忍噪声？ | E0：sm21/sm24 成功产物、sm25 阶段产物，加局部小扰动和真实错误对照；量级先试 1/5/10 mm，厘米级按对象和语义适用性再试 | 定位具体规整/评分/gate 消费者；这些是实验取值，不是全局吸附阈值 |
| 目标档模型能否自行完成量测所需准备？ | E1：一张平面＋一张立面，各用目标档和 Sonnet 级配置做一次无答案尝试；记录工具/人工/耗时，仅在结果不稳定时复跑 | 选择读图配置和修复策略；不能只凭合法 JSON 判断成功 |
| as-drawn 固定流程是否适合自动读图？ | E2：仅在 E1 暴露适配问题时，同一问题视图比较现有流程与模型选择现有工具的方式，其他条件固定 | 决定局部复用、薄接线或替换；不先做庞大模型×流程全组合 |
| 小差异如何得到正确且可用的模型？ | E3：sm25 短边局部样本的原表示与容差规整对照，核查房间/开口/覆盖；改变出口规则时做 EP 最小验证 | 决定规整、局部转换或检查调整；不优先研究如何保住全部原始微小错位 |
| 修复能否贯通和迁移？ | E4：sm21/sm24/sm25 受影响的重放或冷启动整案 | 自动评价是否保持正确结论、实际出口是否恢复；运行方式分别报告 |

E0 先行，E1 不等待 E3 全部解决。局部实验通过后尽快到整案；若相同阶段重复失败且没有新证据，暂停整案重跑，回到最短样本验证假设。每轮保留独立输入、命令、配置、输出和失败原因。

目标档（可本地部署级/Flash 级）从 E1 参与，Sonnet 级为产品运行上限，开发助手不替产品补答案。具体 ID、视觉能力和通道使用前核对；优先使用已授权的订阅做开发探索，明确订阅实验与产品 API 接线的区别。不能默用付费 API 或自动回退到 DeepSeek，权限按 [模型约定](../workflow/models.md) 执行。

## 每轮怎样验收和选择下一步

- **定性结论**：优先自动判房间/外形/楼层、隔断开口、相邻连通及用途可用性；实质问题附对象证据，轻微偏差带提示，不看总分替代这些结论。
- **量化辅助**：自动提取整体尺度、面积/体积、开口量级及定位异常所需的残差。中位数/P95/逐点误差仅在诊断需要时展开，不作为首批交付清单或独立追分目标；源房间与派生热区数量分别解释。
- **关系与有效性**：楼层归属、隔断两侧、窗宿主、相邻与门洞连通；闭合、自交、配对、应有覆盖分别检查，当前 NA 项不算完成。
- **投入**：记录完整/部分/失败尝试数、实际模型与调用次数、可得 token/费用数据、墙钟时间、人工补充内容/次数/时间。订阅没有准确单次账单时不编造费用；少量样本不给稳定成功率结论。
- **验证范围**：局部代码用相关离线检查，阶段接口增加一次真实产物贯通；文档只查 diff/链接。历史重放、冷启动、人工辅助和 GT 内核诊断分别呈现。

详细评价边界见 [验证与评价](../design/evaluation.md)。

## 紧接本计划的首个工作包

1. 用 sm21/sm24 历史成功和 sm25 阶段产物做 E0，复用自动报告；找到一个因细小噪声误报、或容差规整缺失而阻塞的实际消费者，做最短修正并验证真实错误仍被检出。
2. 接通既有读图/flow/judge 的运行接缝，选定 E1 视图和两档可用配置；正常效果由自动评价给结论，人工只处理未能裁决的异常。
3. 交付可查看的真实模型和定性结果，推进完整 case；门窗/空间关系、编辑和后续 CAD 输入按实质缺口补齐，不转回 GT 精修工程。

本批不把体量适配、任意混合输入、全实体 BIM、全套编辑器、热区优化、全面缓存优化或历史债清零放在上述结果之前。出现可查看输出和实验结果后更新下一工作包，不预排大量依赖未知结论的细任务。

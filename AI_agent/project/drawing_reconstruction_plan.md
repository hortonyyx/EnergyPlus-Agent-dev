# 图纸重建：相对精准建模推进计划

2026-09-09。状态：已完成资产核对与计划梳理，实施实验尚未开始。
本批按用户要求优先推进两条路线中的图纸重建；体量推断暂不排入本批施工。产品范围仍以 [目标](goal.md) 为准。

## 本批结果

让完整平面、立面和输入声明，经可复现的读图、校正和确定性建模，得到可查看、可定位问题、可修改并保存的轻量 BIM。先以 sm25 为主案例，再以 sm24 检查迁移表现，随后贯通首个 EnergyPlus 出口。

“相对精准”指尽量恢复输入有证据支持的尺度、房间、隔断、门窗与空间关系。标注尺寸、像素量测、默认值和推断分别记录；首轮先实测误差，不预先承诺统一毫米精度或一个未经校准的总分。

现有项目库都是可选资产：优先复用已有效的代码、工具、样本和实验结论；旧 schema、流程与检查如不适配目标，查清消费者后调整。不以维护全部历史流程为本批交付条件，也不提前重写整套系统。

## 实施顺序与交付条件

### 1. sm25 可视基线与信息去向

从已有 `run_win_e2e` 读取产物，在新 run 中生成离线 3D、分层平面及问题定位图。按原图逐房建立“输入空间 → reading → 校正 cell → 生成区域”的对应；窗、门和可见隔断同步登记，区分已建模、合并、待识别、缺失和明确不适用。

先解释 27/29 差别属于输入口径、识读遗漏还是后段改变；不按总数补造房间。GT 的对象匹配与几何比较在评测侧进行，后续冷启动读图不能看到该对应表或答案。

**交付**：可打开的模型、逐对象去向表、误差初测、按阶段排序的少量阻塞。即使仿真检查失败，已生成的几何也能查看，并明确标为诊断产物。

**完成依据**：每个核对到的源空间和开口都有去向或明确问题；给出冷启动所缺的输入/调用步骤。此阶段完成只表示基线清楚，不表示重建已正确。

### 2. 接通原始图纸到 reading 的最小入口

先做一张代表平面和一张立面的目标档模型实验，再扩到 sm25 全部六个视图。最小入口复用现有隔离执行和量测工具，接到 `flow` 前端或增加薄驱动层，具体接法由兼容性实验确定。

模型负责视图/图层角色、尺寸语义、房间和开口识别、候选选择以及冲突解释；代码负责裁图坐标变换、量测、约束求解、切配与装配。对已有工具覆盖不到的图式，允许模型换工具或报告局部未解决项，不强制所有图纸都走同一套颜色/墙线规则。

**交付**：从本次原始输入启动的命令、实际模型配置和调用记录、全部视图观测、标定/来源和问题说明；有效输出可继续校正并生成查看模型。

**完成依据**：不手填答案坐标、不借用旧 reading 或 case 感知配置生成此次观测；单图成功后至少完成一次 sm25 整案尝试。失败也保留部分输出，但六视图和模型未贯通时本阶段不宣称完成。人工帮助另开辅助结果记录。

### 3. 按输出修精度与完整性，补最小源模型

依次处理尺度/方向/楼层，房间及外形，隔断和门窗，空间相邻与实际连通。用阶段 1 的信息去向区分识读、校正、装配与显示错误，每次只改导致当前主要误差的环节。

以 `CorrectedGeometry`、`BuildingGeometry` 和现有来源字段为基础，用必要字段或薄转换层保留稳定源房间/隔断/开口 ID、宿主、两侧空间、参考面及假设。生成的 Z 编号和切配面不能替代源对象身份。门和未填充开口先具备位置、宿主和连通语义，无需先做全实体墙。

约 65 mm 短边在此开展有界专项实验：检查实际使用的 [InterZone 校验](../../src/validator/interzone.py)、当前 EP 版本及最小样本行为，区分真实层间差异、观测误差、转换错误和求解器限制。源模型保留真实证据；如必须为仿真简化，单独派生并记录改变幅度及房间、开口和覆盖影响。它不应阻塞阶段 1 的可视交付或阶段 2 的读图实验。

**交付**：sm25 冷启动生成的几何、源对象关联、质量说明和剩余不确定项；重大错误有对应的局部行为验证。

**完成依据**：全部可确认的源房间得到保留；已知隔断/开口无静默遗漏；有依据的关键尺寸、楼层和拓扑通过核对；不确定项可定位且不冒充确定事实。若仍缺可确认房间或关键开口，只交付阶段结果，不宣称完整重建。

### 4. 第二案例迁移与一次真实编辑

固定阶段 3 的工具和入口，用 sm24 原始图纸运行，报告其与 sm25 的输入差异、失败和误差。两者都属于既有案例，因此只构成迁移检查；如据 sm24 结果调参，记录后续版本，再另选新的图式验证泛化。

同时选一个窗口移动作为首个修改动作：用户选对象并给出位移 → 更新源开口 → 确定性重建相关几何/宿主 → 检查并保存 → 重新打开仍能看到修改。复用现有查看器，按实际部署选择本地服务或可导入导出的补丁。第一次可用明确参数动作，随后自然语言解析复用同一个动作接口。

**交付**：第二案例模型及对比记录；一个可持久化、可撤销的开口编辑闭环。

**完成依据**：第二案例可查看且已知信息完整性有说明；编辑改变权威源对象，重新生成后仍有效，失败不破坏此前模型。墙推拉和完整自然语言编辑排在这一闭环之后。

### 5. 首个 EnergyPlus 出口贯通

对已检查的 sm25 几何，接协作者物性及现有下游接口，先按房间一对一区域派生，完成 IntakeOutput → IDF → EP。复用阶段 3 的短边实验结论，检查覆盖、开口、构造和边界，不为仿真通行丢弃源信息。

**交付**：可追溯的仿真输入、运行结果、失败/警告说明和几何派生差异。如比较生成/参考几何，挂同套物性并明确比较的是供冷/供热需求等量。

**完成依据**：选定配置的实际 EP 运行成功，几何与输入来源可回查；运行成功与重建准确性分别报告。协作者接口缺口只修实际对接所需部分。

## 用实验决定什么

| 不确定问题 | 最小实验 | 结果影响 |
|---|---|---|
| 旧工具链的主要瓶颈在感知、准备还是后段？ | E0：旧 sm25 产物离线核对及对象去向追踪 | 确定第一处改动；不重新调用模型排查已有产物问题 |
| 目标档模型能否自行完成量测所需准备？ | E1：一张平面＋一张立面，各用目标档和 Sonnet 级配置做一次无答案尝试；记录工具/人工/耗时，仅在结果不稳定时复跑 | 选择读图配置和修复策略；不能只凭合法 JSON 判断成功 |
| as-drawn 固定流程是否适合自动读图？ | E2：仅在 E1 暴露适配问题时，同一问题视图比较现有流程与模型选择现有工具的方式，其他条件固定 | 决定局部复用、薄接线或替换；不先做庞大模型×流程全组合 |
| 小边是否真的不可用于当前 EP？ | E3：真实短边局部样本和同条件对照，先检查导出，再做确定性 EP 最小运行 | 决定修校验、修转换或增加有记录的用途简化；不据源码警告直接下结论 |
| 修复能否贯通和迁移？ | E4：新 run 的 sm25 冷启动整案，再做 sm24 迁移；重大改动才复跑相应整案 | 判断局部收益是否保留到最终模型，决定下一类输入 |

E0 先行，E1 不等待 E3 全部解决。局部实验通过后尽快到整案；若相同阶段重复失败且没有新证据，暂停整案重跑，回到最短样本验证假设。每轮保留独立输入、命令、配置、输出和失败原因。

目标档（可本地部署级/Flash 级）从 E1 参与，Sonnet 级为产品运行上限，开发助手不替产品补答案。具体 ID、视觉能力和通道使用前核对；优先使用已授权的订阅做开发探索，明确订阅实验与产品 API 接线的区别。不能默用付费 API 或自动回退到 DeepSeek，权限按 [模型约定](../workflow/models.md) 执行。

## 每轮怎样验收和选择下一步

- **内容**：逐对象匹配房间、隔断和开口；统计已重建、未识别、缺失及错误合并/重复，源空间与热区数量分别报告。
- **几何**：统一参考面后，记录关键尺寸绝对误差、边界偏差、房间面积误差及窗位置/宽高误差；按尺寸标注、像素和推断分组，报告中位数、P95、最大值及异常对象。第一轮据输入分辨率和实测基线提出数值验收线，后续固定用于比较，改变口径须说明。
- **关系与有效性**：楼层归属、隔断两侧、窗宿主、相邻与门洞连通；闭合、自交、配对、应有覆盖分别检查，当前 NA 项不算完成。
- **投入**：记录完整/部分/失败尝试数、实际模型与调用次数、可得 token/费用数据、墙钟时间、人工补充内容/次数/时间。订阅没有准确单次账单时不编造费用；少量样本不给稳定成功率结论。
- **验证范围**：局部代码用相关离线检查，阶段接口增加一次真实产物贯通；文档只查 diff/链接。历史重放、冷启动、人工辅助和 GT 内核诊断分别呈现。

详细评价边界见 [验证与评价](../design/evaluation.md)。

## 紧接本计划的首个工作包

1. 新建 sm25 基线 run，复用旧几何生成 3D、分层图和房间/开口对应清单，定位 27/29 差别。
2. 核对隔离读图入口与 as-drawn 工具的实际接缝，选定 E1 的平面、立面和两档可用配置；列清模型要自动生成的准备信息。
3. 启动 E1，交付首批目标档原图观测和可检查结果；能继续则立即推进 sm25 六视图，阻塞则只修该阶段。

本批不把体量适配、任意混合输入、全实体 BIM、全套编辑器、热区优化、全面缓存优化或历史债清零放在上述结果之前。出现可查看输出和实验结果后更新下一工作包，不预排大量依赖未知结论的细任务。

| 2026-09-10（每轮一个方向） | 用户将此前双线并行改为每轮只推进一个方面，当前继续还原建模 | 部分推理保留已有 sm24 四立面简化 BIM 与 Voimatalo 单体输入，暂停后续施工；同一还原方向内部仍可按文件/接口分工 |
| 2026-09-10（统一命名与并行研究） | 按信息充分程度称还原建模、部分推理建模、完全推理建模；部分推理研究与还原主线并行 | sm21/sm24/sm25 属当前还原主线；带贴图体量和局部图纸辅助属部分推理研究起点；参考图片、概念文字等主要靠推断的任务称完全推理。不按输入模态分产品，共用底座；具体工作安排见 [研究计划](partial_inference_research_plan.md) |
| 2026-09-10（复杂度暂定方向） | 当前只捋顺源 BIM 简化/合并的方向，档数、控件及对应关系不固定，后续详细设计 | 三档与办公楼划分只是便于理解的例子，不作为产品合同；输入信息充分程度、输出简化程度、后端计算处理相互独立 |
| 2026-09-10（按实际分隔简化/合并） | 源分块以实体隔墙为依据；复杂度表示对假定完全准确的建筑空间做多少简化/合并，最细也不凭空拆分开敞空间 | 核心筒四周若是一圈开放办公，最细仍是一个四周空间；朝向与功能本身不构成隔墙依据。低档可直接推断合并后表达，无需先完整恢复；物理/抽象边界仍需区分，源简化与 EP 热区合并独立 |
| 2026-09-10（单体、源空间复杂度与后端独立） | 只做目标单体，不考虑环境；用户生成前选择通用 BIM 的空间复杂度，再选不同模拟插件 | 办公楼三档划分仅为举例，须结合实际隔墙与上述简化原则理解，不固定块数或强制按朝向切块。后端热区合并等继续独立派生。撤回助手此前按模拟用途配置生成、纳入周边场景的建议 |
| 2026-09-10（体量路线对象与细化配置） | 服务前期各类仿真，以办公、住宿、普通商业等类型化单体建筑为主；模型细化程度由用户配置 | 城市尺度是使用背景；复杂公共建筑后续特化/简化。当前只讨论获取方式与 pipeline，不启动实验；此前按独立外壳推荐的案例须按建筑用途重新筛选 |
| 2026-09-10（体量输入与交互补充） | 各类输入都应尽量产出有用模型，精度与准确性随信息变化；当前先调研并取得带贴图三维体量案例，纯照片另列输入分类 | 缺信息可在生成过程中交互补足，与生成后的 BIM 停点编辑分开；本次先取得输入资产和路线依据，不把照片到几何重建一并作为首例前置 |
| 2026-09-10（收工前收敛范围） | 边试边推进，不预先固定 Agent 结构；当前只集中于产出丐版 BIM，暂不管 EP，不需要六个运行环节 | 一层子 Agent、0–5 映射等是先前讨论建议，不是必须落地的结构。下轮从最小真实实验继续，按实际需要接工具，避免再陷入结构设计和过早复杂化 |
| 2026-09-10（总 Agent 产品形态） | 用户明确主要思路为模型驱动的总 Agent，配备代码、模型等工具完成各环节，并委托助手总体把控架构 | 整案执行由目标、输入与反馈驱动；固定步骤可以是工具内部实现，不能成为所有输入的唯一流程。助手建议先一个总 Agent 加按需专门能力，复用几何内核，以真实 BIM 与失败恢复检验效果，不先堆角色或重写全库 |
| 2026-09-10（证据与泛化） | 标注 + 像素双证据 ＞ 像素证据 ＞ 纯推理；先出有用丐版 BIM，输入越充分再提高精度。材料分层等热工信息归后端模块 | 证据顺序不是生成准入门槛；模型承担图意、采信、工具选择和合理推断，不能为固定图像样式、量测工序或单/双线契约牺牲泛化。推断显式说明，已知空间/开口仍须保留；代码负责几何计算与自洽 |
| 2026-09-10（补充历史动机） | 从单线改双线，是为了减少 reading 提前选线的推理负担，并延后墙厚、轴线/墙边标注引出的出模对齐取舍 | 不能只凭历史单线好结果预先恢复这一职责安排；墙厚几何优先级较低，可靠厚度与几何精度的利用方式仍在讨论，未确认新阈值或唯一表示路线 |
| 2026-09-09（灰空间讨论后确认） | 优先通用底座，主体以逻辑闭合空间体和实际围护/开口表达，参考成熟的物理/虚拟边界思想 | 空间不限矩形，逻辑闭合不要求实体围护封闭；源中保留真实敞开及未知信息。遮阳按需补充、热区切配、物性、空气交换等留给后端，不作为源生成前置；具体 schema 和灰空间贯通仍待实现 |

# 产品目标

**Sim BIM Agent** 将单栋建筑的图纸、文字、照片、CAD或带贴图三维网格转成轻量BIM，供查看、修改与后续仿真分析。不同输入能力逐步接入，不把规划能力当已实现。

## 当前重点

- 在有限模型能力下稳定生成空间划分正确、几何自洽的轻量BIM。
- 以自有runtime和分工模式推进；单模型保留为参照，共用一套domain。先把分工做稳，再按证据降低角色模型需求，不预设越来越多角色。
- 减少模型抄写、机械计算、重复量测和返工负担，确定性工作交给代码。
- 产品效率约30分钟仍是方向；开发不以收紧时长逼交付，保留防失控保护线并完整记账。
- 开源本地级约27B及以下是目标模型档，允许Flash级过渡。实际选型以质量、速度和消耗验证，不以名义模型档代替结果。

## 输出与质量取舍

核心产物是源BIM：空间、物理/抽象边界、门窗、相邻与连通、依据。EnergyPlus是首个可选下游，我方主要负责几何，物性由协作者负责。未来其他模拟出口另行验证。

最细粒度按真实隔墙划分空间；大开敞空间不能仅因朝向或用途被虚构细分。用户可以预先选择显式的合并/简化程度，这与后端热区划分独立。不需要先推理出全部细节才生成简化版本。

定性大于逐点吻合。漏墙、多墙、错拆错并、假楼板、漏门窗、挂错墙和连通改变优先处理；几厘米差异允许有依据的规整。**10cm规整也适用于明确标注或真实存在的更细数值**，目的首先是减轻模型负担。原始读数和采用值可以不同；标注优先用于理解尺度、关系。用户提出读取整图标注后选择统一步长，自动规则尚未设计，不以逐点四舍五入代替联动规整。

信息不足时允许明确标注的推断、默认值与简化；多个合理方案可倾向简单者。类型可作合理推断，但不能静默漏对象或把推断当观测。

## 验收边界

源BIM可用性、图纸保真、runtime恢复与效率、真实服务连接、下游仿真分别验收。源码整理和离线测试不证明真实识读或订阅已可用。精度取舍是产品决定，不宣称所有仿真均不受影响。

部分推理已获认可的Voimatalo细档成果、历史sm25对照与失败结果保留在D盘归档；不把旧结果冒充当前版本生成。当前状态和下一步只维护在 [roadmap](roadmap.md)。

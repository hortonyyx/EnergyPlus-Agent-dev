## 当前工作包：图纸路线优先

当前施工入口是 [详细计划](drawing_reconstruction_plan.md) 的 M0/M1：

1. **M0-1/2/4**：复用 sm24 错切反例，补最小源对象/派生映射和分区评价；已实现的 C2 多边形内核直接复用。将 sm21 成功、sm25 当前产物放进同一自动报告。
2. **M0-3/5**：补门/空开口及连通，做有界容差规整；小扰动可放行，真实漏墙/多墙和假楼板必须被发现。
3. **M1**：交错开展目标档读图探针，贯通三案例原图到可查看 BIM、自动报告、一次持久编辑和一个本批 EP 出口。历史 replay、当前冷启动和人工辅助分别报告。
4. **后续 M2–M6**：默认立面匹配/缺图/整体朝向 → 退台 → 内院/挑空 → 非正交 → 组合案例；按实际依赖和用户项目需求允许前移独立能力，不等旧批次全锁清零。

当前已知三案例与 M0 施工不依赖后续样本。已询问歧义处理偏好和复杂案例需求，未回复部分在计划中明确为暂定安排，不冒称用户已确认。每阶段输入、改动范围、自动验收和完成依据均在详细计划维护；新实验尚无结果。

建议保持一条 main，确需并行时用短期树，公共接口及时合入；不创建两套长期架构。详见 [融合建议](../design/architecture.md)。

## 后续与暂缓

| 事项 | 进入开发的依据 |
|---|---|
| 输入融合和编辑回写 | 按图纸/体量样例的实际缺口推进，不同时建设全模态平台 |
| 物性与下游对接 | 复用协作者接口，真实 case 暴露缺口时再补 |
| idfpy / BEM 重构 | 现有下游及协作者接口确实不能满足输出时评估 |
| token / 缓存全面优化 | 目标档模型形成实测质量/成本/耗时基线并出现具体瓶颈 |
| 自动角色治理、全实体与其他求解器 | 有具体产品工作量或下游用途需要，且现有简单实现不足 |

历史批次、审阅债和分数目标不会自动成为待办。当前先让真实输入产出有用的建筑模型，再按输出问题选择改动。

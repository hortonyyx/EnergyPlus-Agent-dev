# 阶段 3：外层协调与带图局部观察

外层开发模型经 MCP 调用冻结的建筑工具和四个新协调接口；目标档模型只做
被委派的局部观察。外层可以是 Codex、Claude Code 或脚本，底座不假称拿到了
这些客户端内部的模型请求、隐藏上下文或服务用量。

实现入口为 `src/agent/runtime_coordinator.py`，建筑证据装配在
`src/agent/runtime_delegation.py`；通用父子日志和预算仍在 `src/agent_runtime/`。
冻结工具、参考资料、两套既有指引和几何内核不改。额外的局部观察指引为新角色
明确任务边界与三栏返回格式，不改外层原有的建模指引。

## 调用与持久记录

1. `view_image` 返回已有视图编号。网关核原图哈希，记录实际返回图片的哈希、
   原图裁剪框和缩放变换。没有可核原图映射的合成图保留完整工具日志，但不能
   冒充具有原图坐标的委派视图；既有渲染可以先作为输入图经 `view_image` 登记。
2. `delegate_to_role` 接受问题、已登记的视图编号、协调者补充说明和子额度。
   代码保存证据包，固定当时源 BIM 的文件哈希及候选编号，然后创建子任务。
   没有保存候选时版本为输入清单的哈希，明确为未建模状态。
3. 只读局部观察角色实际收到这些图片字节。返回直接看到、解释、不确定，以及
   原图像素框。模型只写局部编号；代码从已下发证据补齐 run、图片哈希、坐标
   关系和源 BIM 版本。未下发图片、裁剪框外定位、错误引用、空白答案不通过。
   返回成立不等于内容正确，语义质量另行评价。
4. `inspect_local_observation` 返回原结果和当前适用性。
   `apply_local_observation` 在调用冻结写工具前重新核对当前源 BIM；已用结果、
   旧版本结果和非当前候选被拒绝。修改由协调者明确选择工具、参数和理由，
   局部观察自身不会自动变成几何修改。
5. `runtime_state` 给出根预算、子任务状态、图片身份和当前模型版本。

每次外层调用记录 operation 或 dispatch，再记录 return。写工具先保存意图及
状态，再执行、记录结果。中断后不明的写入先检查实际保存状态，不能仅凭
快照断言完成，也不会自动重放。重连恢复已保存的子结果；同一任务编号不能
换问题或图片。协调配置、工具、角色模型档案或实现变化会拒绝静默恢复。

子任务与根共享一个追加日志、附件库和账本；子任务的检查点、收据、证据包
分别保存在任务目录。调用串行，当前不支持多个协调进程同时写同一运行。
日志中 `events` 表示当前任务，`all_events` 表示整次运行，父关系必须合法。

## 权限、预算和恢复

局部角色仅暴露五个已有的只读参考/测量工具，图像参数限于证据包内原图名称。
分发器还会再次核对只读授权，直接构造写调用也不能越权。
冻结的 `review_detail` 继续保持禁用，避免暗中调用旧订阅模型。

首批小测暴露的接口缺口已修：请求明确附带实际子额度和可用图片文件名，
工具返回后再递增状态版本、更新剩余调用数、token 和时间；`pixel_profile.name` 明确是输入
图片名。已知的包外图名或裁图外测量返回明确失败回包，底层零调用，可由
下一模型轮读取纠正，不再误记为未知运输结果。涉及旧 profile 绑定的立面
比较只接受下发的完整图片。五个工具本身的说明与参数定义仍逐字不变。

每个子请求先同时核根总账和子额度；其首笔实际预留编号必须与证据包一致。
预留/结算、摘要和重试均归入根账，子超额和根超额有不同的停止状态。
当前角色小测关闭自动重试和回退。批次另有持久请求票据：失败或中断也耗一张，
重启不会重置 60 次上限，日志尾损坏时拒绝继续发送。

模型相关估算见 [请求估算](runtime_request_estimation.md)。上下文限制取模型
档案和调用者限制的较小者，使用输入安全估算加输出预留，超限发送前停止。
预算允许显式缩减输出时记录原值、实际值和原因；图片和文字不静默截断。
Paratera 实际最大上下文及价格未核实，不能把模型原生规格当作服务承诺。
取消清理越过时间预留时，原始耗时和结算拒绝继续保留，未知用量不释放；
停止原因明确为根或子任务时间额度耗尽，不把该状态误报成 token 超支。

自由文本摘要本阶段未加入：局部任务有界，现有结构化状态索引已足够。
后续若整案证据显示上下文受限，再沿用阶段 2 的推断变事实、尺寸/对象仅存
摘要等反例扩展，不以摘要替代原始证据。

## 启动与验证

从本工作树设置 `PYTHONPATH`，所有输出目录和临时文件放在本树。
入口：`python -m src.agent.runtime_coordinator --help`。
真实调用必须明确给出 provider、角色模型、批次额度文件和只读凭据路径；
模型固定为服务启动时的配置，不自动回退。

离线演示和固定角色小测位于
`AI_agent/logs/experiments/2026-10-02_harness_stage3/`。前者用脚本模型和真实
冻结工具，包含裁图、修改、旧结果拒绝、越权拒绝、预算停止和重连；后者经
同一实际 stdio 网关测试所有预先固定问题，评价侧参照从不进入请求。

适用边界：目前为局部委派、串行调度和首版整案准备；不是已完成多模型自治
分工，也未证明整案建筑质量。名词规范仍待用户确认，既有类型名不批量改动。

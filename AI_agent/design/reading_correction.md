# reading / correction：职责、历史依据与下一项

2026-09-10 已完成用户指定的三项 Claude 订阅梳理，主助手交叉核实原产物和当前代码。完整证据、各方案比较、原始报告及纠错见 [本轮报告](../logs/experiments/2026-09-10_reading_architecture_review/README.md)。本页维护当前设计取舍，不把它写成新实现验收。

## 本轮结论与技术取舍

历史单线出口可以取得好 reading，as-drawn 的双面/墙带证据也有实际价值。现有实验没有在同等模型、输入、人工参与和预算下比较两者，不能宣布某一种表示普遍更好或更便宜。

**下一项以有证据的单线作为首个有界贯通对象，先补 reading 到 correction 的最小接口；原观测引用和派生依据随行，复杂墙面/空档按需复用 as-drawn 量具。** 不要求所有图先产出完整双线，也不恢复让校正模型自由重画整栋坐标。这是本轮技术取舍，尚未经新原图实验验证，不是用户确认了唯一长期路线。

这个选择保留当前源 BIM 生成与查看停点，以及同一份 BIM 后的 EP 分叉。灰空间细化、持久编辑和物性扩展继续暂缓。

## 职责：认、量、解释与执行

**模型判断看哪里、对象是什么、哪些证据可采信；代码负责测量、换算、装配和可复查的执行。** 固化好的量具和操作方法，不把一种图纸的颜色、固定阈值或工序顺序推广为所有图纸的唯一算法。

reading 应保留图纸里的墙/房间/开口语义、定位依据和未知项。它可以给出参考单线，也可以给出两面/墙带证据；如果已经选择单线，必须说明那是外皮、中线或其他基准。门洞的定位和身份不能只留一句“墙已补连”。

as-drawn 的价值是将原图测得的墨迹和连续区间、图上尺寸声明、模型的解释分开。它仍在 reading 层判断墨迹族、墙面配对和空档身份，不是“reading 只测两根线、所有语义都留到后面”。代码已有实心墙带与单面表达，不只适配双线画法。历史原型 perception 由开发助手填写、且部分过程见过 GT，不能当目标模型冷启动结果。

correction 的目标仍分两步：

1. **逐图裁定尺寸证据**：代码列同一对象的证据及分歧，无歧义部分计算并记账；模型处理真实歧义；代码执行并复查。
2. **跨图空间推理**：对齐楼层、平立面与开口身份，模型判断冲突及建筑整体合理性，代码执行、装配并复查。

两步都采用“代码列问题 → 模型给决定 → 代码执行与检查”。尺寸不足时允许有来源的推断。计算切分是派生关系，不能在源 BIM 变成物理隔墙；真实敞开、门洞和绘图断墨不能单凭缺口长度归类。GT 只在评价侧，后端物性不参与这两步。

## 下一项的最小范围与验收

1. 用三份历史一层及 sm25 连续走廊反例，整理可执行接口样例：稳定墙/开口 ID、参考线基准、测量/尺寸来源、连续区间与真实缺口、宿主/相邻关系、未知和推断。先验证墙基准、一个门、一处走廊，不先铺全套新 schema。开发助手解释旧 note 要单独记录为辅助决定，不改历史 reading。
2. 验证代码落位与装配保留墙、窗、门和分区；sm24 错切继续被发现；无法定位/判定要有明确待判项。原始观测和派生单线通过引用关联，不维护两份平行权威几何。
3. 之后再新开原图 run，先一张平面再完整 sm21。Sonnet 级承担工序、歧义和整体判断；Haiku 等目标档从可检查的转录或候选识别子任务参与。按图保留局部复核和有限修订，记录人工干预、用量/时间和失败，不恢复无限重抽。
4. 分别验 reading 忠实、correction 是否改坏、源 BIM 自洽可查看。工具调用次数、所有尺寸链是否全绿、内部墙是否有自由端仅作诊断，不能取代真实分区/连通验证。

# reading / correction：职责、历史依据与下一项

2026-09-10 已完成用户指定的三项 Claude 订阅梳理，主助手交叉核实原产物和当前代码。完整证据、各方案比较、原始报告及纠错见 [本轮报告](../logs/experiments/2026-09-10_reading_architecture_review/README.md)。本页维护当前设计取舍，不把它写成新实现验收。

## 本轮结论与技术取舍

历史单线出口可以取得好 reading，as-drawn 的双面/墙带证据也有实际价值。现有实验没有在同等模型、输入、人工参与和预算下比较两者，不能宣布某一种表示普遍更好或更便宜。

**09-10 最新确认：先根据现有信息产出可用丐版 BIM，证据用于提高精度，不能变成输入准入门槛。** 材料分层等热工信息归后端。单/双线和最小接口按实际输入及模型判断负担选用，不先固定唯一 reading 出口，也不等完整证据接口设计完再验证生成。历史单线样例保留兼容诊断价值；此前“优先单线”和“先补齐接口”的建议均不足以落实这一目标。

这个选择保留当前源 BIM 生成与查看停点，以及同一份 BIM 后的 EP 分叉。灰空间细化、持久编辑和物性扩展继续暂缓。

**随后用户明确产品总 Agent 方向**：reading/correction 表示观察和校正职责，可以由总 Agent 按需调用、交错或局部重做，不要求固定角色接力或所有输入经过同一串行流程。本页的几何/证据工具服务于总 Agent；当前施工优先接最小模型驱动循环，设计与完成依据以 [系统设计](architecture.md#现有能力与首个增量) 为准。

## 证据用于提高精度，模型负责泛化

用户明确的采信顺序是 **标注 + 像素双证据 ＞ 像素证据 ＞ 纯推理**。双证据指对图意和尺寸的相互支持，与墙画成单线还是双线无关；标注与像素冲突时仍需模型解释，不能只因两类字段都在就认定可信。

同一栋楼可以有标注约束的外框、仅凭像素定位的隔墙和推断的层高。没有尺寸标注仍可按像素重建；缺少绝对尺度时允许采用明确的尺寸假设；图上不清楚的部分由模型结合整体关系补全。来源说明服务于理解和后续修改，不要求每个推断都补出不存在的像素测量或尺寸链。

带纹理、模糊、单色、复杂表现图由模型选择合适的观察和处理方式，按需调用裁图、量测等工具。工具未检出候选不等于建筑对象不存在，也不应自动终止生成。模型可提出工具候选之外的解释与补全决定；代码把决定落实为自洽几何。固定颜色、阈值、候选目录和工序顺序均不能代替这一能力。

原图信息不足与生成错误分开处理：前者允许带假设生成，后者需要修复或如实报告。已知房间、隔断、门窗及连通仍须保留；已有可靠观测的改判须有解释。更细精度按输入和用途取得，不用强制量测记录或全部尺寸链通过来代替模型质量判断。上述是当前设计目标，现行代码限制见后文，未因文档修改自动解除。

## 09-10 补充：为什么改双线，墙厚精度追到哪里

**用户补充的历史动机**：单线要求 reading 提前选择代表线，涉及推理；墙厚以及尺寸按轴线/按墙边标注，又引出两种出模形式、对齐和精度问题。改双线是为了延后这些取舍，降低 reading 前置判断负担。用户认为墙厚的几何细化优先级较低，更关注其作为墙体参数对仿真的影响；同时提出“若能读准墙厚，是否几何也可更准”的开放问题，尚未定新精度门槛。

**助手当前判断（讨论建议）**：总厚与尺寸基准都可靠时，应由代码利用这些信息改善净尺寸、外轮廓和洞口深度；无需为此强制完整实体墙。只知道总厚不够：轴线未必是墙体正中，图上两根线也未必是完整构造的两侧，尺寸量到哪里、固定哪条参考线仍需解释。转换一旦明确，算术通常简单；不确定时不强行生成精确墙面或自动改空间分区。

例如两道均为 240 mm、轴线位于厚度中点的墙：轴间 5 m 对应净距 4.76 m；若图上 5 m 标的是净距，轴间则为 5.24 m。总厚相同，基准不同，几何结果不同。这是说明例，不是对案例的新测量。

几何总厚与热工构造层信息分别保留并核对相容性。总厚准确不能推出材料、保温层厚度、导热率和热容量准确。用户指定内容要区分“修改实际墙构造/总厚”与“选择仿真等效参数”；前者可能需要几何重新派生，后者不能默默移动源墙。详见 [共同模型中的墙厚区分](model.md#墙厚几何信息与热工构造09-10-讨论)。

当前建议的取舍是：可靠已有信息尽量利用；新增识别/推理成本是否值得，按房间/连通保真和实际用途判断，不为了墙厚微差重开多套源模型。保留双线证据可以与轻量面模型输出并存，reading 是否必须先压成单线、输出是否必须画成实体墙是两件事。

## 职责：认、量、解释与执行

**模型判断看哪里、对象是什么、哪些证据可采信；代码负责测量、换算、装配和可复查的执行。** 固化好的量具和操作方法，不把一种图纸的颜色、固定阈值或工序顺序推广为所有图纸的唯一算法。

reading 应保留图纸里的墙/房间/开口语义、可用定位依据和假设。它可以给出参考单线，也可以给出两面/墙带证据；选用单线时说明采用的基准，无法从图上确定则可明确作为建模假设，不能要求先证明外皮/轴线才准生成。已知门洞的定位和身份不能只留一句“墙已补连”。

as-drawn 的价值是将原图测得的墨迹和连续区间、图上尺寸声明、模型的解释分开。它仍在 reading 层判断墨迹族、墙面配对和空档身份，不是“reading 只测两根线、所有语义都留到后面”。代码已有实心墙带与单面表达，不只适配双线画法。历史原型 perception 由开发助手填写、且部分过程见过 GT，不能当目标模型冷启动结果。

correction 需要处理两类判断，属于逻辑分工，不要求每张输入完成固定两轮证据工序：

1. **逐图裁定尺寸证据**：代码列同一对象的证据及分歧，无歧义部分计算并记账；模型处理真实歧义；代码执行并复查。
2. **跨图空间推理**：对齐楼层、平立面与开口身份，模型判断冲突及建筑整体合理性，代码执行、装配并复查。

代码可列出测量与约束冲突，模型也可主动识别问题并提出新假设，无需局限于代码预先枚举的候选；确定性执行与检查接住这些决定。计算切分是派生关系，不能在源 BIM 变成物理隔墙；真实敞开、门洞和绘图断墨不能单凭缺口长度归类。GT 只在评价侧，后端物性不参与上述几何判断。

## 下一项的最小范围与验收

1. 从既有失败产物定位一个妨碍可查看 BIM 的实际接缝：已有墙/窗/门信息有无传丢、未知基准能否带假设执行、量测失败是否错误地成为停机条件。按需要补最小接口及模型决策能力，不先建设覆盖所有样式的证据 schema。
2. 尽快在独立 run 验证原图到可查看源 BIM，先小范围再整案；并用缺少标注或量测不稳的局部输入检查能否合理推断继续。只改变与当前问题相关的输入条件，不先铺大套风格测试矩阵。历史样例按需诊断；开发助手解读旧 note 单独记辅助决定，不改历史 reading。
3. Sonnet 级承担工序、歧义和整体判断；Haiku 等目标档从可检查子任务参与。保留局部复核和有限修订，记录人工干预、用量/时间和失败。单线/双线、测量方法按图选用，不能靠恢复固定审批链解决泛化。
4. 分别验 reading 是否保留已知信息、correction 是否改坏、源 BIM 是否自洽可查看及假设是否清楚。复用 sm24 错切和 sm25 连续走廊反例保护空间关系。工具次数、尺寸链全绿、墙厚精度均不替代这些结果。

# 图纸识读、规整与源 BIM

识读和规整是可组合能力，不是所有模态必须依次经过的两个模型阶段。

## 职责与实现

模型识别图纸中的空间和构件、读取标注、选择依据、处理歧义。代码负责坐标换算、尺寸计算、几何编译、规整、宿主与连通检查。反馈是否被正确理解和采用仍需真实任务验证。

优先表达完整空间结构与开口关系，局部模糊时按需查看、裁图或量测。尺寸链与标注优先用于尺度和关系，原始读数与采用值分开。不能靠删除门窗、错误合并或改变连通消除编译错误。

- 单模型：`bim_agent_guidance.py` 组合共用规则、输入方法、工具索引与参考资料。
- 图纸分工：`runtime_roles/guidance.py` 定义角色范围；读图产物经试建/提交进入共同装配。

两者复用 kernel 和源 BIM，收益需按明确版本、输入与模型比较。分工规整采用 0.1 m；自动选步长、失败声明的局部恢复及近轴/尺寸链问题仍待处理。本页不增加新的必走步骤。

## 评价与沿革

原图、模型观测、保存几何和独立参照分别核对。图像返回、调用成功或局部几何正确不证明完整识读成功。GT 留在评价侧；人工反馈、旧稿恢复与冷启动分开记录。

历史经验已被持续吸收进当前方法与工具；旧 resources 不是原封不动作为当前 prompt 加载，详见 [继承关系](domain_lineage.md)。本页清理前的完整实验记录见 [归档索引](../reports/archive-index.md)。

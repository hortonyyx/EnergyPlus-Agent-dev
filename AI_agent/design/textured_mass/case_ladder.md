# 案例梯度：从简单到复杂，及内核支持边界

2026-09-18 调研。入口见 [体量输入调研](../textured_mass_route.md)，来源清单见 [sources.md](sources.md)，获取路线见 [acquisition.md](acquisition.md)。

**09-20 案例复核入口：** 香港 15 栋原 GLB 只导首网格、丢节点矩阵，令全批竖轴和高度解释错误，两例另共丢 62 面；完整 scene 已重转并生成四视图，14/15 可由现有观察器读取，一例因源透明材质仍待兼容。旧 L0–L5 标签、用途和“高/中/低”质量未逐栋验收，不能据旧高度/贴图密度纳入梯度；见[选样复核](../../logs/experiments/2026-09-20_hongkong_material_audit/source_review.md)与[转换核查](../../logs/experiments/2026-09-20_hongkong_material_audit/conversion_audit.md)。本页的 L/P/E/S 仍是描述难点的研究框架，不把候选标签或推荐顺序变成产品硬门槛。

本页给部分推理建模的选样排一个阶梯，并说明每一级现有几何内核画不画得出来。内核限制以 [共同模型](../model.md) 为准，本页只引用并标注对应代码位置，不另立一套说法。

## 分级原则

按项目已确认的三轴独立（**建筑自身复杂程度 ≠ 输出简化程度 ≠ 输入信息充分程度**），主梯度 L 只按第一轴排，只回答一个问题：**这栋楼的几何本身，现有内核画不画得出来。**

两类困难单列副轴，不计入主梯度：

- **副轴 P（内部组织）**：酒店客房标准层几何上极简（矩形套矩形）却在推断上极难——房间数只能从窗律推，而项目明确禁止把窗数直接等同于房间数。这是「几何低复杂度 + 推断高复杂度」的典型，不应按几何级别排序。
- **副轴 S（采集与输入）**：树木/邻楼遮挡、扫描缺失属于输入充分程度，不改变建筑本体。选样时应与 L 轴**正交组合**，否则会把一栋 L1 的板式住宅误判成难例。

## 主梯度

| 级 | 新引入且不可回避的难点 | 建筑类型例子 | 内核 |
|---|---|---|---|
| **L0** | 规则单层外壳，适合作为较少形体歧义的基线；入口、用途和内部仍可能需要推断 | 单层超市/建材商场、单层展厅或汽车销售店、独栋单层小办公 | ✓ |
| **L1** | **层界推断**——源网格通常没有楼板对象，可结合窗排、檐线、入口、已知层数/高度等证据推定；信息不足时仍须标假设 | 多层板式住宅/公寓、小型多层办公楼、城市型连锁酒店或宿舍楼 | ✓ |
| **L2** | 外立面平面超过四个，出现朝向自身的内凹面，两翼互相自遮挡；「一个 L 形空间不得被拆成若干矩形」第一次成为活的约束 | 沿街转角 L 形办公楼、U 形宿舍/教工楼、凹字形板式住宅 | ✓ |
| **L3** | 竖向不均质，打破 L1 建立的「标准层重复」先验 | 首层商业 + 上层办公的沿街楼、首层商铺 + 上层住宅、酒店（首层大堂餐饮 + 上层客房） | ✓ |
| **L4** | footprint 随高度变化，中部出现外露屋面和外露底板；这两处范围是**推导**出来的而非观察到的 | 顶层退台办公楼、裙房 + 塔楼的商业综合体、上层外挑的公寓 | ⚠️ 源路径通、legacy 拒 |
| **L5a** | 核心贴外墙或置于端部 → 环绕空间是 L/U 形单外环 | 板式办公楼、板式住宅（交通核大多如此布置，极常见） | ✓ |
| **L5b** | 中心核心筒 + 一圈环绕 → 环绕空间是**带内环的单一逻辑空间** | 塔式办公楼 | ✗ |
| **L6** | 完全围合内院 → **建筑轮廓本身带洞**。楼层轮廓、逐层覆盖检查、立面可见性、室内外判定四件事同时失效 | 欧洲街区式围合住宅、围合式酒店、老城口字形办公楼 | ✗ |
| **L7a** | 周边或角部通高门厅（周围楼板仍是单外环） | 办公楼入口通高门厅 | ✓ |
| **L7b** | 中心中庭（周围楼板成环） | 带中庭的商场 | ✗ |
| **L7c** | 变截面通高空间（上下截面不同的中庭、坡屋顶下空间） | — | ✗ |
| **L8** | 平面方向超出 x/y 两轴 | 不规则街道或三角地块上的斜角办公楼、弧形立面 | ✗ |
| **L9** | 两项以上难点叠加（对应执行计划的 M6） | Voimatalo 在此 | — |

## 内核卡在哪

不支持的几级（L5b / L6 / L7b / L7c / L8）卡点是**同一条硬约束**：空间多边形必须是**正交、单外环、沿高度等截面**的棱柱（[model.md](../model.md) 第 38 行）。

关键是这条约束**不在某一条导出链上，而是从 Agent 输入接口到源内核到 legacy 桥接全线一致**：

- `src/agent/geometry/parametric_proposal.py:57` —— `polygon must be a valid positive-area single ring`，`poly.interiors` 非空即拒
- 同文件 `:60` —— `polygon edges must be nonzero and orthogonal`
- `src/agent/geometry/source_bim.py:168` —— `space {id}: non-orthogonal source geometry is not supported yet`
- `src/agent/geometry/cell_geometry.py:172` —— `polygon edge is not orthogonal`

也就是说，产品 Agent 在**接口层**就无法提交带内环或带斜边的空间。要补 L5b/L6/L7b，改动面比文档表述看起来大得多。

**L4 是唯一新旧路径判定不一致的一级**，报告时必须分开说：

- 新源路径已支持并由 Voimatalo 实证——`source_bim.py:174-193` 的逐层 footprint 覆盖检查按 `floor.footprint` 声明轮廓，用该层 cells 与 `spanning_space_ids` 的并集比对 missing/outside 面积
- 但 legacy 多层装配仍显式拒绝——`src/agent/correction/multifloor.py:1307-1311` 是 `PER_FLOOR_FOOTPRINT_MISMATCH` 的唯一抛出点，第 630 行注释明写 `existing PER_FLOOR_FOOTPRINT_MISMATCH fires unchanged — a real setback`

**另有一条代码里读到、文档未写清的限制**：`source_bim.py` 要求 spanning 空间必须覆盖被引用楼层的**完整层高**，因此 1.5 层高的夹层挑空目前无法表达。

## Voimatalo 定级：L9 组合级

它同时落在：

- **L2** —— 非对称 L 形长短翼
- **L3** —— 首层 5.6 m 含商业，上部六个约 3.2 m 办公标准层
- **L4** —— 顶层退台，西面按北端与长翼分别规整
- **副轴 E2** —— 混合立面（首层店面玻璃 + 上部规则窗 + 局部例外大窗）
- **副轴 S2/S3** —— 两个短端扫描缺失、内院首层缺面

另加弧面屋顶被简化成五个棱柱部件。

**作为首例明显偏难，四条理由**：

1. 它一次叠了四条轴，而项目自己的方法论写明「每类先用最小可控样本定位内核/接口，再用完整图纸验收」，M0→M6 的整个设计就是每次只加一条轴
2. 案例 README 自己声明它是受保护的 1950 年代历史建筑，「不代表随机抽取的新建办公楼」「后续仍需另一栋更普通的跨样例验证」
3. **当时缺少已验收的 L0/L1 简单真实样本**；09-18 香港候选虽然贴了 L0/L1 标签，09-20 已发现旧轴向和高度错误，须重看源立面与用途后才能补上这个空缺
4. 层界估计和内部空间组织在 Voimatalo 的复合环境里难以单独归因；较简单、证据充分的样本可帮助判断究竟是推断方法、输入遮挡，还是形体条件造成错误

这正是 09-16 验收未通过后卡住的地方。

## 补样建议

**可试顺序：L0 → L1，再按可得素材选 L3 或 L2。** 先找少数用途明确、立面可判读的普通单体，利用它们诊断方法；Voimatalo 已有的返工和验收记录仍保留，不因这个建议失效。

- L0/L1 通常减少形体因素，有助于定位输入、转换、观察、层界推断或建模接口问题；仍可能因用途不明、立面模糊、内部信息不足而失败，不能把失败一律归给链路
- L3 可用于检验首层与标准层差异；若先找到更清楚的 L2 单体，也可先验证凹面/自遮挡，选择依据真实素材质量与研究问题
- 记录每例已确认和未知的 L/P/E/S 特征，尽量用少数有梯度的样本隔离新难点；不规定每次只能增加一条轴

**补样入口**：见 [sources.md](sources.md)。香港单体化模型便于按栋取件，但现有 15 例须以修复后四视图重验可见窗/层线、用途和形体，许可改编边界也待确认；赫尔辛基可在已知可读片区横向找更简单单体，优先取市方原件；[acquisition.md](acquisition.md) 的路线 E（渲染开放 IFC）可作为有真值的合成对照候选，**09-18 用户已登记为待议、尚未展开**，具体 IFC/贴图许可与实际几何仍须核实。

## 副轴

**P（内部组织）**：P0 单一大空间（仓库/超市/单层办公）→ P1 走廊串联若干房间（小型办公、宿舍），需从进深与窗排推走廊位置 → P2 客房标准层（酒店/宿舍/公寓），几何最简单但推断最难 → P3 核心筒环绕（同 L5，受内环限制）。研究计划已把「有实际隔间的住宿/办公」列为优先差异，即 P2。

**E（外壳）**：E0 规则窗列，可逐窗数清 → E1 玻璃幕墙或带形窗，使“窗排间隙”这一层界线索变弱，需要再找檐线、框架、入口、已知层数等约束 → E2 混合立面（Voimatalo 在此）→ E3 深凹阳台、遮阳格栅、装饰构架，开口被外挂构件遮蔽且等截面棱柱近似与实际外挂几何不符。

**S（采集与输入）**：S0 四面临空无遮挡 → S1 贴邻建筑一到两面（欧洲街区常态，贴邻面无窗且无法观察）→ S2 局部扫描缺失 → S3 树木或邻楼遮挡首层、内院乃至整个立面。

## 补能力的优先级

若要按建筑类型覆盖面选一项内核能力先补，**内环（单空间带洞）性价比最高**——它一次同时解锁 L5b 中心核心筒、L6 围合内院、L7b 中心中庭三级，而这三级覆盖了塔式办公楼、欧洲街区住宅、带中庭商场这三类在真实城市里最常见的目标建筑。

非正交（L8）虽然也是硬缺口，但改动面更大（读图、校正、宿主、立面可见性、评分的轴向假设全要改），且许多看似非正交的建筑其实只是整栋旋转，已有能力可覆盖。

提醒：补内环时要守住[研究计划](../../project/partial_inference_research_plan.md)的红线——**不能通过多造隔墙、堵内院或加假楼板迎合现有接口**。

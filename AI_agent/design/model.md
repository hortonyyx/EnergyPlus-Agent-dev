# 共同轻量建筑模型

这是两路输入共有的数据要求。09-09 已落最小源对象与 Stage 2 投影，完整开口/连通 schema 尚未贯通；已实现的类型与限制见 [现有实现](implementation.md)。

## 已实现的最小源投影（09-09 M0 增量）

权威可修改参数仍在 CorrectedGeometry 的 Cell/Window；Cell.id 是源空间身份，不采用会重排的 Z 编号。[source_model.py](../../src/agent/geometry/source_model.py) 从它和确定性建模输出生成 `2_modelling/source_model.json`，复用 [schema.py](../../src/agent/correction/schema.py) 的 SourceSpace/SourceBoundary/SourceOpening。现有 geometry JSON/specs 字节合同保持原样，源投影是附带产物。

- 空间保存 cell ID、楼层、完整多边形、高度、role 和校正对象引用。源边界按空间与规整后的环边序编号，尺寸变化/显示面细分不依赖 Z 排序；新增/删除源边需要显式迁移边界身份，不能承诺任意拓扑编辑后 ID 自动稳定。
- 边界是有方向的空间边界，含 owner、相邻空间和对侧边界引用。同一物理隔断的两侧仍为两个相关联的源边界，不假装已建立唯一全局墙实体。当前 Cell 环按物理隔断解释；virtual/door/open 有类型槽，尚无生产生成/导出支持。
- 已有窗保留源 ID、宿主源边界、空间/室外、顶点和 unknown 连通状态。重复/丢失窗、窗移位或错宿主会报告严重问题。门、空开口与可通行关系仍未评价。
- `derived` 分别将 zone/surface/window 映射到源对象；源墙覆盖、派生面是否位于源边界、同一源空间内多出的墙和开口映射会检查。严重映射错误先保存候选与报告，然后阻断下游，探索模式也不例外。

源/派生内容各有摘要；查看器只在派生摘要匹配时载入附带源投影。映射检查的 2 μm 容差仅兼容现有切配的 1 μm buffer 和六位小数，不是图纸比较或规整容差。映射通过证明建模保留了校正对象，不能证明 correction 没有读错/切错房间；后者由独立分区参照与输入证据评价。

## 源对象与派生对象

| 内容 | 最少需要保留什么 |
|---|---|
| 建筑与楼层 | 外形、层高、尺度、局部坐标与方向 |
| 房间/空间 | 原始空间几何、语义、所属楼层；推断空间标明假设 |
| 隔断与边界 | 物理隔断身份、两侧关系、参考面；虚拟计算边界另标 |
| 窗/门/空开口 | 形状、位置、宿主、关联空间与外部；不能只剩显示 mesh |
| 空间关系 | 相邻和实际连通分开 |
| 场景几何 | 遮阳、阳台、邻楼与重要障碍物，可不形成区域 |
| 来源与更新 | 稳定对象引用、输入依据、变换、假设、冲突和人工修改 |

源房间与隔断不因热区优化被覆盖。热区、切配面、查看 mesh、物性装配及 IDF 从源模型派生，并保存对应关系。面模型可继续作为内核，全实体墙不是普遍前置。
一个非矩形房间可以对应多个显示三角形、切配面或仿真单元，源模型仍是同一个房间，不能沿计算切线生成物理墙。物理隔断、开放区域的语义分界和用途特定的计算边界分别表示；不同房间相邻与实际有门/开口连通分开。
稳定源 ID 不依赖会随几何排序变化的 Z 编号。首次实现只补真实 case 所需的房间、隔断、开口与派生映射；到挑空阶段再补跨层空间与楼板孔洞，不能用每层造一个房间和楼板代替通高空间。
可选墙厚、窗内缩与洞深按用途表示为显式几何或可派生参数；构造层厚度与几何参考面不是同一个概念。其他求解器的开口/连通表达按各自用途转换，不直接假定等同于 EnergyPlus 的父面/子面。

## 单位、方向与参考面

输入原单位、尺度可信度和坐标变换要明确；保留局部到共同坐标的变换。内皮、外皮、轴线和厚度不得只凭数值接近混用，假设北向不伪装成观测。
现有 E4 出口用建筑坐标顶点、EnergyPlus Relative 和归零的 Zone 原点/相对转角；它是当前下游合同，不要求每种输入原本采用同一坐标系。源代码入口见 [output_coordinates.py](../../src/agent/output_coordinates.py)。

## 简化与容差

区分观测不确定度、参考面转换、数值精度、几何有效性和仿真用途简化，不共用一个未经解释的“精度值”。规整/简化记录实质改变对象、幅度、理由和来源；原始输入与观测保留，可随新证据重新生成。可编辑的源建筑模型允许是容差内规整后的几何，不必带着原始 CAD 噪声工作。
优先保住源房间、隔断、门窗及空间关系，量化精度服务于用途；生成模型内部的共享边界由代码统一生成。详见 [定性评价与容差](evaluation.md)。
当前项目存在 0.1 m 短边检查，不等于 EnergyPlus 的普遍物理下限。层间差异先核对原图、尺度、参考面和识读残差，再决定修实现还是生成用途特定的简化模型。
不能统一粗网格化、静默删窄面/房间/窗或按预测结果倒改 GT 来获得通过。展示模型与仿真模型可有不同接受状态，检查方法见 [验证与评价](evaluation.md)。

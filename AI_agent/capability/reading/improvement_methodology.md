# 从实际失败改进 reading

目标是提高图纸到轻量 BIM 的可用性，以当前代码和真实输出为依据，不按历史批次补齐所有审阅。

1. 选有明确输入和期望产物的一个问题，先保留当前输出与错误。确认是没有观测、读错证据、坐标转换、结构化整合还是下游几何问题。
2. 查看原图与相关观测，定位信息在哪里丢失或被改写。尺寸标注、像素量测和默认推断分别记录；不要用 GT 答案回灌生成器。
3. 优先复用已有裁剪、CV、结构化观测和确定性求解工具。模型处理感知与语义，稳定数值关系交给代码。
4. 用当前目标档模型参与实验，记录实际模型和人工操作。比较同输入条件下的质量、时间与成本；不先假设必须由最高档模型成功后才能开始。
5. 改完先检查相关行为和相邻真实产物。新缺陷才补必要回归；一次有效结果可复用，不为换人复核重复全量。
6. 检查是否只修好该样本，选择另一个有代表性的输入确认适用边界；扩测由不确定性决定，不先建立全覆盖矩阵。

## 判断改进是否成立

看有证据的房间/隔断/窗门是否保留，尺寸和拓扑是否更合理，假设与冲突是否可见，人工修补和运行成本是否下降。输出 JSON 合法或 accepted 数量增加不是充分条件。
重放已有 reading 可验证后段工程；报告中与从原图冷启动区分。纯像素输入可以是较低精度路线，不能凭统一量化声称获得图纸尺寸精度。

## 保留什么记录

一次工作记录写清代码、原始输入、命令与模型、人工参与、输出位置、结果及未覆盖范围即可。稳定经验进入本页或架构；具体过程留实验目录。不要复制旧 Phase A/B/C 的逐日台账到现行计划。

# 能力与缺口

以接手代码 `461dfc98`、已保存的运行产物及 [本轮代码审计](../logs/experiments/2026-09-08_management_audit/README.md) 为依据。这里描述能力边界，任务排期只在 [plan.md](../plan.md)。

| 能力 | 已有基础 | 仍需完成或核实 |
|---|---|---|
| 从图纸生成观测 | reading、CV、模型工具与已有观测产物 | `flow` 只验证预生成观测，完整冷启动入口仍需明确打通 |
| 图纸多层校正 | legacy/as-drawn 分派、证据整合、多层协调已接 CLI | 冲突处理、信息完整性和泛化需实跑检验 |
| 窗 | as-drawn 补窗已接线且有实际产物 | 不能推广为所有图纸都能完整恢复；B5 仍拒部分 assumed existence 并要求匹配楼层外形 |
| 门/门洞与连通 | 有未分类对象台账与部分观测 | 通用开口、连通和源隔断表达尚不完整 |
| 朝向与视图匹配 | 候选/假设朝向、方向声明和 manifest | 自动多源匹配与冲突仲裁尚不能视为已实现 |
| 建模与配对 | 确定性 polygon/面内核、墙及相邻层切配 | 现行短边检查仍可能阻断；任意通高、斜屋面、三维体量未证明支持 |
| 几何查看与确认 | 离线交互式 3D 查看器、flow 确认/恢复入口 | 完整窗移动、墙推拉、自然语言回写仍属提案 |
| 下游输出 | IntakeOutput / IDF / EnergyPlus 链可复用 | 最近完整 case 尚未贯通；物性协作者交付需对接口验收 |
| 外皮体量输入 | 可复用几何原语和查看出口 | 专用输入适配和内部推断原型尚待建立；现有 B5 对假设开口和楼层外形有限制，不能直接当通用体量入口 |
| CAD 与混合输入 | 有 CAD/GT 工具和图纸资产 | GT 工具不等于生产 CAD 入口；现有图像评测测试仍禁止 case_data 带 DXF/DWG，接 CAD 时需区分用户输入与评测答案后调整；融合与降级尚待实现 |
| 质量、成本与多模型 | 检查、judge、运行记录及配置基础 | 目标档模型从新实验开始形成可比较实测基线 |

旧文档中的“两个腿”常指房间几何与热区再划分，和现在的图纸/外皮体量两条输入路线不同。源房间应保留，热区优化作为下游派生。
历史单次高分或带人工干预的结果只证明当时条件下的表现，不作为普遍能力或强制 pilot 流程。

改进方法见 [reading](reading/README.md) 与 [几何一致性](geometry_consistency/README.md)。其余旧能力文件是历史跳转，不另设排期。

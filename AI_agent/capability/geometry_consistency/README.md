# 几何一致性：证据先于吸附

一致性检查用于发现矛盾，不能自动决定哪份数据代表设计事实。原始输入、源房间和重要隔断应保留；容差分工见 [坐标与几何](../../architecture/coordinates_and_geometry.md)。

## 有用的检查顺序

1. 先核对单位、尺度、原点、方向、楼层和参考面。内皮/外皮/轴线不同不能直接按坐标差判识读错误。
2. 区分墙面、分段墙线与物理墙对象；同墙可能拆成多段，一个线段也不能仅靠邻近就归并。
3. 用投影重叠、方向、距离、厚度、相邻房间和原始引用筛候选。相互最近可以减少误配，但不证明同一性。
4. 合并分段后再比较整体几何，保留原残差和测量依据。层间墙带相互重叠只能提示待核，不能证明必然应对齐。
5. 分别检查区域覆盖、面配对、开口宿主和空间完整性。已有配对全部合法不保证应该配对的区域没有遗漏。

## 如何处理不一致

有直接来源的转换误差可修实现；冲突事实保留并解释。模型用途允许时可以生成独立的简化版本，标出移动、合并或忽略的几何及理由，再核对下游影响。
不要为抹去窄条统一吸附所有楼层、粗网格化所有墙，或静默删除小房间/门窗。相差多少才值得处理由输入可靠性和输出用途决定，不能继承旧表中未经当前验证的固定阈值。

用户在当前会话明确取消模型国别/规模上限，允许 Astra、6.1 Sol 等 work model，并将目标定为10分钟内稳定整楼交付；随后授权“按这个目标做”。该授权覆盖本轮实施、必要验证与目标案例冷启动，不扩展到收费API回退、DeepSeek或其他输入路线。

## 方案与验收

- 复用已有 single_model 入口与同一源 BIM/kernel；一个模型处理六张原图，避免主要路径上的读图员提交、历史任务选择与重派协议。
- 统一草稿/报告有界读取；失败稿的报告与成功稿一样绑定原始证据，分页引用在后续修订后仍定位原稿。
- 补齐跨层隔墙/外轮廓物理边界的检查与规整覆盖，保留尺寸证据、拓扑保护、最终源 BIM 门槛和原始审计。
- 不扩大角色、不新增通用调度框架、不降低空间/开口/连接质量门槛。

验收要求：原六张sm25图纸、独立冷启动、无开发者中途提示或改稿；模型主动完成整楼源 BIM 与查看器，端到端墙钟不超过600秒，并通过独立空间/门窗宿主/连通质量评价。超时兜底产物、离线成功、单层候选和人工补步骤不算目标通过。初次成功后同一冻结版本再做两次冷启动，用3次结果报告有限样本的可重复性，不宣称统计可靠性。

## 本轮改动和边界

- HTTP/SSE 保留可判定的服务类型、错误码、retry hint、request id、传输异常类型和阶段；缺 usage 继续保留未知。普通重试、限流排队、上下文修复和恢复检查点都遵守禁止或未知 retry hint。
- 终态接续是操作者明确选择的新运行。原运行只读、不修改旧 checkpoint，不自动重放原失败请求。旧版本、配置、预算和图像由原 journal 与哈希附件验证，剩余额度只允许一个新目录承接。
- 复用已明确提交的读图交付；通过但未提交的平面仅作为草稿，必须在新任务中读取、再试建、显式提交。链式接续保留原证据与交付顺序，正式交付优先于同范围旧草稿。
- 图纸、模型/档位、角色、6 并发、候选限制和上下文策略保持原配置。无机械上下文上限，无新增 token 上限。
- 维护停机不作为执行时间。新运行扣除旧运行已消耗的请求、工具、活动时长和 ledger 保守占用；不是恢复原来已经过期的墙钟截止时间。

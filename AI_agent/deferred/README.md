# 暂缓事项

这里保存未进入当前计划的候选。只有重启条件出现时再评估，不把旧提案逐项补完当研发目标。

| 事项 | 暂缓理由 | 重新评估条件 |
|---|---|---|
| idfpy / BEM 结构重构 | 当前主线是可用几何，已有下游可复用 | 真实 case 证明现有下游接口无法满足输出，且协作者接口也不能解决 |
| 全面 token / 缓存优化 | 缺少新路径的实测质量、成本和耗时基线 | 目标档模型实跑显示具体瓶颈，能用局部优化验证收益 |
| 自动角色调度与大规模治理 | 不应成为真实 case 前置 | 产品实际多 agent 工作量需要，并有明确节省或质量收益 |
| 全实体 BIM / 多求解器同时扩展 | 超出第一批轻量模型交付范围 | 指定下游场景需要，且表面模型或薄转换层不足 |

CAD、混合输入和模型编辑属于产品方向，阶段安排看 [计划](../plan.md)，不因这里的旧文件名称被永久排除。
旧 [idfpy 提案](idfpy_embed.md) 与 [token 提案](token_optimization.md) 仅用于追溯。

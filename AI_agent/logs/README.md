- [worklog](worklog/)：按日期的状态与交接；本次见 [2026-09-08_takeover.md](worklog/2026-09-08_takeover.md)。

- [reviews](reviews/)：旧派工、执行和审阅记录，继续可查；后续不要求每个任务产生这些文件。
- [downstream_agent_changes.md](downstream_agent_changes.md)：历史下游修改记录，触及相关实现时按需参考。

当前状态只维护在 [plan.md](../plan.md)，当前开发规则只维护在 [AGENTS.md](../../AGENTS.md)。
新日志写清目的、命令、提交、实际结果和未验证范围即可，不复制长篇旧纪律。

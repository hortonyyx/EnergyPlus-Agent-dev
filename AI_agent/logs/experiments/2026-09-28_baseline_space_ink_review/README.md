## 本包解决什么

已有墙路径检查只检查模型声明的墙。漏掉的墙根本不在声明中，模型可能一直检查自选对象并确认错并的房间。新包在每次成功的 `build_plan_bim` / `revise_plan_bim` 后，检查本次编译房间内部的原图像素，返回贯穿内缩区域的水平/垂直中性长线；附完整干净房间与标线副本，保留原坐标映射。所有反馈绑定候选、源哈希、编译稿及原图。

这不是墙识别器，不自动拆房，不把零线条算通过。家具、柜体、文字也可能命中；斜线、短线、断线、低对比线、边界附近线以及未建房间可能漏掉。前三个命中房间自动附图，全部命中房间和报告路径可见，超过图数/24条摘要时明确标出截断。模型仍需结合完整原图作判断。

原型思路来自已完成的 Opus 调查。本实现另处理黑白底、实际凹形掩膜、连续采样段、像素相对内缩及完整裁图映射；不是直接采用原型的语义结论。默认过滤参数在本次九份历史产物重放前固定，没有按误报继续调参。

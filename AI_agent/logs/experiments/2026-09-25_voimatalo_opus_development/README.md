## 依据与取舍

新增观察（只读原单体 GLB，未用父瓦片/OSM/GT/内部图纸）：`observe_interior_cues.py` → `observations/`（带米制格网的近视图；保留 3 份可查询像素缓冲），`measure_band_windows.py` → `observations/west_band_windows.json`。

1. **两端是贴邻山墙，不是缺资料的外立面。** 南端 y=-33.4、东端 x=19.5 在所有高度直到约 22–26 m 系统性缺面，而其余街面/院面都扫到；南端缺面轮廓呈邻楼屋面剪影（中部约 26.5 m、两侧约 22–23.5 m），其上露出的浅色墙条无窗；东端只在约 25 m 以上露出暗色无窗墙条（`observations/south_end_grid.png`、`east_end_grid.png`）。判为街区贴邻山墙，F1–F7 表示为无窗实体墙；退台两端仍未知。
2. **南端交通组。** 沿街 y≈-32.3…-26.1 是一组玻璃：旧清单的高玻璃竖带每层有两道横带（楼梯中间平台特征），本轮又量出紧邻的玻璃列（F2–F7）；其正下方首层是带亮色招牌的暗色门洞。判为主楼梯间＋主入口。楼梯间北侧沿街只有顶两层小窗（本轮量出）→卫生间/服务。内院侧无窗段、被裁凸出体的扫描洞以及南屋顶凸起（机房读法）→电梯/服务核。
3. **北端交通组。** 内院转角退后段每层一扇窄窗＋实墙，上方北屋顶凸起 → 楼梯电梯核；旁边无窗内部小块 → 服务间。
4. **双面走廊。** 长翼进深 14.5 m、两侧均为 3.1 m 模数的窗，1950 年代办公常见单间办公室沿中廊布置；两端交通组要求一条连通走廊。走廊位置、宽度、柱网均为假设。
5. **不按朝向或每扇窗拆房。** 同侧连续单间合并为“办公带”，并声明为本档简化；西北角因两列非标准大窗单列为角部房间。若用户要更细一档，可按窗间墙继续切分（本任务未做）。
6. **所有隔墙在外墙处落在已观测窗间墙内**（验证逐个检查了 77 个隔墙端点），任何旧窗都没有被移动或裁剪。
7. **首层与缺失开口补全。** 北面首层整段缺扫描，但北立面与西街面同为深色饰面（院内是白色抹灰），公开记录有沿街商业 → 按西街面首层节奏推断 5 组店面窗＋北门厅和两处店门；西南主入口门也是推断。均在源中标为推断，不当观测。
8. **保留为未知且写明原因。** 内院被裁凸出体接触面（深度/用途不明，不补体量）、内院南端部分可见的多格玻璃列、短翼内院东端扫描洞（x>15.3）、首层内院缺面、退台两端。

## 使用限制（独立复核后补充）

- **贴邻山墙**在源里只是无窗实体墙及推断依据；后端需根据实际邻接条件显式映射，不能直接当已验证的室外或绝热边界。本轮没有运行EP或测得负荷误差。公共条件需求见 [PUBLIC_INTERFACE_NOTES.md](PUBLIC_INTERFACE_NOTES.md)。
- **办公带、零售大厅、卫生间/服务间是合并表达**，不是逐间房间或逐间温区；需要逐间分析时先按用户选定档位细分。
- 南端电梯只假设在南核一处，南楼梯间只作楼梯；台数未建模。
- 屋盖五部件是外壳几何部件，不是可达的使用空间，因此不参与门连通要求。

## 二、怎么做的（⛔ 三条纪律）

1. ⛔ **不重写判分器。** 复用 `reading_grade.grade()` **一个字不改**，只把**两侧一起**换成像素单位。
   —— 自己另写一个"像素版判分器"就是又发明一套定义（[[recompute-gate-must-mirror-producer-definition]]）。
   **判分器的打分路径实测是单位无关的**：`grade()` 只做「常量比常量、区间比区间」，
   唯三写死米制的 `TJ_*` 常量判分器自己声明 "ANNOTATION ONLY -- never touch a score"。
2. **产品侧只取原始像素观测**：`pos_px` / `runs_px` / `support_cols_px` / `gaps[].{lo,hi}_px`。
   **产品的标定碰不到它们** —— 这正是判别实验要切断的那条腿。
3. **答案侧用【判分方自己的】尺子**：manifest 的 `pixel_to_source_m` ∘ 视图的 `world_from_source_m`，
   ⛔ 一个字节不来自产品。这把尺子 08-27 已过真 holdout。

**信任根自检**（探针启动即断言，不过就 exit）：产品读的 PNG 与 manifest 绑定的 PNG
**sha256 逐位相同**（`6512c86e…`）⇒ 排除「VLM 像素帧 ≠ 文件像素帧」那一族。
两把尺子在同一点上差 **~1 mm**（产品 `m_per_px` 0.021633914 vs 判分方 0.021638876，差 0.023%）。

**像素容差**（由米制容差 ÷ 判分方 `m_per_px` 得到，⛔ 不另外发明）：
`pos_tol 3.697 px` · `end_tol 13.864 px` · `extra_min 4.621 px` · `span_min 0.8`（比例，无量纲）。

## 六、⛔ 我自己在本实验里犯的两个错（都被自己的自证断言接住了，逐字记下）

1. ⛔ **组合次序写反**：像素文档里那个字段虽然**叫** `pos_m`，装的却是像素
   ⇒ 我"扰动米制通道"实际扰动了像素通道本身，读出一片 FAIL。
   **正解 = 先扰动原始文档，再转像素**（像素模式只读 `*_px`，那一步应当看不见）。
2. ⛔⛔ **端点配对方向假设错**：世界 y 与像素行**反向**，`runs_px[0]` 对应 `runs_m[1]`。
   我按下标直配，`run:y` 残差 **7.29 m**，把米制那一列彻底污染，
   **差点据此写下「像素空间丢了免费的正确性」这个结论**。
   ⇒ 改成**两种配对都试、取残差小的、并硬要求 < 1e-3 m**（自证，不靠我判断方向）。
   修正后残差 **≤ 9e-5 m**，方向自证为 `flipped`，那条"结论"当场蒸发。

⭐ **共同教训**：两次都是**我对表示的假设**错，不是被测对象的性质。
⇒ **凡跨表示比较，变异必须在两个表示里【等价】，而且这件事要让探针自己证明，不许我口头保证。**
同族 [[free-correctness-evaporates-when-representation-changes]] · [[proxy-mistaken-for-the-thing]]。

## 八、⇒ 对第 ② 步（一体改）的直接含义

1. ✅ **「描图分接到像素空间」的可行性已经用真产物验过** —— 不必重写判分器，
   只需把**两侧一起**换单位；`grade()` 的打分路径实测单位无关。
2. **判分侧需要的三件都齐了**：判分方自己的尺子（过 holdout）· 产品的像素通道（齐全）·
   洞口像素区间（在 `gaps` 里，需提层）。
3. ⭐ **C4「多画」是最该搬的一项** —— 上一轮实测它在两把尺子的分歧量级上就翻倍，
   而像素空间里它**逐位不动**。
4. ⛔ **本实验不回答**：立面（一条都没做）· sm24（`raster_overlays` 是空 `[]`，这条路在那儿不存在）·
   逐点 holdout（sol 要的「每视图 ≥3 个非共线点、报 max 与 RMS」**仍未做**）。

## 运行入口

```bash

python AI_agent/logs/experiments/2026-07-21_sm24_gt_extraction/probes/final.py    # 拓扑到腔体
python AI_agent/logs/experiments/2026-07-21_sm24_gt_extraction/probes/final2.py   # 再加逐边外扩
```

依赖：`ezdxf` + `shapely`（仓库已装）。样本硬编码为
`AI_agent/logs/experiments/2026-07-21_sm24_gt_extraction/work/sm24_source.dxf`。
`final2.py` 是 `final.py` 的超集（含外扩），单跑它即覆盖全部数字。
（`stderr` 有大量 `no default font` 警告，是 ezdxf 无字体环境的噪声，与几何无关，`grep -v` 掉即可。）

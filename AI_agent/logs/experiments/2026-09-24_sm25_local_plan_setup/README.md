# sm25 保存墙网局部修订

用户允许 GT 辅助，指出 DXF 后续也要作为输入模态；本程先解决局部返工丢其他隔墙，再有界恢复收工。GT/DXF 的用途和浮点/画图误差口径见项目目标与评价正文。

新增通用按 ID 局部修改工具，不含 sm25 坐标/房间数。`run_recovery.py` 从 run42/draft_004 及原首层 PNG 启动一次 GLM 订阅恢复，medium、1800秒。开发只选旧稿和通用复核/保留范围，不提供正确墙段、遗漏开口位置、数量、GT、标注参考或开发修复模型。不是冷启动。

`replay_local_edit.py` 是另行开发受控离线回归，已知假墙分段后14空间/30开口，其他16条隔墙和30个开口声明保持；`controlled_replay.json` 保存结果，不提供给模型。22项相关离线检查通过（局部操作、失败原子性、恢复/过期散列、MCP实际源反馈和既有像素编译行为）。

生成后 `audit_run.py` 复用旧原图冻结参照和 GT F1，验证局部修改重放/保留清单、源显示重放、实际图像返回及空间/宿主/连接。GT 原始三维与忽略高度的8cm平面诊断分别记录，不更改 GT 或候选迁就分数。完整结果见 run43/README 和最新收工。

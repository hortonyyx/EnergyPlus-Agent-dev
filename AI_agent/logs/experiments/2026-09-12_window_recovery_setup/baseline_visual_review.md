## 可直接从图纸读出的事实

- 四张立面均给总高 **6600mm**，并把一层标为 **3000mm**、二层标为 **3600mm**。因此候选的 `F1 z_floor=0, ceiling_height=3.0`、`F2 z_floor=3.0, ceiling_height=3.6` 与图上的楼层链一致。这里的 **3.6m 是 F2 的层高，绝不是 F2 的世界高度基准**。
- `North_view.png`：一层有 3 樘窗，各宽 2400mm；二层有 2 樘窗，各宽 3600mm。图上水平尺寸链分别为 `1240 / 2400 / 2660 / 2400 / 2660 / 2400 / 1240` 和 `1950 / 3600 / 3900 / 3600 / 1950`。
- `South_view.png`：一层有一处门、2 樘 2400mm 宽窗，以及左侧门右边一樘悬空的 **1200mm 窄窗**；其下方水平链为 `3440 / 1200 / 1660 / 2400 / 2660 / 2400 / 1240`，窄窗的左侧竖链为 `1500 / 600 / 900`。二层有 **4 樘彼此分开的 1200mm 窗**，每侧一对，两个窗之间标 720mm。平面 `2f_view.png` 也显示二层南边四个分开的窗带。
- `East_view.png`：每层各有一樘居中的 1200mm 窗，水平链为 `3400 / 1200 / 3400`。`West_view.png`：二层有同样的一樘 1200mm 窗；一层居中的是门，不是窗。两层平面也可见这些端部窗/门。
- 立面竖向尺寸支持：北窗和南侧两樘 2400mm 宽窗的一层窗台为 1000mm、窗高为 1600mm、距一层顶 400mm，即世界 Z 约 `[1.0, 2.6]`；南侧窄窗另有 `1500 / 600 / 900` 链。东一层端部窗为 1000mm 窗台、1800mm 高、距顶 200mm，即约 `[1.0, 2.8]`。二层窗的竖向链为相对 F2 楼板 1000mm 窗台、1800mm 高、800mm 至屋顶，即世界 Z `[4.0, 5.8]`。

上述高度来自图上的尺寸链；并未由房间命名、既有候选或上下文假设补出。

## 应保留的不确定性

- “宿主相符”只指平面中该外墙开口落在候选相应的外侧房间或走廊段。图纸没有以候选的 `F2_O1` 等 ID 标注房间，不能仅由本次查看确认这些语义名称。
- 未做像素标定、回叠或自动正确性判定；本记录没有给任何构件移动、房间重分割或尺寸拟合建议。
- 二层南侧的四窗事实足以指出候选漏窗/合并窗，但它们各自应绑定到哪一个候选房间、精确世界起止坐标和是否需要先调整候选分区，仍需在单独的原图证据与当前源模型中核对。

# sm25 三段连续走廊的辅助判读输入

`reviews.json` 为本程开发助手直接查看两张原始平面图后的三个局部语义决定，不是 GT 房间分组，也不是运行模型的冷启动输出。

- 一层 L043/L044 的第一处缺口：位于纵向走廊与下部横走廊相交处，没有横穿纵向走廊的墙或门扇。
- 一层 L039/L040 的第一处缺口：两侧办公室隔墙同高，但走廊中间没有将它们连起来的隔墙。
- 二层 L041/L042 的第一处缺口：同样是上下贯通的走廊；旧单面 passage 标签不应生成一个横穿走廊的实体开口宿主。

每条决定绑定原图摘要、冻结 reading/compilation 字节摘要、墙 ID 和已有缺口序号。执行时从编墙产物推导跨度，不填写 GT 坐标或人工房间列表；保留原 reading 的冲突分类。图片身份还须与候选冻结 view manifest 相符。原图路径已记录在每条 JSON，图片和旧输入不修改。

复用这些决定属于辅助重建；正常 pipeline 尚未自动从图片产生此文件。后续读图/校正模型可通过相同输入契约提供有依据的决定，仍需独立评价。

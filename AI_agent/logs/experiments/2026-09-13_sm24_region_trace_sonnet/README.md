# sm24 东南空间颜色连通区与边界追踪（Sonnet 独立观察）

本 run 用一张 sm24 一层原图验证“模型自行选颜色连通区，再提交完整空间边界和开口”的局部观察方式。输入未提供 seed、旧 BIM、旧观察、房间数量、人工像素坐标或 GT；任务要求模型自行定位最东南房间，并把门弧、门扇与逻辑墙线分开。本次只读观察不修改生产模型或输入。

## 实际工具流

实际模型先查看整张 `1f_view.png`，随后进行了两次颜色连通区域观察：

1. `region_001` 选择 seed `[530, 780]`、背景色 `[0, 0, 0]`、容差 60。它只得到 bbox `[525, 769, 546, 851]` 内的 1,722 像素、0 个图像洞；返回图显示这是房间内家具/线块形成的窄黑色矩形，不是目标空间。模型没有把这次错误 seed 直接当作房间轮廓。
2. `region_002` 改选 seed `[460, 800]`，颜色和容差不变。它得到 bbox `[403, 702, 602, 869]` 内的 25,424 像素及 1 个图像洞。返回轮廓覆盖东南房间的实际折角，但也如工具警告所述沿北门弧、南门弧和家具绕行，图像洞只表示被家具等非匹配像素包围，不能解释为建筑洞。

模型随后查看北门、南门及总尺寸标注局部，只提交一次 `preview_space_trace`。`trace_001` 用六个顶点把上述颜色轮廓规整成闭合 L 形，并登记南侧外门 `[411.5, 868.5]–[446.5, 868.5]` 和北侧内门 `[558.5, 701.5]–[592.5, 701.5]`；预览返回后即以 `drawing_fidelity: not_evaluated` 选中，没有第二次修订。

## 离线核验

重新运行：

```bash
python AI_agent/logs/experiments/2026-09-13_space_trace_setup/verify_trace.py \
  AI_agent/logs/experiments/2026-09-13_sm24_region_trace_sonnet
```

核验结果保存于 [trace_verification.json](trace_verification.json)：输入问题和原图哈希、隔离观察输入、两张区域图、`trace_001` 几何重放、三次实际返回图以及最终选择哈希全部一致。选定 trace 的 `geometry_errors` 为空，表示六点环与两个开口在计算上可执行；这项检查不证明原图判读、墙参考面或标定正确。

本次局部结果改善了此前最关键的图意对应：识别出房间西北折角，南侧开口作为外门、北侧开口作为内门，两个开口也都放在相应的南北宿主方向上。不过它仍不能直接回写 BIM：

- 东、南外墙的 trace 实际压在外墙室内侧边线，而 `basis` 却写成 exterior face，声明与预览不一致；若直接换算，会把墙厚方向上的偏移带入源空间。
- x 锚点 `[240, 0]–[612, 10]`、y 锚点 `[885, 0]–[135, 20]` 没有精确落在可见的 10000/20000 总尺寸延长线端点，且分别给出约 37.2 与 37.5 px/m 的轴向比例。工具已标记 `calibration_unverified: true`，当前世界坐标不能当作可靠尺寸。
- `region_002` 的原始轮廓仍沿门弧并绕家具；六点 trace 是模型对图像候选的语义规整，不是颜色连通结果自动证明的墙线。

因此这是“房间形状和开口宿主方向识别有所改善”的局部观察，不是完整 BIM 成功，也不是可直接执行的几何修订。后续若用于恢复，需先统一外墙参考面，并用实际尺寸延长端点重新标定后再预览核对。

## 时间与用量

[runtime_audit.json](runtime_audit.json) 由既有离线账本脚本生成。唯一一次只读调用请求 Sonnet、low effort，实际主模型为 `claude-sonnet-5`，124.39 秒完成且未超时。CLI 记录 Sonnet 8,224 输出 token、119,161 cache-read input token、21,633 cache-creation input token，另含 CLI 辅助 `claude-haiku-4-5-20251001` 的 1,045 input / 18 output token。一次调用的 CLI 估算合计为 **$0.2901043**，只是估算，不是订阅账单。本 run 没有父 Agent 回执，124.39 秒就是记录到的本次串行调用时长，不与子调用时间重复相加。

本次审计未调用模型、网络、GT 或 reference review 实验。

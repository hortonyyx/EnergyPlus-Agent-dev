# 请求估算校准

本批只校准请求 token 估算，没有做角色能力小测或整案。`Qwen3.8-27B` 与
`Qwen3.8-Flash` 各做三条纯文本和三条合成图片请求，共 12 次；无重试、无回退，
总输入 15,674、输出 34、合计 15,708 token。凭据只从主树 `.env` 读取规定的两个
Paratera 字段，没有写入记录。

[attempts.json](attempts.json) 是先计数、再外发的持久账本；12 个 `runs/*/events.jsonl`
及其内容寻址附件保存现有 adapter/EventStore 记录的完整请求和完整回包。
[summary.json](summary.json) 按最终校准后的算法重新计算偏差。原始回包的 usage 仍在各事件
日志中，不以汇总替代。

校准后，12 条点估算的最大绝对偏差为 9.45%；预算使用的安全上界 12/12 覆盖实报输入，
最小余量 1.14%。两条标点密集的长文本点估算低 2.20% 与 2.19%，说明近似分词器不能当成
服务端精确 tokenizer；安全上界负责吸收这类误差。图像三种尺寸在两个模型上都逐项精确
吻合：224×224 为 66、896×896 为 786、1600×1200 为 1902 token。既有 sm24 东西立面
的实报 2380/2513 也由同一公式精确复现。

运行脚本 [run_calibration.py](run_calibration.py) 的硬上限为 12。计数达到上限后重跑不会
再调用模型；每次外发前先原子更新 `attempts.json`，进程在未知响应状态中断也不会自动补发。
脚本只生成低压缩体积的确定性合成图，实际新增证据小于 1 MB。

上下文长度的来源与限制见
[runtime_request_estimation.md](../../../../design/runtime_request_estimation.md)。27B 保守采用官方
checkpoint 原生 262,144，而非未经 Paratera 证明的可扩展 1,000,000；Flash 档案分开保存
原生 262,144、可扩展 1,000,000 与 endpoint 未核实三项，请求入场同样保守使用原生
262,144。

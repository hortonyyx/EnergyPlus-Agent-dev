# sm24 四立面开发辅助识读

## 结论

四张立面共同给出单层外轮廓高 **4500 mm**。11 扇窗分成两种竖向规格，不能统一成一个窗高：

- 大窗：底高 1000 mm，高 2400 mm，顶高 3400 mm；对应 `N1`、`E3`、`W5`。
- 小窗：底高 1000 mm，高 1800 mm，顶高 2800 mm；对应 `S1`、`S2`、`E1`、`E2`、`W1` 至 `W4`。
- 三处外门洞口均高 2400 mm，图示底高 200 mm、顶高 2600 mm。北门和东门宽 1600 mm，是带上亮的双扇门；南门宽 900 mm，是带上亮的单扇门。门扇、把手和上亮内线属于同一个门洞，不另算窗。

这些数值均以立面灰色外轮廓底边为 `z=0`。图中没有室内完成地坪（FFL）标记，门底的 200 mm 可能表达勒脚或室内外基线差，但现有输入不足以把门底改成 0。源 BIM 若以外轮廓底作为墙底，可直接使用上述 z 范围；若另设完成地坪，需由平面或用户补充基准后整体换算。

## 量测方法与复核

实际逐张查看了 `East_view.png`、`North_view.png`、`South_view.png` 和 `West_view.png`。只读取了这四张图和 `testdata_prompt.json`，没有读取 GT、旧 reading、旧 BIM 或历史答案，也没有调用外部模型/API。

[measure_elevations.py](measure_elevations.py) 用 PIL 载入图像，numpy 分离灰色外轮廓与青色洞口线，再用 scipy 连通域合并门框并排除门扇内嵌框。灰色墙框以打印的 20000/10000 水平总长和 4500 总高标定，得到每个青色外框的像素坐标与毫米反算值。原图各段尺寸链再逐段相加复核：

- 东：`5700+1600+1540+4800+740+1200+2380+1500+540=20000`
- 北：`540+4800+2520+1600+540=10000`
- 南：`540+1500+2500+900+2520+1500+540=10000`
- 西：`540+1500+2380+1200+1740+1500+1220+1500+3080+4800+540=20000`

运行命令：

```bash
python AI_agent/logs/experiments/2026-09-16_sm24_developer_reconstruction/measure_elevations.py \
  --output AI_agent/logs/experiments/2026-09-16_sm24_developer_reconstruction/elevation_pixel_measurements.json
```

[elevation_pixel_measurements.json](elevation_pixel_measurements.json) 保存脚本原始反算。像素反算与标注值的最大可见偏差约 10 mm，来自抗锯齿线宽和包围框取边；最终装配值采用图上明确标注，不用像素小数替代尺寸文字。图上尺寸未写单位；结合 `20000 × 10000` 外框、声明面积 200 m²及常规建筑图表达，本记录将其解释为毫米，这是单位推断而非额外几何修正。

本记录是开发助手用工具完成的原图识读示范，用于给源 BIM 装配提供可追查参数，不是工作模型独立生成成绩。

# sm21 首层原图冷启动设置

本轮只测原图一层的完整实体分区、门窗平面位置及门连接。输入仅为未经改写的 `1f_view.png`；不提供二层、立面、建筑声明、旧观察/候选或评测答案。工作模型为既有订阅 `glm-5.3-flash`，1800秒上限，无Claude/DeepSeek回退。模型选择图像观察与量测，像素墙网交确定性代码围合/确定开口宿主；不要求手工枚举整案顶点。

运行：`python -m AI_agent.logs.experiments.2026-09-23_sm21_cold_plan_setup.run_glm`。独立输出为 `2026-09-23_sm21_cold_plan_glm_run31`，已有目录不覆盖。

`original_observations.json`及`developer_original_review/`是开发侧独立原图对照，**不送入工作模型**。清单在首个候选生成前保存，以原图整体15000/8000mm标注建立尺度；门窗端点及房间内点用于生成后的平面位置/宿主/连接核对。允许的端点误差与代表墙面差分别记录，不混同高度验收。手工原图解释仍需目视复核，不宣称自动语义判定。

`audit_run.py --run RUN`仅允许生成结束后执行：核输入及代码哈希、精确源/显示重放、独立原图回叠与门窗清单，再读取独立GT且只选择明确标为`Floor 1`的楼层做分区诊断。GT坐标不拟合输出；其他楼层不进入分母。高度依据不在本次输入中，假设值即使碰巧与参照相同也不算还原成功。

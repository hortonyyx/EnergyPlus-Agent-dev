## 全流程行为观察

原始事件日志保存每次请求、工具参数与返回、产物、候选及运行回执。dev model 逐角色观察并记录：

1. 调度员盘点输入、派读图任务的顺序与并发；服务拒绝、排队和重试。
2. 读图员看整图、裁剪、量测的选择，首次试建与成功试建、首次错误、根据反馈修改的内容、实际提交。
3. 一步建楼的每次尝试与成功时刻；跨层对齐、开口宿主、装配复核是否重复。
4. 高度的依据与应用；超过 30 cm 的平面／立面开口位置分歧数、双原图查看、裁决、重读与重新装配。
5. 调度员返工是否修到问题、是否引入新错误，最终交付或停止原因。
6. 各角色请求数、耗时、token 与缓存；总用时及关键路径，和 domain v52 的对应行为对照。

`observe_run.py` 的里程碑只代表首次工具调用，必须结合工具返回核实成功；调用 `finish_bim` 不等于交付成功。正确阻断未裁决的分歧不记为 domain 故障。

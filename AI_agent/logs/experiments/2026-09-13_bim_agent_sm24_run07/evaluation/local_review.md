# run07 局部恢复独立复核

结构化评价确认东南局部有明显改善，但整案仍是 `severe`，不能称为成功还原。

东南房间 `BottomRightOffice` 相对 GT 的 IoU 从 **0.527 提升到 0.981**，对称差面积从 **12.438 降到 0.496 m²**，Hausdorff 边界距离从 **1.645 降到 0.199 m**。它已从 seed 中过小的矩形恢复为带折角的区域；剩余主要是折角竖边约 0.194 m、顶部横边约 0.047 m 的偏移，因此在 0.02 m 评价容差下仍为 severe。

相邻 `Corridor` 的 IoU 从 **0.660 提升到 0.892**，对称差从 **15.615 降到 3.672 m²**，Hausdorff 距离从 **3.44 降到 0.76 m**。局部空间重分配基本纠正了南端归属，但走廊较北侧仍保留 y=7.3 对 GT y=8.06、y=14.38 对 GT y=14.0 的旧错误。全层缺失/多余内部边界长度只分别减少约 1.653/1.874 m，其他东侧错误没有随本次局部恢复消失；`MeetingRoomBig` 和 `TopRightRoom` 的 severe 指标完全未变。

对象身份没有被重建洗掉：8 个空间 ID 全部保留，只改 `BottomRightOffice` 和 `Corridor`；L 形增加两片墙面。22 个开口 ID 均无增删，11 扇窗字段未变。两扇既有门发生局部变化：`D_Corridor_BottomRightOffice` 保留身份、2.1 m 高度和连接空间对，但从走廊竖墙移到新的北侧横墙；`D_S_Rear` 几何未变，宿主和唯一空间归属由 `Corridor` 改为 `BottomRightOffice`。连接仍为 11 条，无增删，只有 `D_S_Rear` 的空间归属改变。

窗评价仍是 `typed_v3_window_comparison_not_integrated_in_this_diagnostic`。**11/11 只是数量相等，不是位置、宿主或尺寸匹配得分。** 本复核只说明局部 GT 数值和源对象身份变化；原图回叠所见的标定偏差、外墙参考面与其余东侧边界问题仍需另行处理。

# 还原质量与失败草稿反馈实验

本批针对原墙网编译失败只返文字的问题，补充原始声明叠图，并将运行提示从抢早首稿调整为保真与图证修订优先。不是重新定义源模型几何检查，也不让编译器替模型补墙或裁门。

[运行脚本](run_quality.py)使用sm24五张原图、原始建筑声明，Sonnet medium，1800秒上限；无旧候选、旧观察、正确房间数/墙坐标或GT。新运行目录为`2026-09-14_bim_agent_sm24_run18`。开发侧指定质量实验和可选墙网能力，运行中不反馈具体答案。

对比旧run17时须同时说明：输入由仅平面变为五图，时间预算和反馈也改变，不作单变量消融或稳定性结论。旧错误重放只证明原始声明被正确显示及源拒绝行为保留；新运行的还原质量需要生成结束后的独立对照。

结果与采用判断将在运行、核验结束后记录。当前采用基点仍sm24/run12、sm21/run22。

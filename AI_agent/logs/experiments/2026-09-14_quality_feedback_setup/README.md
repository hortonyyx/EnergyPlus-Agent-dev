# 还原质量与失败草稿反馈实验

本批针对原墙网编译失败只返文字的问题，补充原始声明叠图，并将运行提示从抢早首稿调整为保真与图证修订优先。不是重新定义源模型几何检查，也不让编译器替模型补墙或裁门。

[运行脚本](run_quality.py)使用sm24五张原图、原始建筑声明，Sonnet medium，1800秒上限；无旧候选、旧观察、正确房间数/墙坐标或GT。新运行目录为`2026-09-14_bim_agent_sm24_run18`。开发侧指定质量实验和可选墙网能力，运行中不反馈具体答案。

对比旧run17时须同时说明：输入由仅平面变为五图，时间预算和反馈也改变，不作单变量消融或稳定性结论。旧错误重放只证明原始声明被正确显示及源拒绝行为保留；新运行的还原质量需要生成结束后的独立对照。

**结果：正常结束但还原失败，不采用。** [run18](../2026-09-14_bim_agent_sm24_run18/README.md)用937.07秒生成7空间/9窗/8门，源自洽、原图/声明与源图运输、重导出和离线查看通过；独立分区severe，仍有错误拆并、走廊截断和开口缺失/合并。只建一次，没有据源反馈修订。当前采用基点仍sm24/run12、sm21/run22。

[两份旧失败的原样叠图重放](failed_draft_replay/index.html)与[核验](failed_draft_replay/verification.json)通过。新run18首份声明即编译成功，因此新失败图没有在这次真实生成中触发；不能把离线MCP检查冒充模型实际利用失败图纠错。

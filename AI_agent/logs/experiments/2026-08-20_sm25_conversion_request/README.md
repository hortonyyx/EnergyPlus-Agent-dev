## 4. ⛔ 阻断项二：`min_room_area_m2` 沿用 sm24 的 2.0 是错的 → 应为 **5.0**

`A_room` 是**纯按面积二分**（面积 > A_room 算房间，否则算墙）——**形状盲**。
sm25 的墙带面是长条形（周长 × 墙厚），最大 4.93 m²，**超过 2.0** ⇒ 被当成房间
⇒ 2F 数出 19 个腔体（15 房 + 4 个墙带）。

**A_room = 5.0 下（修复图，2F）识别完美**：

```
腔体 15 个：走廊 70.25（54 顶点，整块未被切）· 大会议 29.12 · 上部 17.54/17.33/17.11
            · 下部 14.23/13.80/13.80/13.80/13.69 · 右列 7.06/7.06/6.84/6.84/6.84
255.31 (房间) + 34.69 (墙) = 290.00 (楼层)   差额 0.00
```

与主控从 `2f_view.png` 逐间数出的 15 间**逐间对应**（左上 2 办公 + 1 会客 · 右列 5 · 中部 1 大会议 · 下部 5 · 走廊 1）。
**依据**（⛔ 不是"调到能过为止"）：本楼最小真房间 6.84 m²，最大墙带面 4.93 m² ⇒ 5.0 落在两者之间且唯一合理。

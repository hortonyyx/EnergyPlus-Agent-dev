## 3. 三条结论

### ⭐ ① 两抽相差 2.8 倍 ⇒ 这个量级的单次成绩就是噪声

9.0 % vs 24.8 %，同模型、同图、同文档、同范围、同预扫档。
**如果只跑一遍，本轮结论完全取决于抽到哪一个。**
08-01 A 臂那个 35.8 % 落在两抽之外，与「它同样是高方差过程的一次抽样」一致
⇒ **回溯地看，此前所有单抽成绩的可比性都应打折。**

### ⭐ ② 「探针次数」不是「有没有去量」的代理指标（对 08-01 判据的修订）

- **d1 调了 5 次探针**、拿到 27.47 mm/px，**但自述内墙是
  *"traced via visual inspection rather than dimension derivation"*、±0.2 m**，
  并写明「时间花在外轮廓和主分隔上，内部细节没余力」⇒ 9.0 %。
- **d2 只调了 1 次探针**，却直接消费预扫的 `calibration_span_candidates`，
  两轴得 **36.4 / 36.375 px/m、跨轴一致性 0.04 %**（门限 0.30 %）并显式记录「标定接受」⇒ 24.8 %。

⇒ **量得更好的是探针更少的那一抽。** 判「有没有测量」必须看**标定与坐标的来源**，
不能数工具调用次数 —— 08-01 用探针数下的判断在此被修订。

### ⭐ ③ 标定变好了，但**内墙仍然靠目测** —— 分数就丢在这里

d2 的标定质量（0.04 % 跨轴一致）已经很好，**但标定本身不产生内墙位置**：
读图器仍要逐条描墙，而它对内墙用的是目测。
**两抽都在同一处失守**，这是 W1/W3 没有覆盖到的环节：
「先量再画」被理解成了「先把比例尺量准」，而不是「每一条墙的位置都要量」。

**另：平面窗 0/11 连续第三轮全崩**（07-30 / 08-01 / 本轮），与减卷无关，是独立的能力缺口。

## 5. ⛔ 本轮撞出的真缺陷（第一次真用 W4 才现形）

**减卷判卷跑不通**：两抽首次判卷均得 `{"kind":"rejected","error_code":"score_view_binding_invalid"}`。
根因 = GT 侧信任根校验没有把考试范围传下去（`score_inputs.py:141`），
拿全部五张当「必需」与收窄后的两张对不上。

**为什么三道关都没拦住**：W4 补的那把 L8 锁断言的是 `score_vs_gt is not None`，
而**判卷器「拒绝」时产出的侧车也不是 None** ⇒ **锁绿着、判卷其实是拒的**。
GLM 对抗审与主控轻门都验了机制（冻结 / 防漂移 / 消费侧收窄），
**但没有任何一方真的跑一次带范围的完整判卷看它出没出分。**

⇒ **治理教训升级为两条并列**：
- **「探针 ≠ 锁」**（证据只证明当时跑对，不会在改坏时变红）；
- **「非 None ≠ 成功」**（断言写在返回值存在性上，等于没断言）。

修复见 [返工单 r4](../../reviews/request/2026-08-01_w4_scoped_scoring_blocker_r4.md)（commit `caca860`）；
**识图产物已落盘冻结，重新判卷是确定性的、未重跑识图** ⇒ 本轮数据未受影响。

## 6. 归因边界（不得越界解读）

- 本轮相对 08-01 基线同时变了**三件事**（W1 文档 + W3 回执 + W4 减卷）⇒ **不是单变量对比**，
  不能说「W1/W3 有效」或「无效」。
- 两抽之间**唯一差别是抽样**，故 §3① 的方差结论是干净的。
- 减卷是否本身影响质量，**本轮无法回答**（没有同期全卷对照臂）。
- n = 2，§3② 的「探针数不是代理指标」是**机制性观察**（有自述与标定数字支撑），
  但「少探针更好」**不是**结论。

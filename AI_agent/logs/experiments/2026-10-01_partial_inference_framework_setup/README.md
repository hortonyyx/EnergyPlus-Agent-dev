# 部分推理初步框架与双开发模型试验

用户确认 Voimatalo 修订02精细档达标后，要求继续推进，并指定开发模型测试用 **6.1 Sol、6 Sol**。本包沿用统一 BIM 工具与源协议，提炼既有 Claude 实现和 Astra 用户调试经验。

## 实现

- `bim_agent_guidance.py`：将重复网格说明移入按需 `partial_inference` 参考，说明证据、尺度规整、建筑解释、参数装配和实际保存源的复查。不放入本例坐标、房间数、窗表或固定解释。
- `bim_agent_inference.py`：保存观测／推断／简化声明，按需绑定实际源对象和哈希；检查当前绑定。源审计报告尺度、类型、窗分布、楼层成员、门位／高度／连接，以及修订前后逐对象变化。数值描述不冒充规范合格或建筑验收。
- `run_bim_agent.py --prepare-only`：只冻结输入和说明，不调用模型、不提前消耗计时；共用 MCP 注册新工具。
- `bim_agent_bridge.py`：让有代码／看图能力的开发代理调用相同 MCP 工具，保存请求、回执和原始返回图；禁用局部模型委派。不是新增建模管线或正式 GPT 订阅路由。
- 公共查看器吸收已验收演示版的剖切点选修复，隐藏的面不再截住点击或遮挡判断。

## 试验条件

[冻结清单](test_manifest.json)保存353份公共文件哈希、[运行快照](frozen_runtime.tar.gz)、Python依赖版本、同一任务和指引、输入与补充图出处。两模型各一次、`max`、最多3600秒、24次候选保存，无自动重开／回退／局部模型；生成方法自行选择。

原始单体GLB，加4张历史父瓦片的无标注局部原始渲染图。补充图的视角由历史开发选择，不能称“仅单体GLB独立完成”。不提供已验收源、方案坐标、窗量测表或案例装配器。基准经过用户共同调试，独立试验未获得这些逐案纠正；比较建筑效果和可迁移方法，不宣称复现实测内部。

通过协作工具明确指定 `gpt-6.1-sol`／`gpt-6-sol`，上下文从空白开始，各有相同内容的独立运行环境和工作目录。允许读写范围由指令限定，**不是操作系统读隔离**；前后核运行代码、输入和指引哈希，并保存自述。协作接口不提供单独的底层模型回执、token或账单，用量保留空值，不估算费用。

[准备脚本](prepare_tests.py)不调用模型；[控制记录脚本](control_test.py)记录启动／时限／哈希，结束时核完整性。`tools.jsonl`与`bridge/`保留实际工具行为；失败和返工留在各自run。运行结束后由主助手将产物归档、独立评价并更新状态。工作模型试验及还原B/C批次不在本次范围。

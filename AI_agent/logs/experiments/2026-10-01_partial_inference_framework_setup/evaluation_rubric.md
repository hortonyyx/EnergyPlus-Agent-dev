# 部分推理开发模型结果复核口径

本口径只用于两个开发模型运行结束后的独立复核，不提供给运行中的模型。评价对象是各自实际保存并交付的源 BIM、查看页、观察与工具记录，而不是最终文字自述或候选数量。

## 对照边界

已验收精细档证明了一种可接受的建筑表达，但不是唯一答案。它经过开发者历史经验、旧候选和用户逐轮纠正，部分屋顶处理还参考过早期剖切记录；本次两个测试只取得原始单体 GLB、四张无标签父瓦片上下文图和通用“精细办公楼”任务。应据此评价框架能否支持模型独立形成合理方案，不能要求复现验收源的坐标、空间／门窗数量、房间切分、核心位置或特定隐藏面读法，也不能把与验收源不同直接判错。

两次测试的条件相同，分别报告各自完成程度和证据，不选最好的一次替代另一模型的失败。开发模型经验、人工纠正、其他模型或未准入资料若进入运行，须单列为条件破坏，不能计为框架成功。

## 必要的建筑质量

以下各项看实质关系和保存结果。出现漏掉主要体量、系统性吞窗、不可用薄片交通空间、假楼板切断连续核心、普通房间普遍错误接入楼梯间、大片无理由开敞外墙等问题，属于主要失败，不能由几何检查通过或书面免责声明抵消。

1. **整体与楼层关系。** 目标单体、主体与翼／附属体、主要标高、退台和屋顶轮廓应与准入证据大体一致。裁切或缺面应被当作证据不足，模型须用有理由的实体、开口或未定项处理，不能自动解释为建筑开洞或不存在。
2. **精细但可用的内部组织。** 结果应有成体系的办公室、交通和必要服务空间，不停留在少量整层大盒子。房间进深、开间和走廊尺度应具备建筑合理性；连续开敞空间不能为凑矩形、朝向或热区而凭空拆分。窗节奏和窗间墙应约束隔墙落点。本例用户已明确主要重复部分倾向一窗组一间；这是本例精细档偏好，不作为所有建筑的固定规则。两窗合并若有合理尺度或角部理由可以单列，但系统性合并为长办公带不能凭“也可能如此”视为达到了用户所验收的细度。测试未获这条逐案纠正，因此建筑合理性与对齐用户偏好分别报告。
3. **交通与连续空间。** 普通非屋顶分解空间应有合理的入口和通往建筑入口的路线。楼梯、电梯或服务核心应具备可容纳其用途的平面尺度，并与相关楼层实际接触；采用跨层连续空间时，周边楼层应避让其体量，不能为套重复层而插入假楼板。核心的数量、形状和具体位置允许有证据相容的替代方案。
4. **窗、门与隔墙共同成立。** 可见窗组及其间墙带应被保留，异常窗也不能被模板抹平。推断补窗或无窗隐藏面须明确为推断。隔墙不能切穿窗；开口须有真实宿主，不得靠缩短、删除或移动已观察开口来清除宿主冲突。
5. **门位符合通行关系。** 房门应先选择合理的走廊或交通侧，再在真实隔墙上留出可用门垛、墙端和开启／平台余量。不得机械采用最长共墙或把所有门放在墙中点。相邻房间成对错位、靠端布置等均可接受；验收源采用的统一门宽和代表线余量不是通用阈值，评价其尺度与所表达关系是否合理。
6. **屋顶和上部用途不荒谬。** 大面积上部体量不能仅因有面积就统一标为办公室。阁楼、机电、楼梯／电梯延续、竖井、空腔或纯屋顶几何可按证据作合理组合，并保留用途不确定性。主要屋顶高低和显著附属体属于建筑效果；坡曲面、设备细件、屋顶分房和检修路径的精确深化为低优先级。
7. **证据与推断诚实。** 观察、推断、简化和未解决项应可区分；无内部资料时不能声称恢复了真实室内。关键方案应说明使用了单体网格还是四张上下文图、缺少什么信息以及为何选择当前解释。多个方案同样受支持时，较简单且仍满足建筑功能的方案优先；“简单”不能成为漏建可见对象的理由。
8. **保存源可核查。** 必须交付实际源 BIM 和可查看结果，并从保存源复核形体、层、房间、门窗宿主和连通。几何应无实质正体积重叠、未建立开口或不明覆盖缺口。重要推断记录、保存源审计和最终选择应存在；审计数量和范围只描述结果，不自行证明建筑正确。

## 允许差异与低优先事项

以下差异本身不构成退步：房间总数；有明确尺度或局部例外理由的多个窗合并（标准层细度仍按上项核查）；双走廊／中走廊等合理组织；交通核心和卫生间的具体位置；隐藏端墙有窗或无窗；屋顶附属空间的类别与拆分；合理网格规整后的尺寸；门扇方向和未建五金。应看各选择能否同时解释证据、尺度、宿主、连续空间和通行关系。

本阶段不以毫米级贴图、完整踏步栏杆、法规核算、EP 物性／热区、真实租户用途或完备屋顶设备为验收项。公共名称可读性有问题应记录，但稳定源 ID、物理关系和可查看性优先于多体块楼层编号是否符合日常楼层称呼。

## 结论等级

- **框架验证成立：** 已形成完整、可查看的精细方案；上述必要关系没有实质失败；关键推断和保存源均被实际复核。允许保留有边界的隐藏面、真实室内和屋顶细节不确定性。
- **部分成立，需修复：** 工具与方法已产生实质方案，但有一至数个明确的建筑关系、覆盖、开口、交通或保存复核问题。列出问题首次出现的位置及可局部修复范围，不因计数好看判通过。
- **未成立：** 未交付有效源／查看结果，仍是粗壳；主要体量、空间或连通显著不合理；大量可见证据被丢弃；或运行使用了未准入答案、人工／其他模型纠正。

最终报告分别给出：使用过的准入证据、实际建筑组织、必要项发现、允许差异、未检查范围、推断记录与保存源审计是否真正采用，以及相对本次“原单体加四张原始上下文、无人工纠正”条件可以支持到什么程度。不要用验收源的对象逐项差分充当唯一评价，也不要从评价结果向仍在运行的测试模型追加提示。

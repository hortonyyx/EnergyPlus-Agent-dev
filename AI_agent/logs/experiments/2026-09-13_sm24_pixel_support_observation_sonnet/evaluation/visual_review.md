# sm24 Sonnet 像素支持观察独立复核

本复核只读取同一张原图、Sonnet 终答、实际工具轨迹及四份像素 profile，不使用 GT、历史正确坐标、网络或模型。结论未提供给任何生成任务。

## 结论

Sonnet 比同题 Haiku 明显改善：它找到包含目标内边界的正确局部范围，识别出西侧折返墙、东侧外墙及一条青色门扇线，也没有把南立面外窗再解释成第二扇门。新工具使这些判断能逐项回查。

但终答仍没有给出一条可直接用于建模的完整内边界与开口端点。它把门的铰点和门扇末端当作 opening endpoints，又补出一段原图没有的连接墙线，并把东侧外墙列入“与 circulation 相接”的边界折线。北侧水平墙的视觉判断基本落在正确区域，但所称灰色 profile 支持并不存在于整段。因此这次可算“目标定位与主要对象分类部分成功”，不能算精确量测完成。

## 工具实际支持的部分

| Sonnet 说法 | 实际 profile | 原图复核 | 评价 |
|---|---|---|---|
| x=462，y=701–755 的竖向 return wall | profile 001 C01 精确返回该峰值及连续支持 | 是目标空间与走廊间的西侧折返墙面 | 量测与语义均成立 |
| x=604–610 的竖向墙 | profile 001 C03，峰值 x=604，支持 y=672–779 | 是建筑东侧外墙 | 量测与语义成立，但不属于题目要求的内边界 |
| y=751，x=430–456 及 x=462 | profile 003 C02 精确返回这些断续支持 | 是折返处向左延伸的水平墙面；裁图在 x=430 截断其余部分 | 量测与语义成立，范围明确为局部 |
| x=590，y=698–728/730 的青色直线 | profile 004 C01 精确返回 | 是门扇的直线笔画 | 量测与门符号分类成立；它不是开口第二端点本身 |
| x=546–547，y=767–779 | profile 001 C02 | 是下方家具线，不是墙或门框 | Sonnet 没把它正式纳入边界，避免了 Haiku 的主要错误 |

profile 002 的青色 y 扫描有 60 个匹配像素但没有任何候选。Sonnet 没有把空结果当作“无门”的自动证明，这是合理的；不过终答末尾“没有发现其他青色弧或 gap”的措辞仍比该 profile 能证明的范围更强。

## 未获所称量测支持的部分

profile 003 在 y=697 的 C01 只返回 `x=559`、`592`、`602` 和 `604–610` 几个离散支持点，没有返回 x=430–559 的连续灰色区间。原图局部视图确实能看到向左延伸并终止在门铰附近的水平边界线，但其主要线色没有被这次 `[128,128,128] ± 40` profile 捕获。

因此终答的“y-axis scan: peak y=697 … horizontal wall … terminating around x≈559”混合了两件事：峰值行由工具检出，完整墙段则来自视觉观察。把 `(430,697)→(559,697)` 写入折线可以作为带裁图截断说明的视觉观察，不能称为 profile 已量得的连续灰墙。

## 门洞与折线问题

- `(559,699)` 附近是门符号的铰接位置，`(590,730)` 是门扇/弧线末端附近。两者描述门扇运动几何，不等于墙洞两侧的两个宿主端点。
- 终答明确承认没有确认独立第二门框线，却仍在 polyline 中写入“opening/door gap”并以门扇端点代表其范围，精度等级前后不一致。
- `(590,730)→(604,730)` 在原图中没有相应实体墙笔画；它是为把门扇末端连到外墙而补出的线，不能进入实际墙面折线。
- x=604 的东侧外墙真实存在，但题目限定的是房间与 circulation 相接的 interior boundary。把整段外墙放入该折线扩大了任务范围，也掩盖了内边界与外边界尚未连接清楚的问题。
- 西侧 x=462 竖墙和 y=751 左向墙被另列为“separately”，没有与北侧墙、开口组成一条连续且方向有序的边界路径。因而回答虽识别了折返，仍未交付所要求的完整 polyline/segments 关系。

## 裁区与执行范围

Sonnet 查看整图后先裁 `[400,600,620,880]`，再缩到 `[430,660,620,780]`；后者覆盖了目标门符号、折返墙和东侧外墙，是合适的局部范围。相比 Haiku 从 x=480 起裁掉西侧折返，本次定位成功。

实际调用为 `inputs` 1 次、`view_image` 3 次、`view_pixel_profile` 4 次，无工具错误。四份 profile 的候选数依次为 3、0、3、1，保存图、原图哈希及支持区间均已由随 run 的确定性检查复算一致。

选用 `min_fraction=0.05` 使最低候选门槛只有 6 或 10 个像素，保留了 y=697 等稀疏行。工具如实返回了这些离散支持，但模型仍需检查连续区间，不能因该行成为候选就把它扩展成整段墙。

## 适当结论

本次实验证明 Sonnet 能消费编号候选并用原图排除明显家具/外窗误读，也能定位一个真实折返和一条门扇线。仍缺少开口两侧真实宿主端点、北侧墙段的匹配颜色窄条量测、以及按边界顺序组织的完整内墙路径。该观察适合做后续复核线索，不应作为可直接执行的房间 polygon 或门洞坐标。

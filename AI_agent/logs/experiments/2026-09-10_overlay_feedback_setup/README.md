# 原图回叠反馈实验准备

用户希望把产出回叠原图放入 pipeline，让模型据原图迭代校正。本轮仅推进还原建模；新增的是当前实验 BIM Agent 内的反馈，不宣称旧 flow 已统一替换。

从 run12/candidate_01 和其六张原图新建 run13，600 秒，Sonnet 订阅主模型；Haiku 仍可由它按需调用。传入范围见 [预登记条件](experiment_design.json)，只传 scope 字段，其他评测/边界说明不进入模型上下文。没有具体错误楼层、墙、坐标、开发侧标定点、GT 或既有评价。模型自行选择需要检查的图面和方法；本轮明确指定原图回叠这一反馈方面，不冒称完全无提示实验。

显式回叠时登记图像与楼层的标定，新 build/revise 自动沿用，返回实际图像和元数据。只由新显式标定更新对应图面；候选/旧投影保留，失败不丢 BIM。几何自洽、叠图生成和原图正确分别报告；不新增外部 judge 或 GT 到生产生成流程。实现与真实 stdio 检查由 5.6 Terra high 处理，主助手负责实验、独立评价与文档，均在同一方向。

实现冻结、定向离线检查通过后只做一次新真实恢复，运行中不追加已知答案。完成后核对原图/源/标定摘要、实际工具轨迹、几何和备注变化，再做独立分区/窗诊断及必要查看验证。判断是否形成有用反馈循环，不仅统计图片数量；保留失败、未核范围和标定风险。历史辅助 seed 使本轮不属于冷启动，也不是单因素对照。

不调用 DeepSeek、付费 API 回退或 EnergyPlus。结果与后续见 [本轮工作记录](../../worklog/2026-09-10_overlay_feedback.md)。

实现冻结为 [a8293086](implementation_commit.txt)，[9 项离线检查](offline_validation.json)通过；[run13](../2026-09-10_bim_agent_sm21_run13/README.md)已正常结束，真实调用两次显式回叠、一次备注修订并自动收到两张新源回叠图。图面标定保持不变，物理几何也未改；模型说明仍有尺寸链/对齐误判，未取得新的几何改善。

事后 [verify_feedback.py](verify_feedback.py)核对每张源/原图/锚点及重渲染像素，并读取实际模型流的 image block；通用产物与几何查看继续复用前轮脚本。[browser_delivery_check.py](browser_delivery_check.py)仅检查新增交付内容、链接和内嵌查看器。这些审计均在生成结束后使用，不向生产模型提供答案。

## 用法

从仓库根执行，输出必须是新目录：

```bash
python -m scripts.tool_scripts.bim_regression_report AI_agent/logs/experiments/2026-09-27_reconstruction_quality_monitor/runs.json --out /tmp/bim-quality-review-new
python -m pytest -q -n 0 tests/test_bim_regression_report.py
```

配置每行指定case、condition、run；condition是明确的实验条件组，不用它给不同提交的结果强行配对。默认读取run/evaluation/original_openings.json，历史sm25完整门窗审计单独指定opening_audit（相对仓库根）。可选feature_count指定run内已验证的实际使用计数字段；非负整数0代表没有触发，不是失败分数。notes是已核明的语义限制，不参与自动改分。

报告只读取summary、输入/调用回执、最终选择的源BIM、既有独立审计和浏览器报告。逐文件记录SHA256，拒绝重复把同一run计作独立样本。未结束或缺审计的条目仍列出；候选/源哈希不符时不采用旧评分；缺指标和零分母保持未知。条件比较包括输入、scope、生产文件哈希、实际模型、思考档、时限、候选额度、续查、系统指引及实验覆盖；没有可控采样种子/服务端隐藏状态时不声称完全随机条件受控。阶段内名称/说明或累计日志变化不是生成策略变化，当前报告也不替代实际轨迹检查。

已完成13项定向检查，覆盖保留最差结果、不同输入/恢复/实验条件不混算、缺失/中断不丢弃、未触发功能、旧候选/旧源评分拒绝、零分母、重复run和容差变化。15份实际run均可消费，全部被读取的原证据哈希在运行后复核保持。普通离线检查不需要新增模型回归；生产能力提升及稳定性尚未证明。

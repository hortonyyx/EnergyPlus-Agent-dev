## 条件与实际运行

只推进还原建模。用 `a8293086` 从 run12/candidate_01 恢复，仅带已生成 proposal 和六张原图，开发侧明确本轮采用原图回叠反馈，没有给具体错误楼层、墙、位置、正确坐标、开发侧锚点、GT 或旧评价。历史 seed 有人工辅助背景，不是冷启动；本轮改变工具与 scope，不是单因素比较。[预登记条件](../2026-09-10_overlay_feedback_setup/experiment_design.json)保留原样，只传其中 scope 给模型。

实际主模型 **claude-sonnet-5，medium**，Claude 订阅，一次调用，272.66 秒正常结束；上限 600 秒。CLI 估计 1.5339005 美元，不是订阅账单。本次没有调用可选 Haiku、DeepSeek、付费 API 回退或 EnergyPlus。见 [回执](agent_receipt.json)、[汇总](summary.json)、[实际工具记录](tools.jsonl)和无损压缩的 [原始模型流](agent_stream.jsonl.gz)。

| 环节 | 实际证据 |
|---|---|
| 模型自行标定 | 对 seed 显式叠图 2 次，各用对应原图的锚点；保存 calibration_001/002 |
| 修改与自动返回 | 1 次 revise_bim，仅 set_notes；同一响应实际包含 2 个 image block，产生 overlay_003/004 |
| 标定沿用 | 两张自动图的锚点、依据和图像摘要均与登记一致；分别绑定新 source 摘要 |
| 旧记录保留 | seed 的 overlay_001/002 保留，交付明确列 2 份旧源投影和 2 份当前源投影 |
| 开口回查 | 1 次清单读取；seed 及新候选各 4 份完整自报观察回查，均无 finding；当前 4 份与旧源 4 份分开 |
| 实际改动 | 更新本轮假设/未解决项和操作审计；全部房间、楼层、外形、门窗坐标与连通保留 |

新候选仍为 **14 空间 / 84 源边界 / 15 窗 / 14 门洞**，源几何通过。两张自动 PNG 与 seed 对应 PNG 字节相同，是因为物理几何未改；source 摘要因备注和修订审计变化而更新。不能用新图数量或 source 摘要变化冒称发生了几何校正。

## 反馈效果与限制

[回叠执行审计](feedback_verification.json)逐图核对实际源/原图摘要、登记锚点及重新渲染的完整像素，4 份均通过；模型流证明修改响应确实带 2 张图，未只返回文件路径。模型随后选择继续回查并再次交付。这证明反馈运输与持久化可用，**不证明模型正确识别了差异**。

模型登记的一层跨轴比例差异实际约 **0.527%**，却在说明里写成低于 0.5%；二层约 **2.719%** 已被它承认并写回待核，但没有重新标定。它写出的两条北向分尺寸链分别合计 14.76m、14.88m，而非声称的 15m；原图另有 15m 总尺寸，并不能使分链等式成立。本次没有 pixel_profile、map_pixels 或 map_dimension_chain 调用，目测/心算不能记成成功的确定性量测。

一层原图上仍能看到部分源隔墙线落在绘制墙线左侧；其“所有隔墙紧密对齐”的结论过于乐观。生成结束后的独立分区比较仍 severe，窗仍 15/15（13 完整、2 容差内），与 seed 相同。当前目标不因 severe 标签就转向 GT 厘米精修，但也不能把遗漏差异称为已经核准。模型新写入的窗口偏差与其它未核项保留为模型说明，不冒充开发侧全部认可的测量事实。[具体说法审计](evaluation/tool_claim_audit.json)在生成结束后单独保存，没有回流生成。

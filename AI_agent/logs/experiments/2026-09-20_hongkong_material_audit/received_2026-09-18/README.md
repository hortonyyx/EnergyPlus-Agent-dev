2026-09-18 取得。**15 栋**，来源为香港地政总署「可視化三維地圖（單體化模型）」，
按[案例梯度](../../../AI_agent/design/textured_mass/case_ladder.md)的三个轴铺开。
来源与许可背景见 [sources.md](../../../AI_agent/design/textured_mass/sources.md)，
获取路线见 [acquisition.md](../../../AI_agent/design/textured_mass/acquisition.md)。

## 为什么用这个源

- **逐栋独立对象**：包内按 `BUILDING / TERRAIN / VEGETATION / INFRASTRUCTURE / GENERIC` 分目录，
  每栋一个文件夹含独立 `.gltf + .bin + 贴图`。**不需要任何几何裁剪**，也不存在「树和楼粘连」。
- **格式直接可用**：glTF 2.0（FME 2024 生成），采样器 `wrapS/wrapT = 10497 (REPEAT)`、
  `extensionsUsed: None`、无 alphaMode、普通 JPEG 贴图——`mesh_observation.py` 的门槛**逐项满足，零改动**。
- **许可干净**：data.gov.hk / CSDI 通用条款，免费、商用非商用皆可，唯一限制不得转售。

## 取得方式：按需 Range 提取，不下整幅

一幅图幅的 ZIP 是 1–2.6 GB（如中环 11-SW-8D 含 781 栋 / 2.46 GB）。
`fetch_buildings.py` 先读 ZIP 尾部的中央目录，再用 HTTP Range **只取目标建筑的条目**，逐个校验 CRC32。

本批 15 栋实际传输 **24.2 MB**，对应图幅总量 10.3 GB。

```bash
python fetch_buildings.py                 # 取 selection.py 里的全部 15 栋（已存在则跳过）
python fetch_buildings.py --only <建筑ID>  # 只取一栋
python verify_buildings.py                # 逐栋过 mesh_observation 并出预览
```

图幅索引来自 CSDI 的 `file-api`（每幅带 glTF/FBX/MAX 直链，其中的 key 是内置在官方查看器里的公开 key）。

## 校验状态

- `single_buildings/*/record.json` —— 每栋的图幅号、修订日期、ZIP 偏移、逐文件 CRC32、几何量测
- `single_buildings/manifest.json` —— 全批清单
- `single_buildings/verification.json` —— **15/15 通过 `mesh_observation` 校验**
- `single_buildings/*/view.png` —— 预览图。⚠️ **当前相机朝向未调对，多数呈俯视**，
  各栋局部坐标轴朝向不一致，尚未逐栋识别竖直轴；这是预览表现问题，不影响数据本身。

尚未做：与原始航拍影像的独立比对、贴图缺失面的统计、建筑用途核实（轴2 的类型判断来自所在区的城市形态，
**不是逐栋核实的实际用途**）、以及任何 BIM 生成。

## 本地与 Git

入 Git：脚本、选样依据、逐栋 `input.glb`（自包含，共约 7.5 MB）、记录与预览。

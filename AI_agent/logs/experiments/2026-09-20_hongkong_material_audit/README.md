- 新`pack_building.py`将所有buffer/image原字节打入GLB，保留节点、材质、UV和sampler，只加局部平移根节点；源Y-up关系不变。旧15例原件CRC均通过，新15例原场景与平移后逐顶点/UV/材质/贴图字节一致，最大顶点误差0。
- 合成两primitive、第二节点变换实例、第二buffer回归通过。`verify_fetch_integration.py`离线执行真实fetch_building转换逻辑，170面/4实例/4贴图/32.112m高保留，避免修复只存在于辅助脚本。
- 新`review_buildings.py`和离线查看器显示所有网格、原压缩贴图和透明材质，15例各4个方向实际浏览器检查通过，无错误/外部请求；总览15张卡片及2例优先筛选实际验证通过。
- 现有MeshObservation读取14/15，B342原生BLEND透明材质明确拒绝。源材质完整保留，查看器能显示；没有放宽生产工具或静默去面求通过。

## 质量结论及下一入口

2例优先复核：B416…的多排开口/层间带可辨，体量相对规则；B349…两主立面可读但另侧模糊/灰面。6例局部可读、7例不优先；这些是开发助手对四个整体斜视图的判断，不是逐窗测量或真值分数。全部建筑用途仍待核实，灰面不等同实际无窗，也未把楼面窗排直接当内部房间。

“整图像素/总面积”“JPG KB/平方米”、面数及所在地区不能代替读窗、用途或复杂度验收。旧高度轴误读导致单层/高层梯度错置，已撤回作为有效分级；后续先核候选身份/用途及关键正立面，再挑符合普通办公/住宿/商业目标的少数例。必要时从已知可读的Helsinki官方原件补简单单体，Melbourne2020为备选，未扩大下载。

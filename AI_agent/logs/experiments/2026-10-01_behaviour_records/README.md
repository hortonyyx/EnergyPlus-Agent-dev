# 工作模型完整行为记录与跨运行对比（10-01 起）

用户 10-01：“从现在开始模型行为要完全记录，这样方便后续比对”。本目录离线生成，不调用模型、不改生产代码或历史运行目录。

## 记录什么

`python AI_agent/logs/experiments/2026-10-01_behaviour_records/record.py <运行目录名>...` 从运行的原始 CLI 流与回执生成 `records/<运行>/`：

- `record.json.gz`：逐步完整记录——调用时刻与返回时刻、工具名、**完整参数**、**完整文字返回**（返回图片记类型、字节数、sha256，原图另在运行目录）、是否报错、该步之前模型的可见文字与思考 token 估计；每条消息的 token 用量；每次额度读数（5 小时窗口、7 天窗口占用率）；最终回复与总用量。
- `timeline.md`：同一内容的可读表（长参数截短，完整见 json）。
- `summary.json`：对比用指标——首稿时刻、首稿前全图/局部/像素调用数、放大倍数、各立面局部图与立面叠图次数、每条高度依据的来源立面与实际套用立面（按开口几何判断朝向）、报错原文、用量、估价、5 小时窗口占用。

`compare.py` 汇总为 [compare.md](compare.md) / `compare.json`；质量数字取各运行已保存的独立评价，逐行注明来源。

限制：CLI 流里思考块只有签名、没有内容，思考只能记数量；可见文字、全部工具调用与返回均完整。5 小时窗口读数是账户级，可能含同时段其他会话用量。

## 首批对比结论（sm21 为主，sm24/sm25 好结果作参照）

| | 好结果 run57/58 | 修复包 run98/99 |
| --- | --- | --- |
| 房间/位置/宿主/连接 | 通过/29/29/14 | 通过/29–28/29/14 |
| 外墙高度 ≤5 cm | 17/17 | 16/17、9/17 |
| 严格分区 | minor（墙在尺寸值 5.0/10.0/3.0 m 上） | severe（墙在量出的墨线面上：4.989/5.067/2.943 m，偏 4–7 cm） |
| 总时长 / 首稿 | 311–378 秒 / 163–180 秒 | 1081–1125 秒 / 571–777 秒 |
| 输出 / 思考 token | 2.4–2.8 万 / 1.1–1.5 万 | 8.7–10.4 万 / 6.1–6.9 万 |
| CLI 估价 / 5 小时窗口占用 | 1.2–1.6 美元 / 8–9% | 4.2–6.8 美元 / 32–33% |
| 首稿前调用 | 8–20（以全图为主） | 43–45（局部 17–21、像素 13–20） |
| 高度依据 | 6–10 条，均“哪个立面读的套哪个立面” | 3–5 条；run99 三条中两条跨立面套用 |

1. **耗时与用量的台阶出现在 09-27**：sm21 自 run69 起每次原图冷启动的思考都在 5.2–8.6 万、首稿 440–1010 秒；run81 是好结果时期的旧代码、请求逐字节相同，同样为思考 5.8 万、990 秒。主要是模型/服务端行为变化，不是某一版指令造成，后续各版指令也没把它拉回。
2. **高度对错与“按立面记依据”强相关**：好结果（run55–58）、run98、GLM 试跑都没有跨立面套用；退步的 run93/94/99 都有。sm25 好结果也有两条跨立面但高度全对（该楼不同立面窗高相同），所以跨立面应提示核对而非一律拦截。
3. **尺寸精度下降来自做法**：好结果按尺寸标注落墙；现做法按像素量墨线再两点标定，墙落在墨线面上，系统性偏 4–7 cm。
4. run99 最终回复自述“逐立面门窗核对未单独做（平面编译已报零差异）”：只查平面的差异报告给出“0 条”后，被模型当成连高度也已核过的理由。

## 命名核查（同日）

run99 模型内部楼层编号用 1F/2F，属设计允许（内部 ID 不受约束，修订与依据都用内部 ID）；代码生成的公开名照规范为 F1/F2、`Z0x_F1_…`。评价脚本按内部 ID 对楼层是评价侧缺陷，已改按楼层高度。核查另发现两处规范/实现缺口，待与 Astra 协调后在主线修：

- 同一排房间的编号由浮点噪声决定：run99 北侧三间质心 y 为 6.5336925 与 6.533692500000001，六位小数取整正落在 .5 边界，东北间排到了 Z01（run98 为西北间 Z01）。同一栋楼多次生成的公开名不稳定；需要按容差分排后再由西向东。
- 主线 10-01 部分推理改动（`2b83a759`）把楼层公开名改为沿用源楼层名，还原输出的楼层公开名会随模型起名变化，与[命名规范](../../../design/bim_naming.md)仍写的 F1/F2 序号不一致。

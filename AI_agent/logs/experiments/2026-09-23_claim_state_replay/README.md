# 上轮实际产物的状态回放

用 `run_replay.py --out <新目录>` 复制 run26 的候选、原图和已保存观察，离线验证本次改动。无新模型调用，没有新图像识读；替代文字由开发侧明确写入。

为三个已正确的东窗确认现值；在已修东门候选上仅替换过时的“所有门底为0”假设，保留其他门未核假设。结果：东门显示“已应用、当前仍保留”，大窗与双短窗两条观察显示“已核对、无需修改”，待应用清单为空；门下200mm区域性质未定的原观察进入交付。全部空间、边界、门窗和连接逐项不变，源假设和替代历史均保存。

输出在 `artifacts/delivery.html` 与 `artifacts/summary.json`。这是实际产物的开发侧确定性回放，不是 GLM 已自行修复假设或当前采用建筑模型的证据；原始 run26 未修改。

# sm24 East 竖向链 GLM 观察

目的：在水平开口观察通过后，独立核对 East 立面全部三条竖向尺寸链，并绑定门窗外框的原始像素高度。输入只含原始 `East_view.png`，不建 BIM、不读取候选或 GT。

运行通过临时 CLI shim 将实验入口的 `--model sonnet` 映射到项目允许的图像模型 `glm-5.3-flash`；`agent_receipt.json` 的 `actual_model` 已核实为 `glm-5.3-flash`。模型 36 轮、384.56 秒结束，CLI 估算 $0.642716（订阅估算，不是账单）。

结果：

- 屋顶/檐口约 y=229，地面约 y=654，425 px 对应 4500 mm。
- 左链 `1900/2400/200`：门组底/顶 0.2/2.6 m。
- 中链 `1100/2400/1000`：大窗台/顶 1.0/3.4 m。
- 右链 `1700/1800/1000`：中、右短窗台/顶 1.0/2.8 m。
- 门组及三窗 bbox、链端点均绑定原图 profile；三次 `map_dimension_chain` 闭合差为 0。
- 亮子高度仅为视觉估计；中短窗引用右链是量测加同高判断；未检查门扇细节和内部标高。

完整原答在 `agent_receipt.json`，工具原始记录在 `tools.jsonl`，未把事后答案回写任何 BIM。

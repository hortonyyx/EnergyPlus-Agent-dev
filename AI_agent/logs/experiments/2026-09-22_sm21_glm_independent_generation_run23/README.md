# sm21 GLM 独立还原

本轮只给 sm21 六张原始图（两层平面、四向立面）和 `testdata_prompt.json`，未提供 GT、旧候选或旧报告。GLM 使用 `glm-5.3-flash`，1412.21 秒完成。模型先分别建立两层候选，随后合并为 `candidate_03`：14 个空间、29 个开口（15 窗、14 门）、14 条空间连接，源几何自洽检查通过，查看器和交付页可用。

生成完成后才运行独立 GT 诊断。`candidate_03` 的 15 扇窗中 14 扇匹配（9 个在位置容差内，5 个完整匹配；1 漏、1 多），窗高没有出现 z 漂移；空间数量与 GT 对齐，但内部隔墙/走廊边界仍为 `severe`。`candidate_01`、`candidate_02` 是模型生成过程中的单层中间候选，不作为整案采用对象。完整两层结果见 `candidate_03/viewer.html`。

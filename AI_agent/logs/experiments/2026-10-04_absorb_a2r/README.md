## 实现与证据边界（过程中更新）

- 检查点和大 JSON 捕获采用内容哈希树：变动值写新节点，未变节点复用；任一检查点可直接恢复，不依赖逐层回放前一检查点。读取校验所有节点和重建正文哈希，历史普通 JSON 与 A1-R 图片记录仍可读取。小对象保持直接 JSON；节点缓存只加速编码，不跳过读取校验。
- 图片继续按原字节哈希引用，大请求的文本、工具目录与图片模板也可复用。所有真实发送正文仍须在发送前逐字节重建核对。
- 新底座行为报告只保存完整事件文件的相对路径与哈希；`load_behaviour` 可重建相同全部步骤。事件改变后旧报告显式失效，运行结束重新生成；CLI 历史报告的完整压缩格式保持。
- 429 判断依据：[智谱官方错误码](https://docs.bigmodel.cn/cn/api/api-code)。数字码仅用于已识别的智谱域名，未知码停；含“使用上限”的额度优先于临时措辞。旧 S3 只有 HTTPStatusError，不能补猜其状态或正文。中文短句反例明确是合成反例，不冒充真实响应。
- 小测依据：[Messages metadata 定义](https://platform.claude.com/docs/en/api/messages/create)。公开字段仅承诺不含身份信息的 opaque ID，文档没有承诺服务端粘性。小测不用设备标识、会话头或 Claude Code User-Agent；两组前缀仅随机标识不同，长度相同，避免交叉暖缓存。
- 初次普通 `git commit` 的全索引刷新在本文件系统阻塞数分钟，终止后确认只暂存本报告，通过 `write-tree`／`commit-tree`／`update-ref` 完成提交；后续也只提交逐项核过的暂存内容，没有改写共享历史。

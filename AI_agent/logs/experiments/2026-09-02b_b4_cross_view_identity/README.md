# 探针 · B4「跨视图身份配对」到底是不是一个启发式问题

- **日期**：2026-09-02 · **做的人**：orchestrator（主控）· **档位**：**探索档**（⛔ 产物不作成绩）
- **起因**：投影桥设计稿 §7.2 把 **B4（洞口合成）** 标注为「⚠️ 里面藏着一个真问题，⛔ 别当接线」——
  **平面上的那个洞口，和立面上的那扇窗，凭什么是同一扇？**
  当时我写「⛔ 不许用按顺序配 / 按最近距离配这类没人签字的启发式」，但**没给出替代方案**。
- **⛔ 本档【不】动正在跨家族审的那两份**（设计稿 + 第一个探针档，冻结在 `600ebbf`）。

## 一、难在哪（先说清楚）

两边根本不在同一个坐标系里：

| | 坐标 |
|---|---|
| **平面**的洞口 | 世界 xy 的沿墙区间（0.1 mm 整数）|
| **立面**的洞口 | **该立面图自己的局部 x**（`x_range_m`）+ **z**（`z_range_m`）|

而立面的 `x = 0` **不是世界原点，是那张图尺寸链的左端**。

## 二、实测（sm25 四个立面 + 事实层平面）

### 2.1 立面的原点现在是**派生**的，不是手填的

四份 `as_drawn_elevation_v0` 产物的 `calibration.world_zero_source` 全部 = **`chain_fit`**，
并自带交叉核对：

| 立面 | `delta_px` | `delta_mm` |
|---|---|---|
| East | 0.066 / 0.156 | 0.9 / 2.1 |
| North | −0.1 / 0.133 | −1.4 / 1.8 |
| South | 0.332 / 0.081 | **4.5** / 1.1 |
| West | 0.08 / 0.099 | 1.1 / 1.3 |

⭐ 这条**推翻了我原以为还在的一个旧毛病**（[[half-measured-calibration-hides-as-downstream-gap]]：
「尺度靠链拟合、原点靠手填」）—— 在这批产物里**原点已经也走链拟合了**。

### 2.2 ⭐⭐⭐ 尺寸链总长 == 外皮跨度，**逐位闭合**

| 量的东西 | 读数 |
|---|---|
| 事实层外轮廓 bbox | **25.000 × 20.000 m** |
| 中轴口径 bbox（本项目投影桥算法派生）| 24.760 × 19.760（四边各内缩 **0.120** = 外墙 `t/2`）|
| 立面尺寸链总长 | East **20.000** · West **20.000** · North **25.000** · South **25.000** |

**闭合校验**：`24.760 + 0.120×2 = 25.000` · `19.760 + 0.120×2 = 20.000` —— **逐位相等**。
且 East/West 对上 **y 向跨度**、North/South 对上 **x 向跨度**（朝向与轴的对应也自洽）。

## 三、⇒ B4 不是启发式问题（**若下面那条前提成立**）

**可零参数闭合的三步**：

1. **锚**：立面局部 `x=0` ↔ 该朝向**外皮**沿轴起点。
   生产侧不需要外部 footprint —— 外皮跨度 = **中轴 bbox + 两侧外墙各自的 `t/2`**（尺子仍来自数据）。
2. **判据（⭐ 这一步本身就是那道门）**：**`立面尺寸链总长` == `外皮沿轴跨度`**。
   ⭐ **它是等式不是阈值** ⇒ 对不上就**响亮失败**，⛔ 不许配。
3. **配**：两边都换算到世界沿墙区间后，按**区间相等**配对；z 取自立面。

⇒ **⛔ 不需要「最近距离」「按顺序」这类没人签字的启发式。**

## 四、⛔ 但它依赖一条【前提】，⛔ 不是定理

> **「这张立面图的尺寸链横跨整个建筑」** —— 在 sm25 上四张全成立，但这是**这批图纸的画法性质**。
> 局部立面 / 分段立面 / 只画一跨的立面，这条就不成立。

按 [指南 §十三](../../guides/reading_correction_split_guide.md) 的三分法，它属于**前提**：
- ✅ **必须显式命名**并写进契约；
- ✅ **不成立时响亮失败**（而这**零成本** —— 第 2 步那道等式门本身就是它的检测器）；
- ⛔ **不许**现在去实现「局部立面」的泛化（该能力尚未解锁，同 §十三 §5 用户校准）。

## 五、⚠️ 一处必须留缝的地方（⛔ 现在不实现）

第 1 步写「外皮 = 中轴 + 两侧各 `t/2`」时，**⛔ 不许算成一个全局偏移** ——
不同外墙厚度可以不同（sm25 恰好都是 240，那是**读数**）。
⇒ 实现要**逐边取该边自己那堵墙的厚度**，⛔ 不许写 `+0.240` 或 `+2*half_t` 这种全局量。
这就是「别做成升不上去的」在这一处的全部含义。

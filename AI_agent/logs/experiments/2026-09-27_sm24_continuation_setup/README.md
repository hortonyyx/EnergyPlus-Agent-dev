# sm24 保存候选与有界续查

Astra独立开发；使用现有Claude订阅Sonnet/medium，产品不委派局部模型。每个新run只导入run62/candidate_01的proposal和五张原PNG，旧claim、检查结果、GT和开发功能观察不进生成侧。整个run设1800秒总预算，最多两次追加主模型续查；各调用记录分开，沿用同次候选和证据。

本实验检查模型能否根据当前保存状态自主选取并执行后续工作，**不是原图冷启动，也不替换几何更好的整栋基线**。run62的平面误差继承与功能/高度依据恢复分别评价。

## 已确认的界限

追加调用、记录“停止”或源几何自洽均不等于任务完成。源码默认不开启续查（`--continuation-rounds 0`），不能把当前试验机制写成稳定自主完成能力。无源/证据变化时停止只防空转，不证明所有真实有用工作已做完；重复或失败文件也可能改变签名。

房间用途真值仍不唯一。沿用生成侧不可见的[独立原图观察](../2026-09-27_sm24_room_types_setup/semantic_reference.md)：北侧家具解释有歧义；没有用途文字，不能将表内选型或非unknown数量当用途正确率。原图位置、宿主、门连接和typed-GT高度分别沿用原参照/阈值。

99项不同相关离线测试最终通过；纯用途编辑后高度确认应保留、实体宿主改变仍使之失效，贯通测试发现并修复该真实缺陷。第二次只改续查指引，另复用14项续查检查通过；没有跑全量或调用测试中的付费模型。

# Voimatalo 首次工作模型迁移：输入与工具准备

本轮从开发助手已有探索迁移到Claude订阅Opus，用户明确允许本次探索放宽。常规Sonnet级目标不变；此次不检验模型自主处理原GLB、泛化或低档稳定性。

## 输入与人工辅助

`prepare_inputs.py`从历史原始网格观察目录复制14张PNG：7张整体/方向观察、7张完整UV立面正投影。`preparation.json`保存来源及原字节摘要，`building_input.json`保存米制映射、局部坐标变换和已有用途/层数声明。模型不会获得旧BIM、窗位/数量观察、内部布局脚本或GT。现有三维素材本身是米制GLB网格，未转换成体素。

辅助包括开发者此前选定的15度局部对齐、立面位置和三角面筛选。筛选容差为距平面1.25m，并非已验证的物理墙面；附加说明要求结合全景判断凸出/凹入及缺失表面。模型只接准备后的视图，不能将本轮称为原GLB自主冷启动。原单体裁剪遗漏的上下文没有追加输入，此条件与旧展示后续补面版本不同。

只复用原观察和量测方法，不以旧展示的322窗组或165空间作为目标数。内部无真实参照，只评约束一致性、合理性与几何可用性。

## 同一建模入口的最小增量

- `build_parametric_bim`接受模型声明的空间/开口模板及实例；展开重复层、相对标高和源ID，按完整窗跨距匹配唯一宿主，不裁窗或自动划房。跨实例门由模型显式声明。
- 保留逐层L形、退台或独立竖向体的外轮廓JSON往返，共用已有源BIM内核和查看。
- 默认模型仍Sonnet，只有显式`--exploratory-opus`才选择Opus；通道仍为已登录订阅，无付费API或模型回退。普通图纸入口复用现有离线检查。
- 参数化工具是通用几何声明/展开能力；其说明中的数字是独立合成示例，生产代码中没有Voimatalo轮廓、窗位或层数。

37个不同相关离线检查通过（分两次执行，重复部分不加总），覆盖源导出、参数展开、MCP图像/只读隔离及显式模型选项。实际生成/运输/源重放和浏览器核验在run内另记。

## 本轮运行与复核

[首轮Opus](../2026-09-14_voimatalo_opus_transfer_run01/README.md)使用14张PNG和显式建筑声明，medium、2400秒上限，运行选定后生成`delivery.json`。实际耗时与用量以回执为准。首轮命令的scope保存在`agent_request.json`；复现实验必须新建输出目录，不能覆盖旧run。

`audit_run.py RUN`检查实际输入传输、原视图裁切/缩放/网格返回、参数化展开和源独立重导出；`package_result.py RUN`建立原输入与实际源的并排/固定15度坐标叠合查看，未对候选重新拟合；`browser_qa.py RUN`在隔离Playwright环境离线验证实际源查看、旋转、选层和展开。复核工具仅在生成结束后使用，结果不输入本轮模型。

逐动作定位：

1. **看图方式变了，但没按“放大逐个读”做。** 像素工具从 28 次降到 1 次，裁图增加到 32 次，但全部未用 display_scale，多为 500–1500 像素宽的大条带；二层只有 4 张宽条带。
2. **二层南窗按等分放置。** 声明依据写着“bottom row into 4 equal bays”，4 扇窗放在各间正中；原图实际两两贴近隔墙。正是新做法明令禁止的情况，没有被遵守。
3. **一层南侧两道隔墙被漏掉。** 原图是未填色的细双线隔墙（[原图复核](run94_review_1f_south_original.png)，裁取原图 [280,560,1850,1120]；二层见 [此处](run94_review_2f_south_original.png)），模型写“完全开敞、家具不同也按‘不拆连续空间’保持一间”。新原则里“连续开敞空间即使用途不同也保持一间”被当成了不画墙的理由；“不因无填色漏墙”的保护写在做法第 1 步，没有压过它。
4. **完全跳过了第 6 步检查。** 装配后没有看回叠图、源立面或做空间关系抽查，直接记录高度 claim、赋房间用途并交付，说“Given time constraints”，而当时还剩约 1800 秒。

判断：只把指令变短、理顺，不能让当前模型可靠地逐个读门窗，也不能让它主动核对保存稿。单次结果，不代表稳定，但与 run91/93 的共同点一致：**模型不会自己发现声明里的漏墙和按规律补的门窗**。下一步不再同条件抽样，建议把检查量具化——建成后由工具直接报出“图上有、声明里没有的双线隔墙”“门窗声明范围与图上门弧/窗框不符”，模型只需处理报出的差异；同时把 CORE 中“连续开敞空间”一句改为只在图上确无隔墙时适用。

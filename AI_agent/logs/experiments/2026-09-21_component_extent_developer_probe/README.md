# 完整同色范围：开发原图探路

只读sm24原平面/East图，使用现有Toolkit连通区域工具，无GT、BIM或模型调用。所有颜色、阈值、区域筛选由开发选择；本目录没有交给run10工作模型，不计自主识读成绩。

实际保存四次全图overview及十三次逐种子region。它们完整保留失败/分裂的候选，不为预期窗数删选。记录中的bbox是半开原图像素范围，不等于几何开口端点。

| 尝试 | 观察 | 意义 |
|---|---|---|
| 平面 `[0,255,255]`、容差40、最少20像素 | 69个块全被面积阈值过滤，返回空表 | 图上看似亮青色，实际有抗锯齿深浅；空候选不证明无窗 |
| 平面 `[0,200,200]`、容差80、最少20像素 | 37个保留块，178个小块被过滤；东侧长框分成数条线与上下段 | 端点/线段存在，但不能把每个块认成一扇窗 |
| East同参数 | 15个保留块，10个小块被过滤；三个窗框及一樘门的外框/内分格分别出现 | 同一樘门有多个块；构件身份仍须读原图 |
| 平面 `[0,160,160]`、容差130、最少20像素 | 东侧大窗仍分为y381—515与515—558附近的几个块，细框更完整 | 抗锯齿与覆盖标注影响连通；放大原图核组合，不能盲目增加容差求单块 |

实际图像颜色频率曾只读统计以定位第一次空扫描原因；原图中常见青色包括`[0,224,224]`、`[0,176,176]`、`[0,120,120]`，不是统一满亮RGB。此类颜色/阈值没有写进通用方法或run10输入。

开发结合原图判断：平面355—382是灰色墙段，后面的长青色框是大窗，被尺寸线遮断不表示多扇窗。region_002等狭长原图预览已实际查看；应按返回范围再放大带邻墙的干净原图，不能只看一个窄线片。

## 改了什么（每处写明针对的失败，替换不追加）

| 层 | 改动 | 针对的失败 |
| --- | --- | --- |
| 做法（`DRAWING_METHOD`） | 删去“逐排放大读完再建”的前置和“全图太小读不了”的断言；改为读全套图 → 看不清处放大（说明 1600 像素上限，框窄才放得大）→ 优先让每层都有可检查草稿 → 按工具报出的差异和自己的未决项核改 → 高度按“量这个开口的那条尺寸链”读 | run69–94 首稿前 41–77 次调用；run93/94 二层匆忙；run57 零裁图 29/29；run94 整排条带只放大 1.08 倍；run94 高度链挂错对象 |
| 原则（`CORE`） | 隔断对称表述（画了的墙再细也要建，没画的不加）；清报错不许挪门、改为回看该处图；“没看/没辨清/确实缺”三分，只有确实缺或合理查看后仍不定的才作显式假设；坐标换算写清 | run94 一层漏细墙并用“开敞不拆”解释；run94 #47 为清报错改门；run94 二层未放大就“按等分假设” |
| 交付（`FINISHING`/`DELIVERY`） | 交付前把原图能解决的未决项和差异都解决；停止须写明原因；房间用途与改备注给出最小格式；续查提示改用同一段 | run94 剩 1,824 秒未核“二层需放大核对”；run94 用途格式连错 3 次；续查另有一套说法 |
| 工具索引（`TOOLS`） | 像素工具归“量测”，不再限于“具体疑点”；写明图片名须用清单原名、装配参数是列表；关系检查写明用途 | run94 虚构图片名、装配传对象；v1 劝退了 run58 用过的整层剖面 |
| 任务提示（[batch.py](batch.py) `SCOPE`） | 交付要求改序：先几何（隔墙、房间、门窗逐个对照原图），再高度 claim，最后备注 | v1 只列高度 claim 和备注，run94 收尾时间花在清单上 |
| 输入类型 | 运行清单新增 `image_kind`（图纸/体量渲染图/照片/未知），按它挂做法；旧清单无此字段时无体量按图纸、有体量按未知 | v1 把任何图片都当图纸；体量渲染图路径丢了原体量段 |
| 参考 | claim 参考中墙厚段移到 wall_dimensions、改备注段移到 edits；plan_partition 提到新反馈 | 按“完成任务要读的内容”计量时，读取量须低于好结果基线 |
| 看图返回 | 放大被 1600 像素上限压低时明说实际倍数和办法；坐标换算用 `original_pixels_per_returned_pixel` | run94 请求 1.5–2 倍实得 1.08–1.43 倍未察觉；旧说明“×比例”含糊 |
| 平面建模/修改/装配返回 | 新增 `drawing_differences`（[检查模块](../../../../src/agent/geometry/plan_drawing_differences.py)），放在返回最前：图上有而声明没有的双线/填充墙、声明了但图上没有墙、墙上缺口与声明门不符（含端点偏差 >0.15 m）、完全未声明隔墙时的整体提醒。只报告，不拦截，不自动改；比例明显不合理时不检查并提示先查比例 | 漏细墙（run75/83/86/94）、门放在实墙上（run91/93/94）、墙放偏（run74/83/86）在多种写法下反复出现 |
| claim 返回 | 新增只读 `facts`（[模块](../../../../src/agent/execution/bim_claim_facts.py)）：尺寸链合计与起止范围、每个值实际套用到的楼层/墙面/宽度及当前 z、链范围与楼层范围是否相同。不判对错，不改 claim 结构与采信规则 | run94 claim_0001 把 3.6 m 的链套到 3 m 层、三个立面两种宽度的窗；claim_0003 把小窗的链挂到门上 |

## 自动检查的离线验证

[验证脚本](drawing_differences_validation.py)：用三个案例事先由开发侧从原图整理的参照（门窗像素位置、房间内部点）冻结标注，不调用检查本身；再对 108 份历史编译草稿（sm21 64、sm24 21、sm25 23；GLM 与 Sonnet，09-20 至 09-29）运行检查并对照。[标注](drawing_differences_labels.json)、[结果](drawing_differences_results.json)、[人工判定](drawing_differences_adjudication.json)。

| 项目 | 结果 |
| --- | --- |
| 没有任何标注差异的 43 份草稿 | 0 条报告 |
| 漏墙（参照房间被并） | 28/31 报出；漏的 3 处是 sm24 同一种东南折角并房（三次 GLM 运行） |
| 明显错位门（与参照重叠不足一半） | 5/5 |
| 参照门附近没有声明门 / 声明门在参照里找不到 | 31/41、14/25（另 3 份草稿比例错误被跳过，含 36 条门标注） |
| 门端偏差 >0.10 m | 123/141（报告阈值 0.15 m） |
| 对不上标注的报告 | 30 条，逐条看图：29 条是标注未覆盖的真差异（墙放偏、墙画过头、假墙），1 条无法判断，明确误报 0 |
| 修好后报告是否消失 | 下一稿修好的 30 处，报告全部消失；未修的 41 处报告仍在 |

局限：参数是在这批草稿上调出来的（起初 12 份小试后，全量暴露了 sm24 家具双线、sm25 双开门等问题才改），没有独立留出集；run98 才是第一份新数据。只覆盖 CAD 风格的三个案例；外墙窗、立面高度、单线墙、斜墙不检查；“用通道代替假墙”（sm25 GLM）和折角墙并房未能报出。

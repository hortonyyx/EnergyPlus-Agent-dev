# sm21 通用自主复核的实验条件

本轮只做还原建模。检验总 Agent 在没有新错误提示的情况下，能否自己选择原图与局部问题、核对并修订已有候选。

冻结条件见 [experiment_design.json](experiment_design.json)。使用 run10/candidate_02 和原六图；仅将 JSON 中 `scope` 文本作为本轮用户目标传给模型。其余实验说明、旧评价和 GT 不进入生成环境。总模型可选调用 Haiku 局部观察，也可直接用原图与确定性工具处理。

这是一份有过开发辅助的保存候选恢复，不能记作冷启动。新工具只隔离局部模型可访问的文件，主模型仍可能在提问中带入旧答案；事后必须检查实际问题和回答。实现、提示重点和运行条件同时变化，也不能把单次变化归因于其中某一个因素。

生成结束后独立核对图像/实现/种子摘要、模型实际动作、几何变化、源分区和窗对照及可查看性；不将评价结果回灌本次运行。执行结果见 [run11](../2026-09-10_bim_agent_sm21_run11/README.md)。

## 执行结果

冻结实现 `8c14fd4c`；[离线验证](offline_validation.json) 8 passed。真实主调用329.71秒结束，实际`claude-sonnet-5`；只发生一次订阅调用，没有调用局部Haiku。Sonnet自行用原图量测并修订二层四门，原图叠图支持改善；房间分隔未改，分区仍severe，窗仍15/15。

事后核查注意到旧proposal的未解决项本来就列二层门位/宽度待核。这不改变本轮没有新增具体错误提示的事实，但限定了“自主发现”的结论：它完成了一项已有待核线索的自主复核修订，没有证明全面发现未知错误。冻结的experiment_design.json保留运行前原样；本段为运行后的解释。

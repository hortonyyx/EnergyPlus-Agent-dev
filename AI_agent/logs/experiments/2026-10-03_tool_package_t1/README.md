## ④ 时间上限

针对 GLM sm25 到 50 分钟仍只有一层。GLM 默认 6000 秒，`--timeout` 可改；每次工具返回（包括图片与错误）追加已用/剩余分钟。过半且有楼层未保存草稿时提醒先出全楼；剩余不足 15% 提醒停止新读图、只修已列问题并交付；到点拒绝新动作，进程等待以实际剩余时限为限。原有终止进程清理可能多用几秒，清理耗时不算新的建模时间。

预期楼层用 manifest 的 `floor_plan_images` 明示；启动脚本按原有平面文件名声明，通用入口支持 `--floor-plan-image`。未声明时数字楼层文件名仅作可见提示；无可靠范围则完整性为未知。每次从保存源的平面/装配依据及实际楼层重算，不加会话内计数。到点优先保留最近完整全楼稿，即使之后又单独保存过一层或选过部分稿；无完整稿保留最近保存稿，JSON 和 HTML 标明不完整。完整仅指预期楼层覆盖，不宣称几何或原图正确。

验证：脚本模型与模拟时钟覆盖 50%、不足 15%、到点、错误回包、全楼稿之后保存部分稿再超时、只有部分稿以及过期不启动进程。65 个不同相关检查通过（含新增的进程时限反例）。`replay_time.py` 复用 sm25 真实保存时间线：首个可用源在约 1947.7 秒，模拟 3000 秒边界时明确点名 `2f_view.png` 未出草稿。原运行在此处已经被旧时限截停，不声称它真的收到新提醒；详见 `time_replay.json`。

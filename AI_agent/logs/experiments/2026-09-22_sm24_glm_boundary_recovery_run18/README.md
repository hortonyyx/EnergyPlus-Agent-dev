本轮从 run15/candidate_01 恢复，只把原始 `1f_view.png` 和 seed proposal 提供给 GLM；GT、评测结果和旧报告均未进入模型输入。任务限定为复核西南 `conference_W`、走廊南端折角及右下 `room_R4` 接头，已核实的门窗高度和开口清单保持不变。

GLM 使用 `glm-5.3-flash`，476.09 秒完成，CLI 订阅估算 $1.23832（不是账单）。模型通过局部放大、pixel profile 和候选叠图确认：走廊南端墙在约 px y=749–756 处折止，x≈455–462 的下段没有实体墙；西南入口凹槽属于 `room_R4`，而不是会议区。模型据此把 `conference_W` 改为矩形，把凹槽并入 L 形 `room_R4`，并将 `D_south` 的宿主改为 `room_R4`，保留 8 空间、11 窗、10 门和 21 个开口。

候选源几何自洽、查看器和交付页均存在，见 `candidate_01/viewer.html` 与 `delivery.html`。生成后才运行独立 GT 诊断：仍为 `severe`，主要报告内部边界与参照坐标/分段不同；窗户部分诊断仍只比较数量，不能据此宣称整案保真通过。该候选作为原图证据更充分的实验结果保存，不替换既有 `run04/candidate_02` 采用基点。

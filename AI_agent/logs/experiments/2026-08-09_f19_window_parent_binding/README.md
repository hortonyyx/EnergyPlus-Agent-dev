## 7. ⭐ 方法论（本轮换来的）

1. **加一层规范化 = 换表示** —— 与 F-17 那条「换表示会让【免费的】正确性静默蒸发」互为镜像：
   F-17 是**重写丢掉了旧表示免费送的正确性**；本条是**新增的规范化打破了既有比较的相等前提**。
   ⇒ **必答题扩写为两问**：换表示时问「旧表示里有哪些正确性是免费的」；
   **加规范化时问「谁在拿未规范化的形态跟它比」**。
2. **「按下标逐位求差」在环起笔点不同时会把纯顺序差异放大成米级** ⇒ 见到大偏差先分类再定性。

## 对工作方式的具体贡献

| 能力 | 接入位置 | 需要证明的实际收益 |
|---|---|---|
| OCR / 文字定位 | 读数字、单位、标高、名称和门窗表，保留原图/区域引用 | 数字及单位复制准确、位置可回查；减少 VLM 反复读字。不得自行认定数字属于哪个对象 |
| VLM / 检测 / 分割 | 取得完整对象和邻接语境、跨平立面对应、候选区域 | 少漏门/少截端点、减少错套窗型；候选框/掩膜不能直接充当正确源几何 |
| 通用工具模型 | 组织任务、解释冲突、选择工具、落实修改 | 合法工具调用、完整执行并实际保存正确值；长文本自信声明不代替效果 |
| Embedding + Rerank | 从输入说明、工具手册、已授权生产证据中召回小片段 | 召回有用内容并减少无关上下文；不得把评测 GT 混入生成检索库 |
| ASR | 口述要求和后续修改输入 | 转写清楚、保留歧义再确认；有需求时再接 |

同一任务角色可有多个合格模型，一个型号也可承担多个角色。OCR 能独立解决时不必再让聊天模型抄一遍；发生对象对应或跨图冲突再用合适的视觉/推理能力。是否并发、何时升级到辅助和何时复核，由真实失败及效果决定，不固定每案调用所有模型。

## 性能、费用与验证安排

**选择次序：在满足该任务质量要求的候选中，优先比较一次有效交付的总成本，同时衡量总 token 和耗时。** 成本包括主/子模型、缓存、思考、图像、失败重试和返工；服务器部署还需单列运行资源与利用率摊销。不同模型 token 单价/计数方式不同，token 少不自动等于更便宜。费率未知就保留未知，不据此作最便宜排名；不为守住静态智力上限排除经济性更好的新模型。

本轮不产生新的价格/速度排名。原厂高速服务、Flash/Turbo 名称和激活参数不能保证 Paratera 延迟；前次每项两次数字图探针也不足以排名。平台静态 Embedding/Rerank 页有标价，但含旧型号且未核当前账户费率，记录为文档线索，不算已验证当前单价。费用比较要包括图片计费、输入/输出、缓存、思考、父子调用和失败重试；速度记录首次响应、完整有效结果、并发队列及返工后的总耗时。

建议先补齐不同能力的最小验证材料：OCR 用尺寸链/门窗表，视觉用完整门弧和不同窗型，通用模型用工具纠错到保存结果，检索用相关/干扰片段。以对象级真值、实际动作和结果判效，不以工具次数或单一榜单代替。所有候选不必一口气跑整栋；先确认接口和适配，再选代表组合做同输入/同工具的建筑节点回归，并按既有节点约定准备具体批次。当前未启动任何新模型或建筑实验。

下一实现采用 [模型配置与调度设计](../../../design/model_configuration.md)，复用同一套 BIM 工具、状态和评价；不要为每个型号另造方法。能力不足需要显式报告或在已配置、符合费用/调用权限的池中转交，实际模型和消耗均留记录。

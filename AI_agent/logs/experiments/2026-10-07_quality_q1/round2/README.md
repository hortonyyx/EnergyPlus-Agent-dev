## 1. B：跨层对齐保护条件

坐标优先级按标注、使用该坐标的楼层数、共线墙段数、低层顺序处理。一条目标墙可接受多个不相交源墙段。规整端点时锁定已选中的跨层坐标，并带动相连共线墙链，避免被旧坐标拉回形成循环。涉及折线时先无损拆成确定的两点墙段；拆分本身的 `geometry_changed=false`、`movement_m=0`，保留引用与段映射，再走同一套几何及语义校验。

## 2. A：窄条、种子与门窗

同层跨度重叠且距离 `<0.30m` 的平行线必须合并；带名字的种子、挂有门窗都不再是豁免理由。窄条种子删除并记录 ID；门窗移至合并后的墙，沿墙重叠者合并、互不重叠者保留。目标墙的 ID 优先，余下按稳定 ID 顺序；多步合并的旧 ID 映射追溯到最终保留对象。开口高度差记录后按目标选择，不把可处理的高度差当成平面连通冲突。

部分重叠保留真实余段及跨度，接头移到目标线，固定外轮廓始终作为目标。窄条合并允许的房间删除、门窗去重和宿主变化全部写入清单，再用严格编译、空间/宿主/门连接比较与硬约束验证；失败时 `changes=[]`，尝试项只进 `attempted_changes`，不得算作交付改善。

F→A 实际探针还定位到两次相邻外皮合并可把余段压成零长度。现仅删除由本次接头移动产生、移动前为有效两点墙段且不承载开口的零长余段，并记录 `remove_collapsed_wall_step`。承载门窗的余段拒绝，输入中原有的退化墙也仍由严格编译器拒绝，不能借规整静默清理。

拒绝类别如下；实现错误应修复，不能只改名为连通矛盾：

1. 源开口跨过本次重叠跨度边界、窄条内开口无法归属于任一候选宿主，或者门窗宿主将被压成一点，不能完整迁移而保持连接。
2. 沿墙重叠的开口具有互相矛盾的种类或有效通行状态，单一保留开口无法同时表达两者。
3. 合并后出现清单未授权的空间、宿主、门连接变化；或真实几何无法严格编译。
4. 最终仍违反固定外轮廓、同层 30cm、空间 60cm 等硬约束。有限迭代守卫仅用于中止异常，不作为正常放弃可解输入的理由。

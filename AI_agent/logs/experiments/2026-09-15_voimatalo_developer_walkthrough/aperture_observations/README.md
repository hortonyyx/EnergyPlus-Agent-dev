# Voimatalo 四面标准层窗排观察

本目录只使用 `evidence_01/` 中 `west`、`north`、`court_long`、`court_short` 四组冻结的 PNG 原纹理、相机 JSON 和像素缓冲 NPZ。没有读取旧窗清单、旧 BIM、父瓦片、OSM 或 GT；没有模型/API 调用。窗组边缘与重复关系是开发辅助视觉判断，米制换算、局部亮度对比、像素命中、三角面 ID 和墙面深度核验由脚本确定性完成。

## 可直接使用的产物

- `openings.json`：220 条标准层窗组实例。每条含 `id`、观察面、墙片键、像素框、沿立面的米制宽度、可见 Z 范围、判断依据、局部对比和 5 点墙深命中检查。
- `unresolved_observations.json`：9 条不应静默规则化的观察，包括西端大窗、北端两组扭曲大窗、长院墙中部暗槽与右侧裁边窗、两处缺面透出后墙，以及短院墙两条低层残窗。
- `observations.json`：代表排、六排可见高度、水平组定义、相机换算和范围说明。
- `west_apertures.png`、`north_apertures.png`、`court_long_apertures.png`、`court_short_apertures.png`：绿色框是主墙代表排，青色框是另一个有明确深度的台阶/分段墙，橙色为可见但未决，红色为确认透出的另一墙；横线标出其余可重复排。
- `verification.json`：本次共有 220 条可用实例，标准窗每框 5 个取样点全部命中对应墙深；未决项不混入这项通过数。

像素框采用 `[left, top, right, bottom]`，左/上包含、右/下不包含。`z_m` 为 `[低, 高]`，按像素边界换算。R01 是最高一排观察，R06 是最低一排观察，它们不是未经证实的楼层编号。

## 六排可见高度

四个正投影的像素比例不同，但六排对应的 Z 基本一致。完整可见排约为：R01 22.54–24.44 m、R02 19.37–21.29 m、R03 16.14–18.14 m、R04 12.98–14.99 m、R05 9.83–11.83 m。R06 理想可见范围约到 6.8 m，但 north、court_long、court_short 的网格缺口或前景遮挡不支持完整下沿；JSON 只保留实际仍可核的残段。west 的 R06 完整可见范围为 6.76–8.68 m。

## 关键取舍

- `court_long` 的 x≈169–320 暗带命中 x≈−13.4 m 的后墙，当前院墙是 x≈0.7 m；不把暗带当第三组大窗。其右侧 x≈321–406 的竖向暗槽反而命中近侧表面，作为凹槽/大开口未决项单列。
- `court_short` 主墙右侧暗区命中 y≈25.9 m 的北墙，当前短墙是 y≈8.9 m；同样排除。左侧窗组命中 y≈9.6 m 的台阶墙，单独保存为 `court_corner_y`，没有并到主短墙。
- west 右端和 north 右端大窗确实可见，但纹理扭曲、边界及局部表面与标准窗不同，所以保存估测框而不纳入规则窗展开。
- `local_contrast` 只是窗框视觉判断的辅助量。它没有阈值决定对象类别，也没有把所有暗条一律算成窗。

## 重放

从仓库根运行：

```bash
python AI_agent/logs/experiments/2026-09-15_voimatalo_developer_walkthrough/aperture_observations/measure_apertures.py
```

脚本只会重建本目录内的 JSON 和四张标记图，不修改冻结的 `evidence_01/` 或其它旧产物。范围只含四面标准层窗组；地面门、顶层/屋顶窗、细分窗框和无法支持的缺面补全不在本次清单内。

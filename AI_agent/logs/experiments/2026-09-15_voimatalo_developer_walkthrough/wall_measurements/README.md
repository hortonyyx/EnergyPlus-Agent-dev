# Voimatalo 原网格局部墙面量测

本目录是开发助手完整探路中的有界几何量测，只读取原单体 `input.glb`、`evidence_01/direction.json` 和 `evidence_01/sections.json`。未读取父瓦片、旧 BIM、OSM、GT 或语义标签，也未调用任何外部模型/API。

短翼内院墙的原始位置分布在约 9.45–9.55 m 还有明显次峰；主峰估计不能抹掉这项局部折面、浮雕或重建偏移。完整原始分布见 `report.json` 和 `distributions.png`。

上述沿墙数字只是有证据面质心的包络，连续性须看报告里的逐米占用区间。主墙面和低体面有较连续支持；退台西、北只分别覆盖包络约 **27%** 和 **39%**，属于稀疏、断续的局部表皮线索，不能据其跨度直接造一整段连续墙。

低体局部 X=2…12 m、Y=-20…7 m 的近水平表面高度估计为 **Z=6.723 m**，加权 10%–90% 为 6.625…6.814 m，稳健区含 136 个面、约 227.31 m²投影面积。它只支持低体屋面表皮的大致高度，不能解释成楼板实测。

主体四组主立面在约 Z=24.2…24.4 m 仍有强表面支持；退台西/北竖面主要集中于约 Z=25.4…26.4 m。这支持“檐口到退台”的大致高度带，不确定中间构造和楼板位置。

## 产物

- `summary.json`：给装配使用的短摘要。
- `report.json`：选择条件、面积权重、原始直方图、稳健区、分高度结果及沿墙占用区间。
- `faces.json`：每个候选三角面的原 GLB 全局 face ID、旋转前/后的三个顶点、局部法向、面积、质心和是否进入稳健估计。
- `plan_selection.png`：平面上的原候选与稳健主峰面。
- `profiles.png`：每面沿墙方向和高度的实际支持。
- `distributions.png`：面位的完整面积加权分布，保留次峰。
- `validation.json`：输入散列匹配、face ID 范围和数值有限性检查。
- `measure_walls.py`：可重放脚本。

## 方法边界

选择窗口由开发助手根据 `evidence_01` 六个原始剖切显式确定，已完整写在脚本中，不冒充自动墙面分类。估计只使用所选近竖直三角面的质心位置和投影面积；没有把裁剪三角面的全顶点包围盒拟合成建筑轮廓。窗洞、浮雕、凹槽、檐口和摄影测量噪声会使表皮位置偏离轻量 BIM 的代表面，装配后仍需回叠原网格复核。

原网格缺面只表示输入没有相应表面，不能自动补成端墙，也不能断言该处敞开或无窗。

## 一、形态：一堵墙 = 成对的两条面线，**不写厚度、不写中线、不判内外**

```jsonc
{
  "id": "B19",
  "axis": "row",                       // 沿墙方向
  "constant_world_axis": "y",
  "representation": "two_face_lines",  // | "solid_fill"（方言 2）
  "faces": [
    { "role": "a",
      "pos_px": 772.5, "pos_m": 10.058,       // 面【在哪】
      "cols_px": [771, 774],                  // 支撑它的【墨迹范围】（两者不是一回事）
      "runs_px": [[527, 695], [796, 966]],    // ⭐ 真实连续区间，不是 [min,max]
      "runs_m":  [[5.311, 8.924], [11.109, 14.809]],
      "gaps": [ {"len_px": 101, "class": "break"} ]   // 断口逐个记账
    },
    { "role": "b", "...": "..." }
  ],
  "spacing_px": 5.7, "spacing_m": 0.1246,      // ⭐ 观测量，**不叫 thickness**
  "declared_thickness_candidates_mm": [240, 120],
  "opening_runs": [ {"run_m": [...], "fen_px_in_band": 737, "beyond_ratio": 0.31} ]
}
```

**四条设计决定**

| 决定 | 为什么 |
|---|---|
| 不写 `thickness_m` | 它是 `face_a`↔`face_b` 的距离，派生量。**一堵墙的内外两面长度可以不同**（Z 形凹口就是），塌成"中心+宽"这个差异就没了 |
| 不做模数吸附 | 声明值（240/120）来自图上 callout，是 OCR 产物；吸附是换算 ⇒ 归 correction。reading 只交**实测间距 + 见证刻度** |
| 不判内外 | 需要闭合外轮廓才知道哪边是室内 ⇒ correction 的活 |
| 门洞不 heal | 图上面线本来就在门洞处断开，忠实记断口；接不接是 correction 的换算选项 |

**唯一的阈值，而且不是新造的**：`OPENING_MIN_M = 0.60`（项目已签字的洞口下限，F-73）。
实测 sm25 1f 断口长度分布有干净的谷：≤15 px 有 5 处、16–30 px 只有 2 处、31–60 px 有 34 处。
小于此值的空白记为 `hairline` 并入账，**不静默合并**。

**方言容纳（声明化，不是加分支猜）**
- `two_face_lines`（sm25）：两条细面线 + 中空
- `solid_fill`（sm24）：一条实心带 ⇒ 两个面 = 带的两条边；`pos_px` 是位置、`cols_px` 是整条带

## 二、实测结果

### 三条自证判据（⛔ 全部不需要 gt）

| | 反向对账（多画） | 成对性 | 正向对账（漏画） |
|---|---|---|---|
| sm25 1f | 🟢 0 违规，最差覆盖 **0.879** | 🟢 | 🟢 未认领 **4.74%** |
| sm25 2f | 🟢 0 违规，最差 0.875 | 🟢 | 🟢 未认领 4.60% |
| sm24 1f | 🔴 **2 违规**，最差 0.74 | 🟢 | ⚪ **显式降级** |

⭐ **sm24 的正向对账显式降级、不给自信的绿或红**：实测 sm24 的家具图层 = **0.00%**、
structure = 59.1%（sm25 是 19.7% / 31.5%）⇒ **家具被并进了结构色**，
未认领的大块正是桌椅沙发尺寸（87×46、123×77、155×167）。
把 41.9% 当成墙覆盖率报出去就是一个自信的错答案 ⇒ 同 F-69 的「降级必须显式」。

### ⭐ 分辨力实测（收录判据：好的全绿 + 坏的报红）

坏夹具 = **把每条面线的 runs 塌回 `[min, max]`**，即 2026-08-22 那个形状的精确复现（不是编造的）：

| | 正常 | 塌回 `[min,max]` |
|---|---|---|
| sm25 1f | 🟢 0 违规 | 🔴 **19 违规**，最差 0.478 |
| sm24 1f | 🔴 2 违规 | 🔴 **30 违规**，最差 0.232 |

**两种方言上都有分辨力。**

### ⭐⭐ 决定性单例：走廊幻墙消失

`B19` 现在是两条面线各带**两段**，中间 101 px 断口：

```
面 a  y=10.058   x 5.311→8.924  |  11.109→14.809
面 b  y= 9.933   x 5.311→8.924  |  11.109→14.809
```

答案：`(5.0, 9.9999)→(8.94, …)` 与 `(11.06, 10.0)→(15.0, …)`。
原图实测该走廊段灰墨列占比 **2.0%**（两侧 100% / 98.8%）⇒ **那 2.1 米本来就没有墙**。

### ⭐⭐ 顺带推翻 F-78

sm25 2f 全部 22 条墙带的实测间距，**离图纸声明值都在 1.00 像素以内**
（1 px = 21.81 mm）。F-78 报的「图纸上不存在的墙厚 0.131」离 120 mm 只有 **0.49 px**。

⇒ **F-78 不是测量错误，是表示错误**：把一个带噪声的观测量命名成"厚度"这个事实性名字，
它就以事实的身份往下游走。as-drawn 里它叫 `spacing_m`，吸附归 correction ⇒ **该缺陷自动消失**。

## 三、⭐⭐⭐ 信息没丢的反证（本轮最重要的判据）

问法：**答案层里的每一条目标，as-drawn 层里有没有一条同坐标的面线、其区间能覆盖它？**
（外轮廓比**外皮单面线**，内墙比**两面的中点**——这个不对称正是 R-3，它在这里活下来说明
as-drawn 同时携带两者，correction 想出哪个框都行。）

墙的完整范围 = **面线段 ∪ 内部断口 ∪ 洞口墨迹**（三者都已转录，不引入新判断）。

| | 外轮廓 | 内墙 | 总体 |
|---|---|---|---|
| **sm25（两层，75 条目标）** | **100.0%** | **93.2%** | **94.7%** |
| sm24（20 条目标） | 75.0% | 68.8% | 70.0% |

**sm25 剩下的 4 条全部是 0.12 米长的转角碎片**（`(5,14)→(5,14.12)` 与 `(15,5.88)→(15,6)`），
是答案在 Z 形拐角处的分区铺砌产物，不是墙。

⇒ **结论：as-drawn 层没有丢信息，彻底版不会退化。**

## 五、文件

- `tools/as_drawn.py` — 形态提取（面线真实区间 + 成对 + 洞口墨迹 + 见证刻度）
- `tools/checks_as_drawn.py` — 三条自证判据 + `merge_runs` neuter 变异
- `tools/reconstruct_check.py` — 信息没丢反证（**唯一读 gt 的**）
- `out/*_as_drawn.json` · `out/*_checks.json` · `out/*_checks_MUTATED.json` · `out/*_reconstruct.json`

复现：

```bash
EXP=AI_agent/logs/experiments/2026-08-23_as_drawn_reading_prototype
python3 $EXP/tools/as_drawn.py $EXP/tools/cfg_1f_full.json $EXP/out/sm25_1f_as_drawn.json
python3 $EXP/tools/checks_as_drawn.py $EXP/out/sm25_1f_as_drawn.json $EXP/tools/cfg_1f_full.json $EXP/out/sm25_1f_checks.json
python3 $EXP/tools/checks_as_drawn.py $EXP/out/sm25_1f_as_drawn.json $EXP/tools/cfg_1f_full.json /tmp/x.json merge_runs   # 必须红
python3 $EXP/tools/reconstruct_check.py sm25-L_anchor '{"F1":"'$EXP'/out/sm25_1f_as_drawn.json","F2":"'$EXP'/out/sm25_2f_as_drawn.json"}' $EXP/out/sm25_reconstruct.json
```

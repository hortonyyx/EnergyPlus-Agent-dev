⇒ **判分方那把尺子在【逐点】形式下同样通过**，且这次**能看见外包法看不见的东西**
（局部畸变 / 旋转 / 分区偏移）。⛔ 正确读法仍是「**在本方法分辨率下与完美无法区分**」。

### 为什么逐点值得单做（⛔ 不是把外包法再跑一遍）

外包法每组只有 **4 个数** ⇒ 只界定**全局平移+缩放**，**对旋转与局部畸变完全是瞎的**。
逐点残差散布在整张图上（x 305–1414 px · y 316–1253 px），
⇒ 若存在旋转或分区偏移，会表现为残差**随位置系统性变化**；实测**没有**，偏置全部 ≤0.21 px。

### holdout 性质（⛔ 这条是全部价值所在）

manifest 的平面仿射**只用 `WALL` 图层的线峰拟合**；本探针量的是
`WINDOW` / `E_WINDOW`（青）与 `LVTRY`（品红）—— **拟合从没见过它们**，
且颜色取自**图纸自己在 DXF 图层表里的声明**，⛔ 不是我挑的。

## 二、⛔ 三次迭代，每一次都是我自己的方法错（逐字记下，这才是本单的复用价值）

### v1：拿「整个块」去配「它的一个碎片」

全局最优指派（`linear_sum_assignment`）+ 互为最近邻校验，配对率 100%，读数却是
**max 15–27 px / RMS 8–15 px**，而**均值偏移接近零**（0.6, −1.5）。

**看计数就露馅**：31 扇窗 ↔ **49 个墨块**、13 樘门 ↔ **155 个墨块**
⇒ 一个门窗符号在图上本来就是**若干条分离的线**。
我拿「整块的几何中心」去配「某个碎片的中心」——两个不同的量。
⇒ [[proxy-mistaken-for-the-thing]]。**均值近零恰恰在告诉我尺子没偏、是我配错了**，我差点没听懂。

### v2a：改成「先预测框、再就地取墨」，但比的还是**质心**

去掉全局配对（不需要了），改为对每个特征按预测框就地取墨。仍是 **RMS 5–9 px**。
**病根同上一层**：几何**外包中心** vs 墨迹**质心**，在门这种弧线 symbol 上系统性不等
（墨偏在弧的一侧）。⇒ 改成**比外包对外包**（每特征 4 条边），门立刻降到 **0.33 px**。

### v2b：⭐⭐ 扫描本身设计错了 —— **一次动了两个变量**

隔离筛与采样窗**共用同一个 f** ⇒ 每个 f 下入选集合都不同，扫描读数不可比。
症状是**非单调**：f=1.4 → 0.97 px，**f=1.8 → 33.7 px**，f=2.4 → 0.85 px，f=3.0 → 0.85 px。
⛔ 此时若挑一个好看的 f 报出去，就是 [[acceptance-bar-must-not-be-written-from-the-result]]。
⇒ **把隔离半径固定**（`ISO_F = 3.0`）、只让采样窗随 f 变 ⇒ **四档完全持平**，参数真的不承重。

⭐ **三次的共同形状**：**都不是被测对象的问题，是我的测量设计问题**，
而且三次都是**先看到一个吓人的读数、再发现是自己造的**。
⇒ 判据给出极端结果时，先问「是被测对象差，还是这把尺子没量对」
（[[invalidation-blast-radius-must-be-scoped]] 同族）。

## 三、方法（v2b = 权威跑法）

1. **几何侧**：`ezdxf.bbox.extents(fast=False)` 逐特征外包 → manifest 仿射映射成像素框。
   ⛔ 不用块**基点**（基点不是质心，v1 的坑）。
2. **墨迹侧**：**无阈值**——每个像素归到**图纸自己声明的调色板**里最近的颜色。
3. **隔离筛**：只量「固定半径 `ISO_F=3.0` 邻域内没有别的同色特征」的点。
   ⛔ 不筛的话，沿墙密排的窗会把邻居的墨吃进框 —— 那量的是拥挤程度，不是尺子。
4. **比外包对外包**：每特征 4 条边各出一个残差 ⇒ 同类比同类。
5. **采样窗 f 扫描** 1.4 / 1.8 / 2.4 / 3.0，证明它不承重。

## 五、⛔ 这个结论**不**能说什么（诚实边界）

1. **只有 24/88 个特征入选** —— 隔离筛把密排的门窗全排除了。
   ⇒ 结论覆盖的是**稀疏区**；密排区的局部行为**本方法量不到**。
2. **分辨率下限仍是 ~0.5 px**：墨迹外包 ≠ 几何外包，差约半个线宽，与残差同量级。
   ⇒ 「与完美无法区分」，⛔ 不是「精确到 0.85 px」。
3. **plan-F2 的门只有 2 个隔离点**，单独不满足「≥3 个非共线」；
   该视图靠 window 组的 9 点满足要求。⛔ 不许把这 2 点单独当一组结论。
4. **只有 sm25 的两张平面图**。四张立面**一条没做**；
   ⚠️ **sm24 的 `raster_overlays` 是空 `[]`**，这条路在那儿根本不存在。
5. ⛔ **不许从 `POS_TOL_M` 里直接扣掉这个误差**（sol 已明确否掉那种算法）。
   正确形式是**不确定带**：`≤ T − e` 才确定通过、`> T + e` 才确定失败，中间显式签字。

### 机制侧差异（候选归因，需受控 A/B 分清）
1. **硬隔离把探针成本翻倍**：只许 `python tools/run_cv_probe.py --request <json>` 四段式，
   每次探针 = 先 Write 请求文件再 Bash 执行（07-07 可直接带参调用）。
2. **守卫摩擦吃掉 6 轮**（见 F-4）：波浪号 / 分号 / 管道 / `grade` 等被拦，其中 3 次卡在必交总结上。
3. **样板文件缺失**（见 F-2）：kickoff 强制要求的格式锚不在 staging 内、且守卫禁词正好覆盖其目录。
   本轮由主控按安全路径补入后才可用 —— 若不补，缺口更大。
4. **新引入的预扫**：平面 803 个候选，含大量尺寸标注刻度与家具框，信噪比低；
   可能把模型锚定到「尺寸链累加位置」而非墙线本身。
5. **主控 directive 本身是变量（如实登记）**：§2 把「尺寸链逐字读」列为可接受来源的**第一位**，
   可能助推了以尺寸链算术代替量墙。

### 失败形状（很具体）
本轮 15 条墙**全部** `provenance=dimension_derived`、零条实测。它把**北立面**尺寸链
`540|1600|2520|4800|540` 的累加位置（0.54 / 2.14 / 4.66 / 9.46）画成了四道纵向内墙 ——
那是**窗与垛的位置，不是隔墙**；真正标出隔墙的是底部链 `4180|1640|4180`
（→ x=4.18 与 5.82，正是 GT 的两道纵墙），它在 pilot 轮读到过、正式轮却没用。
⇒ **工具跑了、量出来的数没进产物**。「量而非看」的方法论没被推翻，被推翻的是
「给了工具就会去量」这个隐含假设。

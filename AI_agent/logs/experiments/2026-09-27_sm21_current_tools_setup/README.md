## 入口与核验

- `run_cold`：默认run69已存在会拒绝覆盖；未来须`--run NEW_NAME`，记录当时HEAD、当前24额度和生产文件哈希。原run69为旧六次规则，以既有frozen文件和生产快照为准，不能用更新后的入口冒称复现旧条件。
- `run_recovery`：默认run70，拒绝覆盖；只导入指定proposal，未导入旧评价。
- `audit_run RUN_PATH`：生成结束后核原图/生产哈希、输入模式、回执、装配、源/显示重放、用途/高度状态，复用既有sm21原图参照和GT诊断。run含生产快照时按其哈希验证。阈值不变，评价不回注模型。
- `2026-09-27_sm24_view_references_setup.audit_views RUN_PATH`：实际PNG/原像素/来源时序与声明裁图回查；语义另行看原图，运输正确不等同理解正确。
- `2026-09-27_sm24_room_types_setup.browser_check RUN_PATH`：离线层切换、旋转、点选、用途颜色与依据显示。源JSON/GLB和本地HTML不代替原图保真判断。
- `audit_counterexample`：成功图片篡改一个像素后必须失败；旧裁图审计现单列真实失败调用，严格图像核对不放宽。
- `replay_budget`：临时复制run69的六候选，验证旧六次阻塞/24额度下第七次成功，不改变原run或调用模型。

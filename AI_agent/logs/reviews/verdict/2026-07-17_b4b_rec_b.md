## 登记偏差（沿用 REC-A，非新增）
- **PA-C7① list-vs-tuple**：`Point2`=`Annotated[list[StrictFiniteFloat], min/max=2]`、`outward_normal`=`Annotated[list[Literal[-1,0,1]], min/max=2]`，非合同字面 `tuple`（Pydantic strict tuple 拒 JSON list，gt_schema.py L35-37 有注释说明）。REC-A 已判永久留痕；B4b 按 `list` 编码，语义与约束等价。

## 观察（对 B4b 无影响，登记备查）
- **id↔几何绑定的强制点**：segment id 由 extractor（`extract_gt_v3` L617）从几何 `stable_boundary_segment_id` 派生并 `gt_boundary_segment_id_collision` fail-closed；`validate_gt_v3` 强制的是 **id 唯一性**（`id in all_segments`）+ **Vg 几何按 (family,p1,p2) 重导比对**（L571-576），**不**在 validate 内重算 id 串本身。对 B4b **无影响**：B4b 把 `segment.id` 当不透明稳定/唯一 JOIN 键消费（`opening.boundary_segment_id → segment.id`），不依赖「validate 重哈希 id」这一性质。B4b 不得假设 validate 会重导 id 字符串。

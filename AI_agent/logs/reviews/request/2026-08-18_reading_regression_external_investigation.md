## 一、项目与环节背景（读本文所需的最小上下文）

管线：**0_reading（识图，VLM）→ 1_correction（校正，LLM）→ 2_modelling + 3_split_pairing（几何内核，代码）
→ 4_mep（物理，LLM）→ 5_intakeoutput（装配，代码）**。代码入口 `src/agent/pipeline.py:run_pipeline`。

**0_reading 干什么**：给一个 VLM（读图器，`reading-worker-agent`）喂建筑 CAD 导出的 PNG
（sm21 案例 = 2 张平面 + 4 张立面），要它输出结构化的「笔画（stroke）」——
墙线段的**米制坐标**、窗洞位置、尺寸标注转录、以及每个数字的**来路（provenance）**。
下游几何内核吃这些坐标建模，最终出 EnergyPlus IDF。

**为什么它是瓶颈**：坐标错一格，下游全废；而这是全链唯一没法用确定性代码替代的一环。

**判卷**：`scripts/tool_scripts/score_reading_vs_gt.py` 拿产物与 `gt.json` 逐元素对账，
输出 `0_reading/attempts/NNN/score_vs_gt.json`（`wall_hits/wall_total`、`window_hits/window_total`、
`max_wall_offset_m`）。**判卷尺本身已验证没变**：老产物今天重判仍 9/9。

**CV 工具箱**：`skills/intake_pipeline/0_reading/cv_toolbox.md` + `src/agent/reading/`（recipes/tools），
提供 `crop_zoom`（放大局部再读）、`wall_line_profiler`（行列灰度投影找墙线峰）、
`px_m_calibrator`（拿两个已知实距的锚点算 px/m）、`overlay_logger`（把候选/拒收画回图上留痕）等。
**设计意图 = 让读图器「量」而不是「看」**。

## 七、一条贯穿全案的干扰源：guard 的假阳性家族（六次现形）

`guard.py` 用**词法模式匹配**去判**任意 shell + 任意源码 + 任意散文**。输入空间无界 ⇒ **假阳性没有上限**。
六条同族缺陷**无一例外**都是「合法的东西长得像禁忌的东西」：

| 编号 | 内容 | 状态 |
|---|---|---|
| **F-49** | `px_m_calibrator` 文档与 wrapper usage 写的两种形态在沙箱里全跑不通 | 已修 |
| **F-60** | 裸子串 `".." in text` / `"~" in text` 扫整份文件 ⇒ `print("…walls...")` 的**省略号**判「上级目录」、`# gray = ~180` 的**波浪号**判「家目录」；且**一个文件毒死整个执行面** | 已修（+17 锁、双向 neuter）|
| **N-1** | 同一段代码两条通道判得不一样：`grade` 写在 `python -c` 里 DENY、写进 `out/*.py` 再跑则 ALLOW。⚠️「grade line」=**室外地坪线**，是立面图核心词汇 | 未修 |
| **N-2** | 在 `out/` 放一个内容为 `see https://example.com` 的 `.md` ⇒ **干净脚本立刻 DENY**（`notes.md references network egress`）| 未修 |
| **F-61** | 放松档解锁 `\|` 后仍把整条命令交给参数校验器 ⇒ `--batch … 2>&1 \| tail -300` 被判「不认识 --batch」。**J1 因此整臂作废** | 已修 |
| **F-62** | 对**整条多行命令** `shlex.split` ⇒ **heredoc 正文的每个词都成了命令参数**、反斜杠续行的换行成了裸参数。`python -c "print(1)"` ALLOW / `python << 'EOF' print(1) EOF` **DENY**。**J2 的 4 条 deny 全属此条** | **未修** |

**⛔ 这一家族制造了本案最危险的一类误判**：
**工具坏掉与「模型不用工具」在产物上完全同形，只有过程日志分得开。**

## 九、⛔ 排查者必读：本案已知的方法论陷阱（我踩过的）

1. **⛔ 我（orchestrator）的事实性错误率被逐条记录 = 29/29 起步，本案期间还在涨。**
   典型形状 = **把「我以为的盘面」当「盘上的事实」说出口**。请优先复算，不要采信本文的推断。
2. **单点 diff 只能产生候选，多版本交集才能过滤。** 我曾从 `723b0f9` vs 今天的 diff 找到三条被删规则
   （`prefer empty hands over wrong anchors` / `a gray peak is a candidate, not automatically a wall` / `log rejections`），
   **症状还对得上**（今天每抽都多画墙 extra=8–12，07-07 是 extra=0）——

3. **「时间吻合 + 症状吻合」不足以立论**（同一形状已犯两次：08-15「省 crop 纪律」、08-16「那三条规则」）。
4. **判一个「模型不肯做 X」的结论前，先确认做 X 的那条路是通的**（F-49 / F-60 两次现形，第三次是
   「数侧车份数」判它没重做标定，实际它在自己的 heredoc 里重算了、只是没再调工具 ⇒ **判据量错了东西**）。

   ⇒ 「三次成功 deny=0」**不构成独立证据**，那只是当时没有这个测量装置。
6. **⛔ 不得直接采信执行方的数字**：GLM 报「H2 三轮 deny=15」，实际日志 12 次、其中 6 次是我自己的跑前探针。
7. **不要跨列做因果比较**：§3.2 那张表**没有任何一列是单变量**。
8. **立规则不给合法出口 ⇒ 模型自己发明出口**：我写「跑闭合校验并告诉我它闭合了」，
   它**改转录来凑**；**补上合法出口后它当轮就用上了**（如实报「北链 14.76 ≠ 15.00」）。
   ⇒ **诱发伪造的是缺出口，不是纪律不够硬。**

## 1. 背景（读这段就够，细节看 §2 指针）

本项目用**评测标准答案（gt）**给识图/建模管线判卷。gt 的权威来源 = 用户用天正 CAD 画的图纸，
经「图形导出」成 DXF，再由提取器 `src/agent/judge/gt_extraction.py`（GT v3，2026-07 重写）
抽成 `gt.json`。

**今天实测发现：天正图形导出的真实建筑墙线，喂不进 GT v3 提取器。**
两者对"图"的定义不同 —— v3 要**单线区划边界**（相邻房间共享一条线、polygonize 后每个面正好一个房间），
天正画的是**真实建筑图**（墙是双线、门窗洞处墙线断开）。

**用户已拍板（2026-07-21）**：**做转换器，不要求人改变正常画图习惯。**
明确否决了"让用户手画一层区划线"的方案，理由 = 复杂建筑手画不可行且**容易画错**（画错的是答案，
错答案会把对的产物判成错、且无人发现），只对简单建筑成立 ⇒ 违反不变量 #6。

## 3. 目标与范围

**目标**：输入天正「图形导出」DXF（真实建筑画法），输出 GT v3 提取器可直接消费的几何，
**全程不要求人改变正常画图习惯**。

**建议架构（可推翻，但推翻需给理由）**：
`源 DXF → 转换器 → 规范化几何 → 现有 v3 提取器 → gt.json`
即**不改 v3 提取器本体**（零回归风险），转换器产物须**留痕可核验**。
若你认为应改 v3 本体或换别的接缝，请正面论证并给出回归风险评估。

**范围内**：正交建筑（墙轴平行于世界轴）。**必须能长到** L 形（sm25）/ U 形（sm26）/ 回字形（sm27）
—— 这是 C2 路线的既定爬坡序列，**不是远期设想**。

**范围外**（本轮）：斜墙 / 曲墙 / 非正交；多层跨层对齐（但**不得烤死单层假设**）；
CAD 作为产品输入模态的方言适配层（那是 plan.md N3c 的 P3 defer 项，与本转换器**分属两侧**，见 §10 边界）。

## 4. 硬约束（违反即不可接受）

1. **不变量 #6（建筑复杂度可扩展性铁律）**：不得把"墙厚统一 240 / 每层满铺 / 共用 footprint /
   矩形网格"这类**当前简化假设烤死**。sm21 老提取器 v2 正是烤死了"矩形网格"假设才不能用于 L 形 —— **勿重蹈**。
2. **fail-closed，绝不静默出错答案**：转换失败必须**明确失败 + 给可定位诊断**（哪条线/哪个洞口/哪个接头）。
   这是 gt 生成器，**错答案比崩溃危险得多**（会把对的产物判成错，且无人发现）。
3. **gt 铁律**：转换器属 judge 侧工具，`gate①`（`src/validator/checks/*`）与执行器（`src/agent/pipeline.py`）
   绝不 import；`tests/test_gt_discipline.py` 机械守。
4. **答案可核验**：转换结果必须能渲染出来给人肉眼核（现有 `render_gt.py` / overlay 链路）。
   人核不了的答案不算答案。

## 5. 必须正面回答的设计问题（缺一不可）

1. **双线 → 单线**：如何配对同一道墙的两侧线？墙厚**不统一**时（外墙 240 / 内墙 120/200 混用）怎么办？
   取中心线还是别的基准？与 v3 的 `boundary_reference: "outer_skin"`（centerline 不支持）如何自洽？
2. **洞口补齐**：门窗洞处墙线断开。实测**窗块** bbox 精确等于洞口，但**门块** bbox 含开启扇、越出墙皮、
   **≠ 洞口**（⚠️ 2026-07-21 更正，见 SURVEY §5 线索 1 —— 门窗须分别处理）；
   且 v3 的 `_entity_points` **拒绝 INSERT**。补齐策略是什么？块被炸成线的图怎么办（不能假定一定是块）？
3. **接头**：丁字 / 十字 / L 角 / 墙自由端（端头封口）各如何延伸与裁剪？容差从哪来（`judge_gt.yaml` 已有七个容差，勿另造）？
4. **凹角与非凸轮廓**：L / U / 回字（**带洞**）如何保证 polygonize 出的面与设计意图一致？
   注：v3 的 `geometry_profile` 目前只有 `c2_simple_orthogonal_no_holes` —— 回字形带洞是否需要新 profile？
5. **区划意图从哪来**：v3 靠 `zone_seeds`（每房间一个种子点）定分区。种子点谁给、怎么给？
   **关键**：L 形走廊必须是**一个**面（用户 2026-07-21 拍板：算 1 个热区）——
   转换器不得在走廊拐角引入把它切开的线。
6. **失败诊断的可定位性**：给出诊断码设计与"人拿到诊断能做什么"的闭环。
7. **验收**：如何证明转换正确？（建议：sm24 真图端到端 + 合成夹具；**但 sm24 通过 ≠ 泛化**，
   请给出泛化证据策略。）
8. **房间用途（role）**：天正导出 DXF **不带房间名**（sm24 全图仅 5 个文字 = 5 个图名）。
   用户定：sm24 不作判分项，**sm25 起在 CAD 标房间名**。转换器如何接这条演进（有标签/无标签都要能跑）？

## 一、做什么（一句话）

把 `WallCompilationV1.walls` 派生成 `CorrectedGeometryV3` 的**房间**，并落 envelope。
算法 = **中轴平面剖分**，全档见设计稿 §四 与 §六之三。

**四步**（设计稿 §四）：
```
① 切割线 = 全部中线 ＋ 洞口（当中线延续）   ← ⛔ 不加洞口则一个房间都切不出来（实测）
② 端点延伸：墙带与对方实体矩形相交(含相切) ⇒ 延到对方中线
③ cells = arrangement 的每个有界面
④ footprint = 全部有界面的并集（⭐ envelope 里标 footprint_provenance = derived_from_walls）
```


## 一之二、⭐⭐⭐ **共线缝：本单已替你选死**（设计稿 §9.1 · ⛔ 非谈判项）

同轴**共线**的两段墙之间的缝，规则本身**永远不接**（它只处理垂直对）。
复核方实测：分隔墙上一个 **100 mm 共线缝** ⇒ **两个房间静默合并成一个 24.0 m² 的面**。

⇒ **本单选 ①：共线 gap 视为洞口延续（按 opening 规则补线）**，并**写进 envelope 契约**。

⛔ **你若实测认为应当选 ②**（不补 + 明说所跨房间会合并 + 让判分侧看得见这个决定）
⇒ **A 层停报**，⛔ **不许自行决定** ——
⭐ 立此条的理由：不给合法出口，施工方就会自己发明一个契约决定
（[[rule-without-legal-exit-breeds-invention]]）。

## 二、⛔⛔ 本单的三条纪律（**来自用户 2026-09-02 令，见[指南 §十三](../../guides/reading_correction_split_guide.md)**）

1. ⛔ **几何派生代码里不得出现任何长度/厚度常数。** 需要尺寸时**只能从被处理的数据里取**
   （如「对方墙自报的厚度」）。⛔ 不许写字面量、⛔ 不许从配置读一个「默认墙厚」。
2. ⛔ **验收夹具不许只用现有 case 的墙厚。** 必须有一组 **90 / 150 / 300 / 370 混排**
   （⭐ 且**同一张图里厚度不唯一**）。只喂 120/240 就只证明了 120/240。
3. **正交**：当前实现**可以只处理正交**，⛔ **不要求**写非正交的拒绝路径或泛化分支
   （⭐ 且实测**非正交今天进不来**：设计稿 §9.2 三重关死）。
   **唯一要求 = 那个假设【局部化 + 有名字】**（一处判定 / 一个命名函数），
   ⛔ 不许把「反正是正交」散进每个函数。
4. **容差**：本单只有一处容差（§三），**必须数据派生**，⛔ 不许施工方自己定一个数。

## 三、⭐ 那处唯一的容差（**必须这样写**）

判据比较用 `<= ht2 + 1 unit`，那个 `1 unit` = **数据自己声明的坐标分辨率**，
**从输入的 `units_per_metre` 派生**，⛔ 不许写字面量 `1`。

⚠️⚠️ **写破这一句（设计稿 N-3）**：`units_per_metre` **只在 gt 侧存在**
（`as_measured.py`，`Literal[10000]`）；**生产链是浮点米、没有这个字段**
⇒ **本单的容差挂的是【夹具输入】的粒度**；**生产链接入时必须重新声明粒度来源**，
⛔ 那时不许沿用 1 unit 这个数。**这句要写进代码注释与契约。**

## 五、验收（**规则形态**，⛔ 不写成现状名单）

| # | 规则 | 怎么证 |
|---|---|---|
| **1** | 剖分出的 cells **互不重叠且并集 = footprint** | **零阈值**断言 `hole_area == 0 and overlap_area == 0`，⛔ 不用 `coverage_area_tol_m2` |
| **2** | **相邻房间共面**：任意内墙两侧的房间边**逐顶点相等** | 直接断顶点，⛔ 不断哈希 |
| **3** | **改厚度时房间边界不动 —— ⭐ 判据是【环带是否为空】，⛔ 与增/缩方向无关** | ✅ **变异不翻转任何延伸判定**（机械可查：新旧半厚之间的环带 `(min(ht旧,ht新), max(ht旧,ht新)]` 内**没有任何朝外端点**、且无沿向缓冲翻转）⇒ **cells 逐顶点不变**。⭐ **与增/缩方向无关**（实测：环带空 ⇒ 增 10 mm 也不变；环带非空 ⇒ 增 2→3、缩 3→2 **都变**）。「增厚」与「邻墙端点跟随面对称移动的一致重画」只是**构造上保证环带恒空**的两个充分方向（一致重画中跟面端点 `d_new = ht新`，恒贴边；⚠️ 夹具须**不含第三方环带端点**）。⛔ **环带非空 ⇒ cells 可以变，这不是缺陷** —— 归夹具 #3（厚度报错）+ gt 对账，⛔ 不由本条管、⛔ **也不许拿夹具 #3 的输入验本条的 ✅ 方向** |

| **6** | ⭐⭐⭐ **对 gt 签字 zone 【双向】逐个位置对账：F1 14 · F2 15** | ⭐ **双向语义见 4b（③ 无主面即红是非谈判项）**；⭐ **逐视图各跑一次**（F1 一次、F2 一次），⛔ **不要求**把两层装配成一份两层产物（那是 **B2**）。⛔ 不许引「28 vs 30」（旧读数拼接）；基准钉**签字冻结的 `gt.json`**，⛔ 不用判分侧读数（它在 REWORK、会漂）|

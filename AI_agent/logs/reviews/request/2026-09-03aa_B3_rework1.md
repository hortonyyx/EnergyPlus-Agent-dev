## 一、⛔ B-1：**T6 主锁在第四契约变异后仍是绿的**

### 复核方实测

```
MAIN_LOCK=GREEN_AFTER_FOURTH_ADAPT_MUTATION
RESTATED_MUTATION_ASSERTION=RED
```

**病因**：`tests/test_o22m1_as_drawn_producer_types.py:446` 的 `_wire_sets` 把 `CONTRACTS`
**放在默认参数里** ⇒ **定义时就绑死了旧 tuple**。主锁（`:471`）调 `_wire_sets()` 不传参，
所以运行时往 `vector_contract.CONTRACTS` 塞第四个 `ADAPT` 契约**打不到它**。
而常驻变异测试（`:502`）**没有调用主锁**，是显式传入变异后的 tuple **另抄了一遍预期相等式**。

> ### ⭐⭐⭐ 这一条最值得你看一眼的地方
> **同仓那把参照锁 `tests/test_o22m7_evidence_wiring.py:644-647` 的 docstring 里，
> 白纸黑字警告过这个形态**：
> 「⚠️ Explicit parameter — a module-level default would bind at def time and
> **neuter the monkeypatch the mutation test relies on**.」
> ⇒ 你照抄了那把锁的**形状**，却把它当初**专门设计来避开的那个缺陷**又引了回来。
> ⛔ 这不是骂你 —— 是说**「照抄形状」不等于「照抄它防的东西」**，
> 抄一把锁的时候要连它 docstring 里写的「为什么这样写」一起抄。

## G-1 · `scale_origin` 无人要求，导致平面通道必 NA（BLOCKER 级）

**实况**：本轮 pilot 的 `scale_origin` 是 `null` ⇒ 生产判卷器给出
`channel plan not_applicable | ['plan_frame_unavailable']`，
`walls_complete 0.00 / 57.86 fail` —— **描得再准也是 0 分**。

**根因**：主控 U-01 裁定平面帧由产品声明的 `scale_origin.world_x_m/world_y_m` 承载，
但 **识图侧从头到尾没有任何地方要求填它**：`grep -rn scale_origin skills/ src/` 只命中
`src/agent/reading/schema.py:125` 的字段定义本身。07-30 那轮碰巧填了，本轮没填 ——
**纯靠模型自觉，零约束**。判卷器要一个没人负责生产的字段 = 断链。

**死骨架**：
1. **reading guide / pen 规则**里显式要求：平面视图**必须**声明 `scale_origin`，
   给出字段语义（世界原点 = 整栋投影最大边界 SW 内角，见不变量 #2）与填写样例。
   读图器本来就要跑标定（directive §2 已强制），把结果落进 `scale_origin` 是顺手的事。
2. **gate① 对平面视图缺 `scale_origin` 应当阻断**（fail-closed），不许静默通过 ——
   否则同一条链下次还会断。**注意**：这会让历史产物失效，请先查 `case_tests/` 下既有
   reading 产物有多少缺该字段，把影响面报给主控再决定是阻断还是 warn。**不要自行决定。**
3. per-run directive 同步（主控自己会改，你只需在执行日志里点出需要改哪一句）。

## G-2 · 标定不可靠：两轴差 9%、RMSE 超判卷容差（MAJOR）

**实况**（模型自述 + 主控复核）：`px_m_calibrator` 给出 40.22 px/m，但
- X 轴锚点：px 245→620 = 375 px / 10 m ⇒ **37.5 px/m**
- Y 轴锚点：py 54→872 = 818 px / 20 m ⇒ **40.9 px/m**
- 残差 X **−0.68 m** / Y **+0.34 m**，**RMSE 0.474 m**

判卷墙容差是 **0.30 m** ⇒ **标定误差本身就超过容差**，描得再准也必然 miss。
模型如实标了 "medium confidence / should be verified before production use" —— 它诚实，是工具没兜住。

同族前科：2026-07-25 立面批的「各向异性 1.92% ＝ 等比截图物理不可能」，
最终查明是**标定控制点选错**，与 GT 无关。

**死骨架**：
1. `px_m_calibrator` 必须在**两轴标定结果显著不一致时响亮失败或降级**，
   而不是把两个不同的尺子平均成一个。判据请用**可复算的结构性判据**
   （例如两轴 px/m 相对偏差超过阈值即 raise），阈值须**实测推导 + 双向证明**，
   禁先定数字后补论证。
2. 残差超过 recipe 里已有的 `calibration_warn_residual_px` / `_m` 时，
   当前只是 warn ⇒ 评估是否应当 fail-closed。**影响面先报主控，不要自行改判**。
3. 给出**锚点选取的确定性辅助**：让工具能自己找到尺寸线的两个端点（extension line 交点），
   而不是让弱模型目测两个像素坐标 —— 这是「量而非看」在标定这一环的落地缺口。

## G-3 · 预扫结构候选把外墙打成碎片（MAJOR）

**实况**（主控复核）：`structural_candidates.json` 348 条里，
**最长竖线只有 209 px、横线一条都没有** —— 而建筑外墙在图上是 375 px × 818 px 的贯通线。
⇒ 预扫没有把**任何一条贯通外墙**交给读图器。

**根因推测**（须你实测确认）：`clean_vector_v1` 的 `min_run_px=4` / `merge_gap_px=2`
令墙线在每个窗洞、门洞、尺寸线交叉处被打断，碎片再没被合回去。

**死骨架**：
1. 先**实测确认**根因（不要照抄我的推测），把证据写进执行日志。
2. 在**不丢弃任何候选**的前提下（沿用本批已确立的口径），增加一层
   **共线碎片合并**，产出「长结构线」视图，让读图器能直接拿到贯通墙。
   合并必须确定性、可复现、且**原始碎片仍然可达**。
3. 用 sm24 平面自证：合并后应当能拿到 4 条贯通外墙（x=0 / x=10 / y=0 / y=20 对应的像素线）。
   **这条是本项的验收判据。**

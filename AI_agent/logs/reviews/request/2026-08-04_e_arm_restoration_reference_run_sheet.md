## 2b. ⭐ 升档阶梯（目标是拿到达标产物，达不到就往上加档）

**逐档尝试，每档 ≥2 抽；任一档达标即停、后续档不必跑。⛔ 不许停在不达标的位置。**

| 档 | 配置 | 说明 |
|---|---|---|
| **E1** | Haiku 4.5 + CV 工具箱 + 老 review 环（= 07-07 原样复原） | 最省；若它就达标，说明机器已修好 |

## 3. 判读标准（对齐 07-07 老件在今天尺子下的实测）

**参照点（已实测）**：07-07 老件 = **内墙 57.86/57.86 = 100 % · 外轮廓 60/60 · 多画 0 m**。

| 指标 | 达标线 |
|---|---|
| 内墙命中 | **≥ 95 %** |
| 外轮廓 | **100 %** |
| 多画 | **< 3 m** |
| 窗（existence / along / width / sill / head） | 全项命中 |
| provenance | `dimension_derived` 占比应回到 **≈ 13/14** 量级（07-07 水平）；crop_zoom 调用数应显著 > 0 |

⚠️ **provenance 那两行是本臂最有信息量的部分**：今天 Sonnet 无监督 = 10 条墙**全 `seen`** + crop_zoom **0 次**；
07-07 = 13/14 `dimension_derived` + crop_zoom 11 次。**若 E 臂复原后 provenance 回不去，说明复原没做到位，先别看分数。**

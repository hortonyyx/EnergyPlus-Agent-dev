### 1. 现象：sm25 上 **3 个过阈值的 cavity 被 `derive_boundary_edges` 静默丢掉**

跑 `python AI_agent/logs/experiments/2026-08-30_f153_orchestrator_repro/probe_1_which_cavities_are_dropped.py`：

| view | cavity | 面积 | 贴墙率 (≤4 cm) | 最远采样点距墙带 |
|---|---|---|---|---|
| plan-F1 | `cavity:8bd127719198fd63` | **88.27 m²** | 400/400 | **0.000 m** |
| plan-F1 | `cavity:04e1293098b1a95a` | **28.68 m²** | 400/400 | **0.000 m** |
| plan-F2 | `cavity:495501ce9b36f0f3` | **70.34 m²** | 400/400 | **0.000 m** |

对照：**未过 5 m² 阈值的碎片全部是 0.0576 m² 的墙垛碎屑**。
⇒ **这三个是被墙完全围合的真实房间**，「天然 NA、本就无 ring 可导」不成立。

### 2. ⭐⭐⭐ 根因是**两个**，机制完全不同（⛔ 别当成一个来修）

**形态 A —— 出口射线只走 0.1 mm 就撞进【垂直邻墙】，一条 span 判死整个 88 m² 的 ring**
（命中 F1 88.27 + F2 70.34，**两层同一处**）
```
span      = axis=x, cavity_const=160000, lo=46400, hi=53600, side=-1
owner     = 墙组 ('x',160000,161200)     ← 120 mm 水平墙，cavity 在其下方
exit_point= [50000, 161201]             ← far face + 【1 个单位 = 0.1 mm】
覆盖它的 = WALL w_y_49400_50600_161200_197600  ← 一堵【垂直】墙，正好从 y=161200 起向上
⇒ _classify_boundary_fact 判 logical_edge=False
⇒ derive_boundary_edges 里 `ring_is_logical=False; break` ⇒ `continue` 整个 cavity
```
⭐ **这不是运气不好，是结构性的**（`probe_4_single_sample_fragility.py`）：
```
span x[46400,53600] 以 1 mm 步长采 721 点，落在墙体并集内的只有 121 点 (16.8%)
中毒区间 x=[49400,50600] ← 正是那堵垂直墙的两个面
而生产代码只采 mid_along=(46400+53600)//2=50000 ⇒ 正中中毒区 ⇒ 判死
```
⇒ span 两端关于那堵垂直墙的中线**对称**，`mid_along` **系统性地**落在 T 形接头上。
**83.2% 的采样位置本来会判活。**

**形态 B —— 一堵墙的 `along_min` 比同侧兄弟大 1 个单位（0.1 mm），而 owner 查找要求整数精确相等**
（命中 F1 28.68）
```
span   = axis=y, cavity_const=52401, lo=99430, hi=100630, side=-1
owners = 0                                    ← 没有任何墙组认领
near-miss 墙组 ('y',50000,52400) 的覆盖区间 = [(96399,103599)] ← 完全盖住 [99430,100630]
差的只有 const：52401 vs 52400 = 【1 个单位】
```
**52401 是谁造的**（`probe_3_detail.py`，主控实测）：
```
全仓 walls/openings 里 const==52401 的：【0 个】；cavity 环上是【精确的 52401.0】不是浮点噪声
造它的是一堵 x 轴墙的 along_min：
  w_x_99430_100630_52401_88800   face y=[99430,100630]  along x=[52401, 88800]
而它的三个同侧兄弟全是 52400：
  w_x_0_2400_52400_86400 / w_x_38800_40000_52400_110400 / w_x_57600_60000_52400_88800
再往上一层，这堵墙的两条面线【自己就对不上】：
  13AE const=99430  along=[52399, 88800]   ← 比 52400 多探出 0.1 mm
  13AD const=100630 along=[52401, 88800]   ← 比 52400 缩回 0.1 mm
配对取的是【交集】(max) ⇒ along_min=52401 ⇒ 墙带缩回 ⇒ union 后留下 0.1 mm × 0.12 m 的缝
```
⭐ **连带第二处伤**：这条 0.1 mm 缝还毒化了 `representative_point()`：
```
cavity area=28.6832 m2, bounds x=[52400,88800]
representative_point = (52400.500000, 100030.000000)   ← 落在那条 0.1 mm 缝里
centroid            = (70599.992, 99999.543)
```
而 `derive_boundary_edges` 拿 `representative_point` 定**每一条 span 的 `side`**
⇒ 一个 28.68 m² 房间整圈的 `side` 都建在一条 0.1 mm 缝里的点上。

### 3. ⭐⭐ 失败半径 = 整个 ring，而且**完全静默**
`derive_boundary_edges` 对判死的 cavity 只是 `continue`，**不写任何 readout / diagnostic / gate 信号**。
⇒ 一条 0.12 m 的 span 判死一个 88 m² 的房间，账面上看不出发生过任何事。

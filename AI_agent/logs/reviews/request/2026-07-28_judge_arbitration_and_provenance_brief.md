## 1. 三条缺口（按活体证据陈述）

### 缺口 A · 多个诊断并存时由谁定案

判卷器在配对几何时会遇到两类问题：
- **真破裂**：上游产出的几何本身有拓扑问题（如两段墙之间有 1e-9 的缝、同一区域重复占用）。
- **不可测**：几何合法（生产端校验全绿），但判卷器的精确路径量不了它（如一条 dx=5e-10 的近轴边，两侧写法不一致）。

**已确立的约束**（基线 R-4，仍有效）：判卷器**只许说「我量不了」（capability NA），不许说「上游几何非法」**。这是此前三轮假红的结构性根源。

**缺口**：基线**没有规定当两类问题同时出现在同一楼层时谁定案**。三轮实现各自给出不同答案，各自被证伪：

| 轮次 | 实现 | 活体反证 |
|---|---|---|
| r2 | advisory 配对提到正交门之前（谁先跑谁定案） | 产品额外画一条 5e-10 斜边 ⇒ 自己的 1e-9 真缝整轮降级为 capability NA 不出分 |
| r3 | 收集诊断后按类别裁决，但 real-break 用 **reason 白名单**判定 | 白名单只含两种 reason ⇒ 实际优先级成了「白名单内 identity > capability > **白名单外 identity**」；`exterior_duplicate_owner` 被收集为 identity 类却不在白名单 ⇒ 仍可被 advisory 洗成 NA |

**r3 的活体**（sol 独立构造，生产五项校验全绿）：footprint `0.1×0.1`；cell A、B 都等于完整 footprint（重复占用）；cell C 左半幅梯形、右边从 `x=.05` 斜到 `x=.05+5e-10`。上游 coverage 的 overlap `0.015 m²` 低于现行 `coverage_area_tol_m2=0.05` 故放行。
- 只有重复占用 ⇒ `score_product_identity_invalid`（正确判红）
- 重复占用 **+ 一条未配对 advisory** ⇒ `score_unsupported_combination`（**整轮 NA、不出分**）

**审阅方点名的实现难点**（事实陈述）：当前诊断的 context 只有 reason 与 floor_id，**没有足够的 span / 来源信息去区分「advisory 扰动派生出来的 duplicate」与「独立真实的 duplicate」**。而简单把 `exterior_duplicate_owner` 加进白名单会把既有合法的 advisory 派生形态重新误判为红（既有锁 `test_r4_live_counterexample_is_unsupported_not_identity_invalid` 会红）。

### 缺口 B · 计分守恒用什么数值判据

判卷器给墙计分时，把产品墙覆盖答案墙的长度按区间累加，并有一道守恒门：一条产品墙被记的覆盖量不得超过它自身长度（防止「一条 4 m 墙赚 8 m」的假绿，该假绿在 r0 真实发生过）。

**缺口**：基线 R-2 只为**身份层三个阈值**（合并 / 分裂 / 直径）规定了「实测推导 + 双向证明」，**没有覆盖守恒门**。两轮实现在二元之间摆动，各自被证伪：

| 轮次 | 实现 | 活体反证 |
|---|---|---|
| r1/r2 | `covered > obs_length + 1e-9` 才拒 | 固定窗吞掉真实过计：`covered=4.0000000005` 对 4.0 m 墙，`extra_rows=0` ⇒ 可见假红被换成静默假绿 |
| r3 | 零容差 `covered > obs_length` 即拒 | **合法**的三段严格相邻（零缝零重叠）铺满，因浮点顺序累加比端点直差多 **1 ulp** 被判红 |

**r3 的活体**（sol 独立构造，correction 生产五项全绿）：GT 上方一个长 zone、下方三个相邻 zone，T 型接头切出三段目标墙；correction 上下各一个长 cell，得一条完整产品墙。三段两两满足 `previous.p2 == next.p1`。
```
target lengths = 9.528046041637907 / 6.656808030274133 / 4.676648646020535
covered 顺序累加 = 20.861502717932577   (0x1.4dc8b712eef7fp+4)
observation.length = 20.861502717932574 (0x1.4dc8b712eef7ep+4)
excess = 3.552713678800501e-15          (1 ulp)
```

**审阅方的关键论断**（事实陈述）：施工方的论证「不相交片段之和不可能超过投影长度」只成立于**实数**，**没有证明 binary64 的逐项减法与顺序加法会与另一次端点减法得到同一 bit pattern**。且当前 target 层用 `_SUBINTERVAL_SUM_TOL=1e-9`（承认累加漂移）、observation 层用零容差（假设精确不可能超出），**两层互不自洽**。

**明确的否定约束**：**不得再在「固定 1e-9」与「逐位零容差」之间摆动**。

**双向要求**（任何方案都要同时满足）：
1. 真实重叠导致的过计（如 `covered=6 > length=4`）必须响亮拒绝；
2. 上述三段合法铺满**不得**拒绝；
3. 负 extra 的处理必须与同一判据一致——既不许静默吞掉真实过计，也不许拒绝合法舍入。

### 缺口 C · 判卷器凭什么认定两个数是同一个坐标的两次出现

基线 C-1″ 规定了**输入合法性合同四条**，须在运行时执行、违反即响亮拒绝：
① 同一意图坐标的全部出现值直径 < 合并阈；② 不同意图坐标之间最小距离 > 分裂阈；③ 不出现落在护带内的距离；④ 归并不得造成零长边 / 相邻重复顶点 / 环自交 / owner 重数冲突。

**缺口**：合同 ①② 需要知道两个出现值是**同一意图**还是**不同意图**，而当前实现只有距离 ⇒ **用距离反推意图 = 循环假设**，无法真正执行合同。

**已给过一次骨架但两轮未落地**（事实）：主控曾裁定「意图身份 = 来源身份，输入里本就存在」，形如 `polygon 顶点 → (floor_id, zone_id, vertex_index)`、`boundary 端点 → (floor_id, segment_id, endpoint_side)`。**两轮施工均未实现**，且第二轮自查表未将其标为 PARTIAL（施工方误以为已完成）。

**当前实况**（主控与审阅方各自独立核实一致）：
- `_cluster_axis(raw_values: Iterable[float], ...)` 只收浮点值；`_build_floor_identity` 把点展平成 `(float(p[0]) for p in materialized)` ⇒ **来源身份在进聚类器之前就丢光**。
- `score_identity_contract_mismatch` 全仓**只在码表出现一次**，零 raise、零输入版本、零负锁。
- 合同 ④ 只覆盖 polygon 的**相邻**顶点坍缩。**非相邻重复顶点 / 归并后自触自交 / 同一 owner 与自己反向配对**全部静默接受。活体：环 `(0,0),(4,0),(4,4),(0,4),(0,2),(2,2),(0,2)` 当前产出一条 `zone_ids=("Z","Z")` 的「内墙」。
- boundary / reading 侧的错误 context 缺 `diameter` / `diameter_hex`；boundary duplicate-after-merge 连原始两对端点都没记。

**为何并入本轮**（用户 2026-07-28 拍板）：三条缺口同源——都关于「判据凭什么立足」。

## 2. 已成立、不要推翻

以下经跨家族对抗审独立验真，**是本轮设计的地基，不在讨论范围**：

- **C-1 身份机制**：放弃全定义离散化（任何定格量化都有边界），改单链接聚类 + 护带 + 直径守卫 + 歧义显式拒绝。三个历史反例（真实 sm24 `8.059999999999999`↔`8.06` / `0.1+0.2`↔`0.3` / 1-ulp 量子边界对）已转绿。
- **C-1′ 身份池 = 文档内不跨文档**：GT 池与产品池分离；跨文档比较只在判卷容差层；产品向答案**单向**配准。硬锁「答案原子与分母 = 答案字节的纯函数」已落地并经 neuter 验真。
- **C-2 分母 = 长度（米）**，criterion 三分（漏画 / 多画 / 重笔）。
- **C-3 联合切点原子化**；`score_match_ambiguous` 在平面墙通路结构性不可达。
- **B-1 单向注册**：产品墙注册到唯一答案支撑线，≥2 条响亮拒绝（不许选最近）。r0 的「4 m 墙拿 8/8」已堵死并经 neuter 验真。
- **身份层三阈值**：`merge=1e-12` / `split=1e-11` / `diameter=1e-12`（直径 ≤ 合并阈）。余量经独立复算：合并侧对实测漂移 562×、对 20 m 单 ulp 281×；分裂侧对 1e-9 缺口 100×。
- **R-4 方向**：「几何合不合法」权威在生产端，「判卷器能不能量」权威在判卷端且只许说 unsupported。**上游 `_EPS=1e-9` 本阶段只 advisory，不翻 blocking。**
- **W5 共享正交判据**已在生产与判卷两端真接线（neuter：生产 8 红 / 判卷 24 红经 extraction）。
- **未配对 advisory 已进可计数的运行时日志**（含 floor 与两端点 binary64 hex）。

## 3. 硬约束

1. **不变量 #4（gt 铁律）**：`case_tests/test_baseline/gt/` 只 gate② judge 与人可读；gate① / 执行器绝不 import。共享模块零 gt import。**已签字的 sm24 答案一个字节都不许动**（不重签、不迁移、不「规范化」）。
2. **不变量 #6（建筑复杂度可扩展性）**：方案必须为未来复杂体量留路（非方形 / 退台 / 挑空 / 中庭）。**禁把「正交」「共底面盒子」这类当前简化假设烤死到无法松动。**
3. **sm21 legacy 通路零变化**（既有分数字节 + 渲染像素 hash + 分派路径）。
4. **判卷器不得宣判上游几何非法**（R-4）。
5. 方案须给出**可机械验证的验收出口**（每条出口要能写成会红的锁 + 指定 neuter），不接受「靠约定遵守」。
6. **禁止先定数字后补论证**（R-2 纪律，本轮同样适用于缺口 B）。

## 4. 已被实证否决的路径（不要再提，除非能推翻其反证）

| 路径 | 反证 |
|---|---|
| 把坐标映到绝对格子（定格量化 / Decimal 取整 / 定点整数） | 任何全定义离散化都有边界；6 个量级各构造出跨格反例 |
| 「谁先跑谁定案」的顺序调整 | 两种顺序各有一种错（advisory 先跑 ⇒ 真缝洗成 NA；tile 先跑 ⇒ advisory 扰动出 `exterior_duplicate_owner`） |
| 用 reason 白名单判定「哪些算真破裂」 | 白名单外的 identity 诊断仍被 capability 抢先掩盖（第三张脸） |
| 守恒门用固定容差 `+1e-9` | 吞掉真实的 5e-10 过计 |
| 守恒门用逐位零容差 | 合法三段铺满因 1 ulp 假红 |
| 用距离反推「同意图 / 异意图」 | 循环假设：合同 ①② 要验证的前提正是它假设的东西 |
| 判卷器对量不了的形态报 identity invalid | R-4：判卷器拿自己的能力上限宣判上游几何非法，是三轮假红的结构性根源 |

## 5. 出案要求

针对**三条缺口各自**给出：
1. **机制**：判据凭什么立足（要能回答「为什么这条判据不会在下一个位置再破一次」）。
2. **边界行为**：分不清 / 量不了 / 真破裂 三种情形各自的出口，以及**并存时**的裁决规则。
3. **可机械验证的验收出口**：每条要能写成会红的锁 + 指定 neuter；并说明如何同时满足 §1 各缺口列出的双向要求。
4. **与 §2 地基的兼容性**：明确说明是否触碰、如何不触碰。
5. **实施代价与风险**（含对既有测试的影响面估计）。

**格式**：markdown，落 `AI_agent/proposals/`。推导写清楚，结论要能直接当施工基线用。

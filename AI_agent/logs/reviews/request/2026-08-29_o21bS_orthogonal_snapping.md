## 一、承重前提（⛔ 请自己复核）

**今天的行为**：转换器收墙线时，若一条线**两条腿都超过 `tau_axis`（= `dxf_axis_alignment_tolerance_m`，1 mm）**，
就发一条 `tarch_wall_nonorthogonal` 诊断并 **`continue` 整条丢弃**
（[`tarch_normalize.py:383-387`](../../../src/agent/judge/tarch_normalize.py#L383)）。

**实测后果**（主控，`plan-F1`）：

```
签字件（人工改直过）      face_lines = 225
as-received（没动过的原图）face_lines = 222   ⇒ 少 3 条
逐笔点名：13AD (dx=3639.90 dy=5.81) · 13AE (dx=3640.10 dy=5.81) —— 两腿都超 ⇒ S1 丢弃
          13DC —— 零长线（另一类，⛔ 本单不动它）
```

⇒ **`as_signed` 结构上比签字图少 3 条面线**，而修订台账**只会平移、不会拉直**，补不回来。
⇒ 这就是 **F-138**：「正交吸附不承重」那条口径在 `as_measured` 改从 as-received 出之后**已经作废**。

## 二、要做什么

### R1 · **把动作从「丢弃」改成「吸附」** ⭐ 含一个**必须停下上报**的阈值

**改什么**：两腿都超 `tau_axis` 时，不再 `continue`，而是**把短腿吸零**（即把这条线吸到它的主导轴上），
并**记一条吸附决策**（见 R2）。

⛔⛔ **但这里有一个今天不存在、必须新立的领域参数，⛔ 你不许就地发明它**：

> **歪到什么程度，仍然算「画歪了」（该吸）；超过多少，就不是画歪、而是一条真的斜线（⛔ 不该吸）？**

- 今天没有这个参数 —— 因为今天的动作是「丢弃」，丢弃对任何歪度都「安全」（丢错了至少是响亮地少一条）。
  **一旦改成吸附，吸错了就是【静默造一条图上不存在的墙】** —— 那正是本项目 33 条虚构墙的病根形状。
- ⇒ **你要做的是**：① 把它变成一个**有名字的、显式声明的参数**（⛔ 不许硬编码在 if 里）；
  ② **实测**全部在册 case（sm21 / sm24 / sm25 两侧图）里**每一条被判非正交的线的实际歪度**，列成分布；
  ③ **把你建议的取值 + 那份分布 + 「取这个值会吸附哪些线、放过哪些线」一并【停下上报】给主控**，
  ⛔ **不要自己定完就往下做**。主控要拿它去请用户签字（同 [[silent-default-threshold-behind-otherwise-conclusions]]：
  「否则就是 X」背后藏着一个没人签字的阈值；且弃权/边界类领域参数一律要签字）。
- ⚠️ **在拿到签字之前**，你可以先把**机制**做完（参数化 + itemize + 守恒式 + 测试），
  用**能让 sm25 通过的最小值**当占位并**在代码与报告里显式标注「待签字」**。

⭐ **另一条设计约束**：吸附**只允许把短腿吸零**（即吸到最近的轴），⛔ 不许顺带移动长腿方向的端点、
⛔ 不许改变这条线的**沿墙区间**。理由 = 事实层存 `(线位, 厚度, 沿墙区间)`，沿墙区间用于分母与洞口落位。

### R2 · **吸附决策必须 itemize**（GLM 点名，⛔ 不许静默）

> GLM 原话：否则 `as_measured` **静默丢失「原图是歪的」这件事**，与 A3 同族镜像。

⇒ `converter_readouts` 新增吸附清单：**哪条线（handle）· 吸之前的两个端点 · 吸到哪根轴 · 短腿被吸掉多少**。
⛔ 「被吸附过」和「本来就是正的」**在产物上必须分得开**。

### R3 · **守恒式随之更新**（GLM 在裁决里已给）

吸附后 S1 丢弃清零 ⇒
`len(all_wall_handles) == wall_lines_total + <吸附清单长度是 0，因为它们现在【进了】wall_lines> + degenerate_line_count`
⚠️ **准确形式由你按实测定**，但**必须满足**：`plan-F1` 与 `plan-F2` 两个视图**都逐位成立**，
且**把吸附清单里任一条删掉 ⇒ 恒等式必须红**（自证有牙）。

### R4 · **F-D 指纹翻转的显式处置**

动转换器**必然**让闭包指纹翻转 ⇒ sm25 那条 legacy 豁免值失效。
⭐ **锁已经补好了**（②-1b-R 的 R3：集合整体相等），所以**这次不许再靠往豁免集合塞值糊过去**。
⇒ 正确处置 = **让它红，并写进「随 gt 重签一并修」**；⛔ 不许扩大豁免集合。
**验收**：`verify_raw_layer_reproduction("sm25-L_anchor")` 变成 `implementation_drift`（**这是预期**，不是回归），
且那条集合整体相等的断言**仍然咬合**。

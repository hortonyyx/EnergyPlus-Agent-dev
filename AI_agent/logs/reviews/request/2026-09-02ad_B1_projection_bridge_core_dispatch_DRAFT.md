## 一、做什么（一句话）

把 `WallCompilationV1.walls` 派生成 `CorrectedGeometryV3` 的**房间**，并落 envelope。
算法 = **中轴平面剖分**，全档见设计稿 §四 与 §六之三。

**四步**（设计稿 §四）：
```
① 切割线 = 全部中线 ＋ 洞口（当中线延续）   ← ⛔ 不加洞口则一个房间都切不出来（实测）
② 端点延伸：墙带与对方实体矩形相交(含相切) ⇒ 延到对方中线
③ cells = arrangement 的每个有界面
④ footprint = 全部有界面的并集（⭐ envelope 里标 footprint_provenance = derived_from_walls）
```

## 二、⛔⛔ 本单的三条纪律（**来自用户 2026-09-02 令，见[指南 §十三](../../guides/reading_correction_split_guide.md)**）

1. ⛔ **几何派生代码里不得出现任何长度/厚度常数。** 需要尺寸时**只能从被处理的数据里取**
   （如「对方墙自报的厚度」）。⛔ 不许写字面量、⛔ 不许从配置读一个「默认墙厚」。
2. ⛔ **验收夹具不许只用现有 case 的墙厚。** 必须有一组 **90 / 150 / 300 / 370 混排**
   （⭐ 且**同一张图里厚度不唯一**）。只喂 120/240 就只证明了 120/240。
3. **正交**：当前实现**可以只处理正交**，⛔ **不要求**写非正交的拒绝路径或泛化分支
   （⭐ 且实测**非正交今天进不来**：设计稿 §9.2 三重关死）。
   **唯一要求 = 那个假设【局部化 + 有名字】**（一处判定 / 一个命名函数），
   ⛔ 不许把「反正是正交」散进每个函数。
4. **容差**：本单只有一处容差（§三），**必须数据派生**，⛔ 不许施工方自己定一个数。

## 三、⭐ 那处唯一的容差（**必须这样写**）

判据比较用 `<= ht2 + 1 unit`，那个 `1 unit` = **数据自己声明的坐标分辨率**，
**从输入的 `units_per_metre` 派生**，⛔ 不许写字面量 `1`。

⚠️⚠️ **写破这一句（设计稿 N-3）**：`units_per_metre` **只在 gt 侧存在**
（`as_measured.py`，`Literal[10000]`）；**生产链是浮点米、没有这个字段**
⇒ **本单的容差挂的是【夹具输入】的粒度**；**生产链接入时必须重新声明粒度来源**，
⛔ 那时不许沿用 1 unit 这个数。**这句要写进代码注释与契约。**

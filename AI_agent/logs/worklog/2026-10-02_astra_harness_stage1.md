## 工作包与可续接状态

- Astra 主线程：`src/agent_runtime` 的事件存储、模型适配、预算/停止、最小恢复、入口与集成；阶段 0 核心严格类型。
- `building_snapshot`：GPT-5.6 Sol / high，建筑契约跟进 3/4/5/8、保存 BIM 语义快照、对应测试与样例。
- `history_replay`：GPT-5.6 Sol / high，行为记录兼容读取、七组历史归档、确定性重放与跨版本比较。
- `frozen_tools`：GPT-5.6 Terra / high，冻结工具分类/MCP/哈希材料；服务容量错误中断，部分代码保留。
- `tools_finish`：GPT-5.6 Sol / high，接手工具包并复核逐工具分类、通用 MCP 依赖边界与真实工具证据。

各代理只编辑指定文件。共享工作树小提交只暂存自有文件。开发子代理不调用外部模型、不读凭据。

名词草案尚待用户确认，旧类型名本轮先不改；新增用规范。Paratera 最多 20 请求，只测图片、工具、公开思考字段；主线程统一计数，其他代理不得调用。初始外部调用 0。

## 实现判断

- 核心契约统一严格 Python 类型；JSON 从 `model_validate_json` 读取，避免把字符串/布尔值自动变成预算数字。
- 原费用联合缺少“价格未知”，新增 `CostUnavailable`，不把未报告价格伪记为 0；不扩展阶段 2 金额调度。
- 在工具发送前持久写入意图，增加通用 `tool_invocation`；生命周期补 `start`/`stop`。已知结果和协议失败均保留原件。未知写先读取保存状态，证据不足就停止，不自动重复写。
- 请求用明确序列化字节直发 HTTP，适配结束后先校验注入位置与图片哈希再落盘；没有 SDK 自动重试、隐藏转换或模型回退。
- 预算的 token 预留是保守估算，与服务报告用量分开；若实际超过预留，保存真实回执后停止，不能伪造合法结算。

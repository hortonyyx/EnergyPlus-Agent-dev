# 09-23 观察参数应用与厚度属性节点

用户批准按 Opus 两轮讨论结果施工，并再次明确工作模型继续 GLM。本节点只推进还原建模，没有 EP、部分推理或实体墙几何开发。

## 实现与验证

结构化观察绑定候选/目标对象/图像位置，采纳决定单独保存；尺寸链、像素轴标定和已存 profile 引用由代码换算后进入现有修改内核。门窗参数、共享墙位置和构件厚度支持引用；应用记录保存实际前后对象、相关连带移动、未绑定参数、成功或失败。推断允许但要标明依据；旧数值修改仍可用，不虚称全部参数已经观察驱动。

厚度保存在源 BIM `component_attributes`，关联物理墙/板。完全重合共墙两侧共同归属；不偏移任何空间、边界或开口。宿主改变须重绑、部分接触不自动传播，这是当前实现限制。并未实现完整实体构件、停点编辑 UI 或后端热工消费。

GLM 显式路由支持主模型及局部图像观察继承，实际型号与请求型号分别留证，路由异常不自动回退。当前图像工作模型为已验证的 `glm-5.3-flash`；本轮没有 Claude 工作调用或其他模型探测。

离线检查两组：几何/源出口/量测引用/平面入口 48 项通过；观察应用、GLM 路由、MCP 和输入恢复 54 项通过，合计 102 项。检查覆盖尺寸链实际写入、profile 篡改与过期引用拒绝、失败留证、共享墙连带移门、厚度不动几何、只读权限与 GLM 主/局部同路由。

[真实历史产物回放](../experiments/2026-09-23_claims_offline_replay/README.md)重放旧 GLM 竖链到实际东门，并在真实模型写入人工构造的墙/板厚度验收值，源几何逐项不变。不是新识读，不采纳该厚度为建筑事实。回放与原图 GLM 运行独立并行完成，未提供给模型。

[GLM run26](../experiments/2026-09-23_sm24_claim_application_glm_run26/README.md)从未修正高度的旧候选出发，独立识读东立面三链，以结构化尺寸链值把 ED1 从 0–2.4m 改为 0.2–2.6m；三窗保持。实物源比较只改变这一门，其余空间/边界/连接/门窗保持。1 次调用、237.09秒，CLI估算$0.574512（非账单），未使用 GT。新候选可查看，开发侧完成原图/立面视觉核对；不代表整案保真完成。

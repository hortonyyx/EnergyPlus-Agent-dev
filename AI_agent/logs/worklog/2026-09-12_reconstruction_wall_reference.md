# 09-12 还原建模：局部墙面与标注基准

用户从课题汇报任务回到主线，本轮只推进还原建模。开工为干净 main@05fa83d3、与远端一致、仅主工作树。已完整读取共同入口、目标、roadmap、开发约定与最新汇报/还原交接；沿上次提出的墙厚/标注方案做有界实现。

## 本轮实现

`1a6fa1c4` 接通真实源墙 ID 到两侧墙面的局部证据、厚度/偏移未知状态、标注两端身份/原图像素、确定性代表面换算及原图回叠。通过可选 proposal/source 字段进入源摘要，不改变旧源边界与门窗关系，不要求完整实体墙。Agent 可试算后持久化，自动反馈显示派生墙面；镜像不静默保留错误方向的旧证据。

完整设计与首版边界见 [共同模型](../../design/model.md#09-12-局部墙面与尺寸换算已接入实验-agent)。首版仅完整直墙及完整重合共墙，不支持走廊长墙的分段接触、一般角接/T 接点净空、显式敞开围护与洞深；材料分层、EP、部分推理和完整交互编辑本轮均未施工。

## 验证

[受控验证](../experiments/2026-09-12_wall_reference_setup/README.md)覆盖净距/轴距/外侧距/混合端点、偏心与反向、缺段尺寸链、未知偏移、共享墙单一证据、源对象保留及改墙后重派生。首次蓝色墙面像素边界被 PIL 截断，明确取整后修复。相关 38 项检查通过，另加真实 stdio 数值试算—保存—图片返回检查 1 项通过；之后加强同方向缺段链测试并单独通过。这些是定向离线检查，不是整案保真或新的全量成绩。

## 真实实验

[run14](../experiments/2026-09-12_bim_agent_sm21_run14/README.md)从 run13 恢复，仅六张原图/旧 proposal，开发侧只指定局部墙厚与尺寸方向。实际 claude-sonnet-5/medium，Claude 订阅 357.54 秒正常结束，CLI 估计 $1.3628069（非订阅账单）。两次保存尝试失败后产出 candidate_02：两段 inferred/厚度与偏移未知记录、没有 wall_dimensions、没有物理几何修改。走廊分段共墙被明确拒绝；模型后改选完整共墙。14 空间/15 窗/14 门，独立窗 15/15、分区仍 severe。原图/代码/源摘要与独立重放、显式回叠完整像素及浏览器离线交付检查通过；未知偏移没有画出墙面，这次未触发保存后的自动反馈。

run14 对两条竖向尺寸链实际调用算术工具，保留 7.76m 与 8m 差异；但对北链折点对应当前代表线、差额来自墙厚等仍有未证实的自信判断。模型说明不是自动验收结果，详见实验 README。首次浏览器命令误用缺 playwright 的项目 Python；复用既有浏览器虚拟环境后通过，没有新装环境。

run15 进一步限定为原图有明确厚度标注的外墙，以验证数值证据及墙面回叠；没有提供具体墙 ID、厚度数值、正确坐标、标定或 GT。这是更具体的辅助恢复条件，不是独立冷启动。[最终结果](../experiments/2026-09-12_bim_agent_sm21_run15/README.md)：实际 claude-sonnet-5/medium，351.27 秒正常结束，CLI 估计 $1.4480208（非账单）。candidate_01 保存两段外墙的 240mm 总厚及有符号偏移、2 条带像素的尺寸，实际画出派生墙面；北墙同墙两面换算结果成立，西墙正负侧端点反置导致 -0.48m 残差却未修。另把 y=810 像素错作建筑底边，跨轴比例差异 46.7596%，回叠竖向明显压缩。模型最终承认标定问题但没持久写回源；西墙证据还跨用了另一房间的墙段，应保留推断口径。

run15 的全部物理源对象仍与 run14/seed 相同，故复用同范围的分区/窗参照结果，不新跑评分。八份实现与六原图摘要、源摘要、墙和尺寸独立重放、完整回叠像素与实际工具 image block、浏览器离线页面及 iframe 通过。模型两次均在保存后才登记图面，真实自动新图反馈本轮没有发生，不能与此前 run13 成绩或本轮离线测试混称。两次都无 Haiku 实际调用。

本轮新产物建议先读实验 README 及独立核对再查看模型；run15 新证据保留为候选，不能把它们自动当成已确认的新几何基准。下一轮直接处理端点残差和错误图面锚点，判断是否足够支持实质局部修订。

## 范围与后续

两次生成都在现有 Claude 订阅隔离环境内，只开放原图和确定性 BIM 工具，Haiku 局部观察按需可选。没有 DeepSeek、付费 API 回退或 EnergyPlus；GT 只在生成结束后独立评价，不将已知答案反馈模型。旧模型、失败候选和原始流保留，流无损压缩记录摘要。

本轮补工具和真实证据表达，不宣称整体源分区改善、稳定自主纠错或独立冷启动成功。后续应围绕实际端点基准与回叠差异选择一处实质修订，再及时换例；不以毫米级 GT 转绿为目标，也不先扩展全楼墙实体或完整治理。

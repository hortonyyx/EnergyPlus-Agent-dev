# 09-10 七页课题汇报首版

用户在两份展示资产完成后，要求先做一版 HTML 汇报：极简、克制的科研风格，不用大段文字，关键文字中英双语。本轮只制作汇报，沿用已确认的七页结构；产品还原主线仍暂停在既有交接。

## 交付

- [汇报入口](../../../showcase/2026-09-11-research-report/index.html)：1600×900 设计画布，自适应窗口比例；浅底、细线、少量蓝绿色。研究目标、研究问题、三类建模、Agent 架构、两项成果、后续计划共七页。
- [静态 PDF](../../../showcase/2026-09-11-research-report/research-report.pdf)：七页、16:9，作为备用；三维交互仍在 HTML。
- sm25 页对照原始一层图纸与楼层展开静帧；Voimatalo 页对照真实贴图单体与当前 revision_02 模型。
- 两页“交互演示”在原页通过 iframe 展开已有 HTML，保持 sm25 原生查看器形式。Voimatalo 可切换原始体量、外壳、内部推理三版；返回保留所在幻灯片。只在点击后加载一个查看器，关闭时卸载。
- 支持左右键、数字跳页、Home/End、F 全屏、O/页码目录以及可点击导航；打印样式输出全部七页。离线加载不依赖 CDN、网络字体或模型 API。
- showcase 总入口改为先进入本次 slides，保留配套资产页与旧展示入口。操作及搬运说明放在汇报 README。

## 内容边界

相对高精度仍是研究目标。建模三类按信息充分程度划分，Agent 按反馈组织建模，共同 BIM 再派生后端模型。EnergyPlus 标识既有下游连接，其余风、光、声标为待扩展；不把本次展示写成新增 EP 实跑。

sm25 标注为人工辅助修订展示；Voimatalo 标注主助手辅助探索、内部未核实推断，来源 SUM / Helsinki。没有新增空间/窗/门，没有改变原始输入、当前模型、查看器或产品代码。三维静帧只是截图时隐藏界面、基准网格/坐标轴；sm25 在显示层展开楼层、隐藏顶面以露出内部。原始一层平面图为字节不变的复制。

## 分工与验证

主助手负责内容、版式、交互、视觉检查与集成；按项目模型分配约定，Terra 子助手完成有界的静帧初稿与离线浏览器交互检查。未调用其他外部模型/API，未调用 DeepSeek。

验证见 [实验目录](../experiments/2026-09-10_research_slides/README.md)：

- 1440×900 和 1920×1080 的 file:// 离线检查：页码/深链接/键盘/目录焦点、三处模型入口、旋转/分层/展开、Voimatalo 三版切换与返回保持通过；无 JS 错误、缺失请求和外网请求。
- 本地 HTTP 同源 iframe 内 Escape 返回通过。file:// iframe 的键盘事件受浏览器隔离差异影响，顶部返回按钮始终可用。
- 最终 1600×900 七页截图人工查看，修正第 3、7 页内容与底部分隔线过近的问题；所有图片加载，主要文字边界无溢出。
- 打印 PDF 验证为 7 页、1152×648 pt（16:9）。未做新的几何/模型/仿真测试，既有两份展示验证继续有效。

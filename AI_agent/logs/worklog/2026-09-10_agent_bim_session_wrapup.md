## 用户最新方向（下轮优先）

- 产品形态是模型驱动的总 Agent，配备代码/模型等工具，根据目标、输入与执行反馈组织任务。用户委托助手总体把控，但要求**边试边推进，不先定死结构**。
- 当前只集中在产出**可查看的丐版 BIM**，暂不管跑通 EP，不需要凑齐旧 0–5 六个环节。总 Agent 加一层子 Agent、旧阶段映射只是讨论建议，不是已定实现要求。
- **标注 + 像素双证据 ＞ 像素证据 ＞ 纯推理**：证据增加时提升精度，缺证据允许明确假设继续生成；纹理、模糊、单色、复杂表现图不匹配某种工具时不能自动没输出。已读到的房间、隔断、门窗和连通不能丢失。
- 单线改双线的历史动机是降低 reading 提前选线的推理负担，以及延后墙厚、轴/边标注带来的对齐取舍。当前不预先恢复单线或强制双线。可靠厚度与尺寸基准可用于提高几何精度，但精细墙厚不是生成前置。
- 材料分层等热工信息归后端模块；源 BIM 与后端用途派生分开。灰空间细化、完整编辑及物性扩展继续暂缓。

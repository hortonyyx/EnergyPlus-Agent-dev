# Voimatalo 缺面补全与统一查看器

用户看过第一版后指出：两侧缺图不意味着透空，正面缺口很可能是凸出的竖向交通盒；展示形式统一成 sm25。随后再次明确，不能预先把缺面都当成封闭墙，应先推理各处构成。本次按这个要求复核原贴图及裁剪前去标签瓦片的局部上下文。

结果：两个端部与邻楼贴接，按贴邻/露出山墙推断补全；正面补阶梯形凸出交通盒，保留不透光主面和六组退入窄窗。交通用途为推断，外凸几何和窄窗有新增纹理线索。没有建周边环境，没有修改输入 GLB。几何仍由主助手直接判读并用确定性工具生成，不计产品 Agent 自动生成成绩。

两版为 **13 / 165 个空间体、均 322 窗组、10 / 173 门**。原 316 窗的身份和几何完整保留；新交通盒连续跨八层、每层有连接门，没有假楼板封堵。细分版只在交通盒接入处调整假设走廊支路和临近两个办公室，其余既有分区沿用。源几何/接触/开口自洽检查 pass，但未评价真实内部或仿真结果。

[展示入口](../../../showcase/2026-09-11-research-report/demos/textured-mass/index.html) 使用与 sm25 相同的原生查看器布局与交互，旧定制顶栏/底栏撤下。Terra 负责包装与浏览器检查，主助手负责图意推断、几何和集成。原版本源目录保留在展示目录下，旧主 HTML 可由 `b6125c29` 回看；最新源目录 `revision_02/` 单独保存。

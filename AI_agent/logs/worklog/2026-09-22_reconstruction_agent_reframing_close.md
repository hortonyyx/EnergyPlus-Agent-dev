# 09-22 Agent 主线重定位收工与下一入口

## 本轮收工结果

在上一轮 GLM 实验收工后，用户进一步明确了项目主线：

- 07-07 一类旧案例的价值在于低级模型配合 CV 工具完成高精度图像到结构化 reading；不要求把旧 pipeline 原样恢复为新产品流程。
- 开发模型先探路、再将工具、步骤、中间产物和检查方式交给工作模型，是与历史 reading 经验互补的开发路线。
- 新产品应尽快形成模型驱动的总 Agent，旧 `reading / correction / modelling` 的职责拆分作为可调用能力和中间产物参考，不能继续把 Sonnet/GLM 直接整案出 BIM 当作主开发路线。
- 还原建模与部分推理暂时分开验证，但最终共用同一个 Agent、状态、工具路由、几何底座和查看/检查出口；部分推理额外管理假设、未知和缺失信息。

上述重定位已写入 [Agent 重定位记录](2026-09-22_reconstruction_agent_reframing.md)，并更新路线索引。当前没有新增生产代码，尚未开始 Agent 状态和观察账本的实现。

## 下一轮明确入口

下一轮先与用户讨论面向不同仿真后端的 BIM 输出形态，再继续 Agent 开发。讨论范围包括：

- 几何对象与来源/假设如何组织；
- 墙厚、门窗类型、材料或物性占位等非几何信息哪些需要在源 BIM 预采集；
- 哪些信息属于通用源模型，哪些应留给具体仿真后端派生；
- 如何保持几何准确优先，避免为 EP 或其他后端提前引入错误的物理假设；
- 还原建模与部分推理如何共用输出 schema，并区分实测、推断、默认和未知。

下一轮讨论结束后，再据此实现 Agent 的状态、观察账本、动作契约和输出接口。本轮不启动新的整案生成实验。

# 扩大模型能力池与成本优先的工作档

用户最终澄清：Flash 工作档以 Sonnet 为能力参照，更看重速度和低消耗，成本优先，同时衡量 token；智力上限不作严格限制，允许同一档随时间变强。按名字筛 Flash 和把这档固定为 Sonnet 硬上限的解释均已纠正。主力仍朝 Qwen 27B 这种本地级发展；降低智力依赖、快速、便宜逐步实现，建筑质量要求保持。产品支持用户自接模型和服务器多模型配置/调度，不能只在单一组合做好。已同步会话入口、目标、模型约定、决策、架构；此前暂缓视觉选型的排期由本次调研要求更新。

刷新 Paratera 目录一次，仍94项；公开官方资料核对后整理23项平台内候选和8项平台外能力，覆盖通用、本地主力、快速工作、视觉、OCR、embedding、rerank、ASR、检测/分割。平台列出、原厂能力、前次实测、实际建筑质量/经济性分开；只有此前4项有小型图像/工具接续记录，本轮新增推理0。目录含已公告下线型号、参数说明冲突、托管和权重规格差异、价格/速度未核等见[完整调研](../experiments/2026-09-28_model_capability_research/README.md)。DeepSeek只读资料、未调用。

六个候选 YAML profile 保留，补充按任务总成本、token和速度选型而非名称/静态智力上限的说明；原件按字节归档并核历史hash。Qwen3.8-Flash / GLM-5.3-Flash保留参与比较，暂未锁定默认产品组合。原始8次请求及回执不改，通用默认与BIM订阅入口不改；配置加载/客户端构造离线验证，无新增网络推理。

[配置设计](../../design/model_configuration.md)分开服务连接、模型能力与任务调度，专用服务不硬套聊天接口；未知角色不应无声回落不适配的默认模型。工作与复核/回退按已配置模型和费用/调用权限执行，Flash档没有必须低于固定Sonnet版本的门槛。此为设计，完整运行时未实现，未安装模型、启动建筑回归或自动多模型调用。

下一能力包接通API与同一BIM工具循环，准备最小OCR/视觉/工具任务验证，再用不同组合核可替换性。在满足任务质量要求的条件下，优先比较有效交付的总成本，包括主/子调用、思考、图片、缓存、失败/返工和自部署资源；总token/耗时同记，不将便宜单价、少token或高TPS直接当整案更划算。原Sonnet中断批次已结束，不自动续跑；整体还原质量尚未恢复，行为诊断保留。

## 本轮实现

- `proposal_edits.py`：对 legacy v1/v2 做深拷贝修订，支持 x/y 整体反射、窗/门更新、带理由及来源的删门、假设备注替换；房间/开口 ID 不变，几何算术由代码执行。反射同步窗方向和位置、门端点及非矩形轮廓方向。未知操作/字段、重复 ID 及未支持的额外围护/楼层 footprint/方向元数据明确拒绝。
- `run_bim_agent.py`：`--resume-candidate` 只导入 proposal 并重建生产检查；新增 inspect/revise 工具、剩余时间反馈、候选北向箭头；主模型 medium effort，局部 Haiku 由模型按需选用。图片响应附原尺寸、裁切范围和缩放因子，真实 stdio 已验证混合图片/文字响应。
- 所有候选独立落盘，操作记录有父方案摘要、改判理由、前后值和来源；旧候选不改。后补来源传播：活动门窗写入新来源，旧来源留在 before，支持显式更新对象假设；独立源 BIM 的 generation.corrections 保留完整修订历史并参与源摘要，包含删掉开口的原对象。
- 这是方案层局部修订和恢复，未接完整编辑 UI/正式 flow，也未承诺派生边界 ID 跨编辑稳定。工具只接本次图像和自产方案，生成侧不可读任意文件、GT 或事后评价。

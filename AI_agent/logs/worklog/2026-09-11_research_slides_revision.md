# 09-11 项目汇报逐页修订

用户审阅首版后给出七页具体修改。本轮继续展示制作，入口仍为 [HTML 汇报](../../../showcase/2026-09-11-research-report/index.html)，另更新静态 PDF。产品主线、原始图纸、已有源 BIM 与完整查看器不改。

## 用户要求与页面变化

1. 标题改为“面向设计前期的仿真轻量 BIM Agent”；封面直接嵌入可旋转的轻量 BIM，去掉完整检查面板。
2. 以实际图纸、已有模型截图、旧 showcase 的仿真结果示例表达长流程，明确人工识读、整理与专业配置导致设计反馈滞后。目标收束为轻量公共仿真底座。移除“尚待验证”等进展/验收说明，保留项目汇报的目标表述。
3. 多模态输入用具体图片展示，进入 BIM Agent 后展示还原、部分推理、完全推理三类。实际图纸、直接旋转的 Voimatalo 原始贴图、真实建筑航拍分别作为代表；分类解释由用户口头讲，不再把“依据是信息充分程度”写到页面。产品分类定义不因此变更。
4. Agent 内画出“输入识读 → 信息整合 → 空间推理 → 几何生成 → 检查修正”及返回反馈；这是概括信息处理关系，没有把产品实现固定成唯一工序。后端写实际名称 EnergyPlus、Radiance、OpenFOAM、Pachyderm；EnergyPlus 标已有连接，其余归扩展接口方向。
5. sm25 左侧同时显示两张平面、四张立面，右侧直接旋转 BIM，强调完整建筑图纸输入。
6. Voimatalo 原始贴图与输出直接在同页旋转；第 5、6 页输出都统一叫“轻量 BIM”。不再经过按钮弹窗或跳转。
7. 下一步按四个竖向栏排列，取消额外大标题；保留用户指定的空间理解、复杂建筑稳定性、降低模型依赖、交互编辑四项。

## 展示实现与素材

新增 `embeds/`，从已验证的完整 HTML 生成精简、独立离线副本。沿用 Three 与原始几何/贴图，只改变摄像机、背景、显示辅助和控件；BIM 留整体/分层/复位，封面与原始贴图使用 bare 模式。只加载当前页需要的 1–2 个 iframe，翻页卸载，避免后台 WebGL 累积；子页把有限翻页键传回父页，父页核对来源窗口后处理。

页面删去进展与验证脚注，不删除原始记录、数据假设与资产说明。sm25 仍是辅助修订展示；Voimatalo 内部仍是未核实的推理方案。本轮没有新模型生成、产品后端适配或 EnergyPlus 实跑。

真实航拍为赫尔辛基 A-lehtien 办公楼的公开影像，Harria / Wikimedia Commons，CC BY-SA 4.0，页面保留短署名和许可链接；这是 Google Earth 类视角的真实航拍参考，不冒充 Google Earth 截图。六张 sm25 图纸原字节复制。第 2 页仿真图与文字意图图来自旧 showcase；前者只标“结果示例”，不作为 sm25/Voimatalo 的结果。四个后端名称及领域已核对官方页面。详细来源见 [素材说明](../../../showcase/2026-09-11-research-report/SOURCES.md)。

## 分工与检查

按项目成块派工偏好，Terra 完成精简查看器，Sol 获取真实航拍和整页交互检查；主助手负责内容、版式、集成与视觉检查。没有外部模型/API 或 DeepSeek 调用。

第一次整页截图暴露原始贴图的旧说明面板仍遮挡模型、style 嵌套和背景不一致，主助手要求并核对修正。整页交互检查又发现装饰物过滤后调用空 `Scene.add` 产生错误；定位为本次显示封装的问题，修正后单独复查，不作为源代码噪声豁免。

完整验证与最终截图见 [本轮证据](../experiments/2026-09-11_research_slides_revision/README.md)。范围为离线显示、图片完整性、直接旋转/分层、键盘回传、导航与卸载/重载、七页打印；不增加产品几何或仿真验收结论。

最终七页已逐页查看，无文字越界、图片缺失或外网请求，PDF 为 7 页并同步到汇报目录。1440×900 与 1920×1080 各完成 76 项交互检查，修复后所有三类查看器补测均无页面或控制台错误。六张 sm25 图与原图字节一致，两份 BIM 的内嵌几何与完整查看器一致，页面本地链接均有效；校验值见 `delivery_check.json`。

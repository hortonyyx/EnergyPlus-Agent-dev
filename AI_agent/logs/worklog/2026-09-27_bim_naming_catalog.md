# 09-27 全构件命名与房间功能目录

用户将下一项优先级改为命名与房间功能：查旧命名约定，包含墙窗逆时针规则，覆盖 HTML 全部可点击对象（层、块、面）。功能类型优先找 EnergyPlus 既有表，不让工作模型自行扩词，类型与色块颜色固定映射。本轮独立开发，无子代理、工作模型或仿真调用。

## 查证与实现

06-23 用户 ratify 了 `Z01_F1_Office_SW`、`Z01_W1`、`Z01_W1_Win1` 及 Floor/Ceiling/Roof 方案，墙从最南、同 Y 最西顶点逆时针。旧实现仅在下游建模路径，当前独立源 BIM 的 HTML 仍显示内部 ID。本次将其接入源 BIM 公开名映射，保留所有内部 ID 和引用。门／空洞、局部显示片、开敞／未知区域和可选边补充同源后缀；共享门单一源 ID、两个房间侧别名。所有点选提供所属层、房间与父面；按层／块模式不再被门／辅助面命中抢走说明。楼层采用源楼层身份，修正按窗标高就近归层的潜在错误。

EnergyPlus `Space Type` 文档明确没有预定义枚举；采用其生态中 OpenStudio(R) 标准库的 `level_1_space_types.json`，固定提交 `83b1e64c6f130f02b48c8b3ad4eeb3eb4da41663`，原样保留61类与注释，另设项目 unknown。原始 JSON 与许可证随库保存。唯一运行时表同时保存标准代码、上游ID、中文、名称token、颜色与已知别名；模型 `get_bim_reference('room_types')` 与 HTML 从同一表读取。标准化在构建副本执行，原始 proposal 不变；表外类型报错，无功能默认为unknown。未启用任何负荷、时刻表、材料或设备参数。

规范：[全构件命名](../../design/bim_naming.md)、[功能类型表](../../design/room_types.md)。命名使用模型 XY 方向，不宣称真北；新增／移动房间可能改变公开序号，内部引用继续用源 ID。源 ceiling 不因处于顶层而自动改称外屋顶。

## 当前状态与接续

功能类型和全构件命名已接入当前独立源 BIM 输出。历史归档不覆盖；历史 EnergyPlus 派生面的命名模块保持原实现，不能把其切片重新解释成源物理墙。新的类型校验会明确拒绝历史 `office_inferred` 等临时类型；恢复旧稿时需在新候选明确迁移，不能静默吞掉。

sm21/run58、sm24/run56、sm25/run54仍是还原质量基线。本程只增加命名和显示验证，未证明工作模型已在新指引下独立选对房间功能。下一项可回到此前拟议的有限感知／核查角色对照，和房间功能目录是不同概念，具体选模／并发尚未固定。用户本轮要求独立推进仍有效。
